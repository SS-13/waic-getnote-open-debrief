# data/ · 第一大块：原始数据

> 来自得到笔记的 WAIC 采访原文。按年归档，**只入本地，不一定入库**（看体积与敏感性决定）。

---

## 结构

```
data/
├── 2024/                  ← 按年分目录
│   ├── 2024-07-XX__<被访者公司>.md
│   ├── 2024-07-YY__<被访者公司>.md
│   └── ...
├── 2025/
│   └── ...
└── 2026/
    └── ...
```

每年一个目录，里面是该年 WAIC 期间的所有采访笔记原文。

## 文件命名

`<YYYY-MM-DD>__<被访者或公司>.md`

- 日期：采访日期（按 getnote 原始 `captured_at`）
- 后缀：被访者姓名或公司，二选一

## 存储策略

| 情况 | 处理 |
| --- | --- |
| 单条笔记 < 几十 KB、纯文本 | 入 git 即可 |
| 录音 / 大体积文件 | 仅引用 `audio_url`，不入库 |
| 含敏感信息 | 加 `.gitignore` 规则，仅本地 |

## 如何新增

1. `mkdir -p data/<year>/`
2. 用 `scripts/fetch.py --year <year>` 慢慢拉（自动归类）
3. 手动补充时按命名约定放文件
