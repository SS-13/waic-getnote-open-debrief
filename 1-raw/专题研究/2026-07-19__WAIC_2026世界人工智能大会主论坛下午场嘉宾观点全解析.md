### 📊 主论坛下午场嘉宾观点全景梳理

本次主论坛下午场集结图灵奖得主、中外院士、全球AI领域顶尖学者与头部企业创始人，围绕AI全球治理、物理智能、产业生态等核心方向输出前沿思考，按四大板块结构化整理如下：

#### 一、领航伙伴：理论锚定方向

该板块聚焦AI发展的底层逻辑与全球治理框架，核心嘉宾观点如下：
| 嘉宾身份 | 核心观点金句 |
| :--- | :--- |
| John Edward Hopcroft（图灵奖得主、美国康奈尔大学教授） | 各国需制定应对信息革命带来的种种变革，专注于培养人才的国家，将成为世界领先的强国。 |
| 杜宁凯 Nicholas B. Dirks（纽约科学院院长兼首席执行官） | 要采取行动开展人工智能治理，必须要创造出新的实践方式。 |
| 薛澜（清华大学苏世民书院院长、研究教授） | 人类社会要想共同保证人工智能的安全，就要确保AI大模型不会超越风险红线，建立风险监测与防控机制，提高社会对人工智能技术的认识，并积极参与人工智能伦理道德问题的讨论。 |
| Mark Nitzberg（加州大学伯克利分校人工智能研究中心执行主任） | 如果人工智能是全球公共产品，那么围绕人工智能安全与伦理治理的科学研究，也必须成为一项全球共同事业。 |
| 王坚（中国工程院院士、阿里巴巴实验室主任） | 人工智能正在变得像数学一样基础，未来50年，其作用就像数学在人类科学发展历史上所起的那样。 |
| 苏昊（复旦大学浩清特聘教授、复旦大学通用物理智能研究院首任院长） | 物理智能的架构，是把人还给人。物理智能的突破口，不在模型的架构，而在知识的聚合。通用性是终点，而可靠性才是起点。 |

#### 二、锐见通向未来

该板块聚焦AI技术落地的前沿探索与创新实践方向，核心嘉宾观点如下：
| 嘉宾身份 | 核心观点金句 |
| :--- | :--- |
| 刘子鸣（清华大学助理教授、元图智能研究院科学家） | AI时代最大的优势是知道怎么去“偷懒”，不是可以靠勤奋把缺口补上，如果AI没有办法帮我们偷懒，那都不算AI。 |
| 曹越（Sand.ai创始人兼首席执行官） | 要敢于相信AI的能力，只有敢于相信的人才会迎来真正的Aha Moment（尤里卡时刻）。 |
| 陈恺（上海人工智能实验室青年领军科学家） | 研究的元能力是进化模型的核心能力，把模型培养成“天才科学家”，将会比“天才程序员”达到更高的上限。 |
| 诸葛鸣晨（Recursive创始成员） | 期待未来的RS1算法成为通用求解器，然后用这类算法来探索“完备神经计算机”，实现图灵完备、行为可溯、可编程，并具备机器原生语义的新型神经网络。 |
| 姜旭（亮源智创创始人兼首席执行官） | 具身智能公司实现新、成功率高的打法可能是保持开放的心态，做非常广泛的探索。 |

#### 三、思想启迪行业

该板块聚焦AI产业发展的伦理边界与长期价值，核心嘉宾观点如下：
| 嘉宾身份 | 核心观点金句 |
| :--- | :--- |
| Yoshua Bengio（图灵奖得主、加拿大蒙特利尔大学教授、LawZero科学和工业联盟主席） | 人类必须建立完善的风险管理流程，并以负责任的方式实施，最终确保重大决策体现全球共同福祉。 |
| 周伯文（上海人工智能实验室主任、首席科学家） | AI可以代表人类行动，但不能代替人类负责。让渡代理权的速度，不应超过我们验证它的能力。 |
| 姜育刚（复旦大学副校长、教育部长江学者特聘教授） | 具身智能作为未来产业会走进大众生活，人类将进入“人机共融”的新时代。 |
| 徐立（商汤科技董事长兼首席执行官） | AI真正意义上走向大众并不是通过替代，而是通过放大每个人的能力，带来更多更可能性的场景。 |

#### 四、共创伙伴：生态释放潜能+场景贯通链路

该板块聚焦AI产业落地的商业化路径与垂直场景创新，核心嘉宾观点如下：
| 嘉宾身份 | 核心观点金句 |
| :--- | :--- |
| 沈亦晨（曦智科技创始人、董事长） | 光电融合的规模化落地不是“什么时候发生”，而是“正在发生”，3-5年内数据中心里有30%以上的芯片会是光芯片。 |
| 查浩（思朗科技董事长兼首席执行官） | 整个行业从过去补单点能力发展到了系统级优化以及在系统中追寻效率的新阶段。 |
| 胡效赫（基流科技创始人兼首席执行官） | 从第一性原理的角度看，如果能把Coding（编程）做好，就可以催生出“杀手”级别的大场景。 |
| 薛继龙（艾捷科首席科学家） | 推理市场的需求量很大，场景非常多元，这将驱动硬系统的重构和新架构的诞生。 |
| Andreea LACHAPELLE（2026世界人工智能大会全球首席人工智能官） | 负责任的AI是我们必须严肃对待的问题，更好的绩效表现带来了更重大的责任。 |
| 姚卯青（觅元合伙人、智科科技董事长兼首席执行官） | 世界模型核心本质是能够理解物理世界的运行规律，它最重要的功能是能够预测世界的下一个状态。 |
| Alex Zhavoronkov（英矽智能创始人兼首席执行官） | 随着我们迈向制药超级智能，我们不仅将重塑医疗健康的未来，更将破译生命的深层密码，让健康寿命的延长不再是梦想。 |
| 陈亦伦（它石智能创始人兼首席执行官） | 它石的路径可以概括为Foundational Model + App：一方面拥有全球范围内最集中、最丰富的制造业场景。中国拥有全产业链模型，另一方面集中丰富制造业场景。 |
