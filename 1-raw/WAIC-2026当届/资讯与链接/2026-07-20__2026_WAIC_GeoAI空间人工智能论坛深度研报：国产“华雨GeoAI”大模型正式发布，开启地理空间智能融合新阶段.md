### **🏛️ 论坛核心概况**

本次论坛是2026年世界人工智能大会暨人工智能全球治理高级别会议（WAIC 2026）的重要分论坛，于7月18日在华东师范大学空间人工智能学院正式举办，主题为“洞悉天地 智引未来”。
- **主办单位**：华东师范大学、同济大学
- **协办单位**：浙江大学、莫干山地信实验室
- **参会阵容**：汇聚海内外院士专家、顶尖科研学者与行业领军代表，围绕空间智能前沿核心议题开展深度研讨，聚力推动多学科交叉融合与产学研协同创新。

### **🚀 核心成果发布：“华雨GeoAI”大模型**

本次论坛最重磅的成果是华东师大自主研发的**“华雨GeoAI”大模型**首次对外发布，该模型由地理信息科学教育部重点实验室牵头，联合空间人工智能学院、地理科学学院、自然资源部超大城市自然资源时空大数据分析应用重点实验室共同推出。

#### 技术背景

城市降雨内涝临近预报因城市系统与下垫面高度复杂，长期是国际前沿和行业难题，华东师大开拓了利用卫星遥感实现城市降雨内涝临近预报的全新技术路径。

#### 核心技术能力

| 技术维度 | 具体参数与能力 |
| :--- | :--- |
| **技术底座** | 以多源地球观测数据为基础，深度融合人工智能算法、地理空间分析及物理机制模型 |
| **验证过程** | 历经多次上海历史台风事件内涝过程迭代验证，通过与实测水深反复比对优化，预测精度表现突出 |
| **预报时效** | 可实现**提前3至6小时**的城市内涝临近预报 |
| **核心价值** | 精准回应“哪里积水、多深、风险多大”等关键问题，为城市应急管理和防灾减灾决策提供科学及时的数据支撑 |
| **落地进展** | 已与气象局业务部门完成对接，开展多轮模型验证和下垫面参数优化，即将投入业务化应用 |
| **未来规划** | 持续拓展智能感知、精准预测与风险决策能力，助力构建更安全、更具韧性的城市环境，服务数字地球建设与可持续发展 |

### **🎯 战略定位：服务国家“人工智能+”部署**

当前人工智能正以前所未有的速度重塑世界，空间人工智能作为实现“空-天-地-底”全域智能的核心，已成为全球科技竞争的制高点与驱动新质生产力的重要抓手：
1.  对接国家“十五五”规划对“人工智能+”的全面部署，响应上海打造世界级AI产业集群的发展目标。
2.  华东师大2024年依托百年地理学科积淀，以“地理空间为基底、人工智能为引擎”，整合遥感科学、计算机科学等优势学科成立空间人工智能学院，是学校主动服务科教兴国战略、推进新工科建设、深化交叉学科创新的核心实践。
3.  持续深化政产学研用协同创新机制，推动前沿技术迭代升级与落地应用，赋能国家战略落地、产业转型升级与民生安全保障。

### **🔬 前沿学术观点：院士专家勾勒GeoAI技术蓝图**

论坛主题演讲环节，四位顶尖专家从全域空间维度输出系列前瞻性、引领性学术成果：
1.  **Naser EI-Sheimy（纳沙-艾尔希米，加拿大工程院院士）**：在“导航：GeoAI与物理世界的基础纽带”报告中，系统阐释导航技术作为GeoAI衔接数字空间与物理世界的核心纽带价值，夯实空间智能技术应用底层逻辑。
2.  **童小华（中国工程院院士、同济大学副校长）**：聚焦国家深空探测战略，分享“月球与深空探测智能测绘遥感研究进展”，展示我国智能遥感测绘技术在深空探索领域的突破性成果。
3.  **张晓平（加拿大工程院院士、清华大学深圳国际研究生院教授）**：立足低空经济新兴赛道，提出低空智联网感通算控一体化创新发展路径。
4.  **李军（加拿大皇家科学院院士、华东师大空间人工智能学院名誉院长）**：深度解读太空智能计算创新范式，揭示其全面重塑卫星对地观测体系、赋能全球地球科学研究的核心价值。

论坛当日下午同步开设四场平行分论坛，由华东师范大学、莫干山地信实验室、同济大学、浙江大学分别牵头，聚焦四大核心方向：
- 智能遥感应用
- 时空地理信息智能
- 智能感知处理
- 地球智能
集中展示GeoAI在智慧城市、自然资源管护、防灾减灾、生态环境监测等领域的前沿探索成果。

### **📌 关键洞察与行业价值**

本次论坛不仅为全球空间智能领域科研工作者搭建了高水平对话平台，更通过“华雨GeoAI”大模型等成果，展现出中国学者在空间人工智能领域从基础研究到应用转化的全链条创新能力，将进一步加速空间信息科学与人工智能技术的深度融合，搭建高能级协同创新平台，持续为我国空间人工智能的高质量发展注入动力，让空间智能技术更好地服务国家战略、赋能产业升级、造福社会民生。
