### 🔍 核心模块总览

本次解析的代码是微信公众号H5生态的底层基础库，覆盖**设备环境识别**、**微信JSAPI封装**、**网络请求路由**、**数据埋点上报**、**富文本内容处理**五大核心能力，是微信H5页面实现跨端兼容、原生能力调用、性能监控的关键支撑组件。

### 📱 设备与环境检测体系

该模块通过User-Agent正则匹配与运行时特征校验，实现全平台的精准识别，核心识别维度如下：

| 识别对象 | 匹配规则与判定逻辑 | 关键标识位 |
| :--- | :--- | :--- |
| Windows系统 | 匹配`Windows 版本号`特征，同时校验32/64位平台属性 | `Device.os.windows`、`Device.os.type=15` |
| macOS系统 | 匹配`Mac OS X 版本号`特征，处理版本号下划线转点格式 | `Device.os.Mac`、`Device.os.type=14` |
| iOS全系列 | 覆盖iPhone/iPad/iPod三类设备，提取iOS版本号 | `Device.os.ios`、`Device.os.type=1/13` |
| Android系统 | 匹配`Android 版本号`特征，同时支持鸿蒙系统识别 | `Device.os.android`、`Device.os.harmony` |
| 微信内置浏览器 | 精准识别微信主程序、企业微信、小程序环境、鸿蒙微信等场景 | `Mmversion.isWechat`、`isInMiniProgram` |
| 特殊浏览器 | 覆盖QQ浏览器、UC浏览器、小米浏览器等第三方内置内核 | `Device.browser.MQQ`、`Device.browser.UC` |

同时内置多项关键能力兼容性判定：
1.  **H5视频支持检测**：仅Android 4.1+且微信版本≥4.2的环境返回支持
2.  **自动播放权限判定**：iOS 10以下系统默认禁用视频自动播放
3.  **iOS锁定模式识别**：iOS 16+环境下检测WebAssembly、WebGL等API是否被禁用
4.  **触摸事件兼容**：iOS 6以下与微信5.0以下版本强制禁用触摸能力

### 🛠️ 微信JSAPI封装层

该层对微信原生`WeixinJSBridge`能力进行异步封装，解决跨域、初始化时序、重复回调等痛点：
-   **异步就绪机制**：通过监听`WeixinJSBridgeReady`事件，确保JSAPI调用前桥接已完成初始化
-   **跨域兼容处理**：针对跨域iframe场景自动降级，避免抛出非预期错误
-   **事件回调管理**：维护`JSAPIEventCallbackMap`映射表，支持同一事件注册多个回调函数
-   **未支持能力缓存**：对返回`action not supported`的能力进行本地缓存，避免重复无效调用
-   **二次打开场景适配**：在二级页面场景下自动等待页面鉴权完成后再执行JSAPI调用

### 🌐 智能网络请求路由

该模块实现了三层请求降级策略，最大化利用微信原生能力提升请求性能与安全性：

| 请求层级 | 触发条件 | 核心优势 |
| :--- | :--- | :--- |
| 原生JSAPI请求 | 微信环境内优先触发 | 绕过Webview跨域限制，直接通过微信客户端发起请求，性能最优 |
| 客户端转发请求 | 配置了对应转发域且版本达标时触发 | 由微信客户端统一接管请求，自动携带Cookie与鉴权信息 |
| 标准XHR请求 | 非微信环境或前两层失败时兜底 | 兼容普通浏览器场景，保证基础可用性 |

同时内置完整的请求监控能力：
-   全链路网络日志输出，支持远程调试工具捕获请求全流程
-   响应数据结构校验，自动上报不符合预期格式的异常
-   请求长度超限检测，对URL/POST数据超过4096字节的场景进行埋点告警
-   自动重试机制：针对鉴权失败场景自动调用`updatePageAuth`刷新票据后重试请求

### 📊 全链路数据埋点体系

该体系实现了多维度的性能与业务数据采集，核心特性包括：
1.  **批量上报策略**：默认4条数据合并为一次上报，1秒超时自动触发兜底上报，减少网络请求次数
2.  **页面离开兜底**：通过`unload`事件与微信`reportOnLeaveForMP`能力，确保页面退出前数据不丢失
3.  **多端兼容上报**：非移动端环境自动降级为`navigator.sendBeacon`上报，保证数据送达率
4.  **指标聚合能力**：支持求和、平均值两类聚合统计，自动按维度分组计算
5.  **异常监控**：内置BadJS异常上报通道，对JS错误、请求失败等场景进行采样上报

### 📝 富文本内容安全渲染引擎

该引擎针对公众号文章内容进行安全过滤与增强渲染，核心能力如下：
-   **链接白名单过滤**：仅保留微信域名下的合法链接，自动过滤外部恶意跳转链接
-   **特殊标签转换**：将小程序链接、位置POI标签、话题标签、音乐标签转换为微信原生可识别的组件格式
-   **关键词高亮**：支持搜索结果场景下的关键词精准定位高亮，自动避开代码块、引用块等特殊区域
-   **多内容类型适配**：针对音频页自动提取时间点标签、图片页自动处理中英文排版偏移问题
-   **安全字符过滤**：自动移除可执行脚本相关标签，防止XSS注入风险
