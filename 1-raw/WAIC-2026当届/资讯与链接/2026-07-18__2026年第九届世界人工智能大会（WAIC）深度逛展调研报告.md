### 🏆 展会核心基础概况

本届是WAIC举办的第九年，也是史上关注度最高的一届，整体以“智能伙伴，共创未来”为主题，创下多项历史纪录：
| 核心指标 | 具体数据 |
| :--- | :--- |
| 展览总面积 | 超10万平方米，为历届最大 |
| 参展企业数量 | 1100余家 |
| 展出展品总数 | 3000余项 |
| 全球首发展品占比 | 超300项 |
| 嘉宾阵容 | 汇聚图灵奖、诺贝尔奖得主及中外顶尖院士 |
| 展期时长 | 4天，7月17日正式开幕 |
| 场馆布局 | 史无前例的“三地四馆”格局：世博、张江、西岸三大分会场分别对应核心技术、算力基建、未来应用三大领域，世博主会场下设4个独立展馆，分别展示应用生态、基础设施、具身智能、科创项目 |

开展首日即便仅开放半天（中午放行观众，下午4点闭馆），现场已摩肩接踵，叠加上海40℃高温、室外体感近50℃的极端天气，观众仍在户外排队近2小时入场，行业热度可见一斑。

### 📌 五大核心逛展洞察

#### 1. 全行业的“机会追逐潮”

本届WAIC一票难求，原价168元的单日票被黄牛炒至上千元，甚至出现网友有偿求代逛、代收集名片宣传册的现象。场馆内约三分之二的入场者佩戴工作证，不同颜色证件对应不同身份：红色为嘉宾、蓝色为媒体、橙色为参展商/论坛主办方、绿色为工作人员，大幅降低了陌生人建联的成本，让展会成为高度浓缩的行业社交场。
首日到场人群可分为四类核心群体：
-  AI从业者：了解行业前沿技术进展
-  初创企业：对接上下游资源、拓展商业合作
-  专业投资者：实地考察产业基本面、挖掘优质项目
-  应届求职者：借AI盛会叠加秋招的契机投递简历，不少企业HR也直接在展位挂出招聘需求双向揽才
本届WAIC首次设置OPC专区，从711个报名项目中遴选出22家“一人公司”为其提供展示机会，同时组织超200位投资人现场对接项目，全维度打造资源对接场域，集中体现了国内从业者面对新一轮AI技术变革时，混合着焦虑、激情与行动力的集体状态。

#### 2. 具身智能：从“千机一面”到底层技术分化

本届展会具身智能赛道热度持续攀升，参展企业从去年的80余家增长至200多家，现场同步展出208款终端、300余台机器人，堪称行业“大阅兵”。
表面上大量人形机器人外观趋同，展示动作集中在挥手、递物、倒咖啡等标准化场景，让不少观众产生审美疲劳，但行业底层竞争逻辑已经发生本质变化：
-  一年前行业核心目标是证明“机器人能动”，展示内容以预设动作为主
-  2026年行业竞争焦点转向“让机器人理解真实交互信息”，**触觉智能**成为新的核心赛道：机器人不再仅依赖视觉感知环境，而是通过感知接触力、摩擦、滑动等数据实时调整动作，完成叠衣服、精密装配等复杂任务，不同企业已在感知、决策、执行等底层能力上走出差异化技术路线，逐步构建起专属技术壁垒。
行业下一阶段的核心挑战，是完成从实验室到生产线、再到普通家庭的落地“最后一公里”突破。

#### 3. 消费级AI：家用“贾维斯”从科幻走向量产

本届WAIC首次出现接近科幻作品中“全场景智能助手”的落地产品：摩尔线程推出的**MTT AICUBE AI家庭中枢**，该产品已实现量产并在京东上架，售价10999元。
以“生成上海三日游方案”为例，它的能力链路已从传统问答工具升级为长期在场的生活协作者：
1.  理解需求：基于自然语言生成包含景点、路线、时间分配的完整旅行方案
2.  自动执行：绑定用户微信后自动创建专属联系人，按时间节点推送行程提醒，无需用户随身携带设备
3.  持续跟进：基于历史上下文承接用户后续修改需求，动态调整方案
这标志着AI不再是“拿起即用、放下即停”的工具，而是开始成为家庭中持续在线的“第二角色”。

#### 4. 工业AI：落地速度远超消费端，成为AI成熟第一站

工业展区是本届展会人流最密集的区域之一，核心逻辑是产业侧对AI的落地诉求远高于消费端：
-  西门子面向中国市场正式发售**Eigen工程智能体**，首次实现工业AI从“辅助工具”向“自主执行”跨越：工程师仅需用自然语言描述需求，AI即可自动完成硬件配置、程序编写、可视化界面设计全流程，在与中科摩通的试点中，将刹车系统调试的时间成本压缩了30%。
-  西门子提出“场景牵引”是工业AI落地的核心路径：中国拥有全球最完整的工业门类、深厚制造体系和快速创新能力，AI只有深入每一条真实生产线解决具体问题，才能完成从单点突破到规模化落地的跨越。
当前AI距离大规模进入普通家庭仍有距离，但已经在工厂场景中完成落地验证，成为AI技术走向成熟的第一站。

#### 5. 算力基建：轻量化终端背后的硬核支撑全面崛起

本届WAIC几乎集齐了国内所有头部芯片、服务器、智算厂商，大量数十吨级的算力设备直接搬进展厅，成为最受专业观众关注的展区：
| 核心算力产品 | 关键参数与亮点 |
| :--- | :--- |
| 东方算芯堆叠芯片 | 成立仅2年的初创企业，通过将计算芯片与存储芯片垂直堆叠（每层厚度<0.5mm），大幅降低数据传输损耗，实现原创路线量产 |
| 华为昇腾950超节点 | 首次亮相，最大可扩展至8192张昇腾卡，算力规模是上一代384卡超节点的20倍 |
| 中科曙光10万卡AI超集群 | 入选本届WAIC十大“镇馆之宝”，全国产自研，面向高精度科学计算场景 |
| 中兴通讯异构超节点 | 入选十大“镇馆之宝”，核心优势是可高效兼容不同国产厂商GPU，生态包容性极强 |
| 阿里云真武M890×磐久AL128超节点 | 入选十大“镇馆之宝”，全栈自研，同等算力下推理性能较传统架构提升50%，是前一代产品的3倍 |
过去一年国产算力产业实现跨越式发展，不再是单纯的技术追赶者，已经进入与全球顶尖厂商并行、甚至局部领跑的阶段。

### 📝 补充细节

本届展会最具代表性的普通参与者，是专程从苏州赶来的00后散户投资者，他现场逐一走访沐曦、摩尔线程、华为昇腾等算力企业展位，实地调研国产半导体进展，印证了WAIC早已不是单纯的行业技术展会，而是不同群体寻找自身在下一轮AI浪潮中位置的核心资源场。即便行业仍存在泡沫与不确定性，绝大多数参与者都不愿只做时代的旁观者。
