- **论坛**：记忆张量·从一次性 Agent 到记忆原生智能时代论坛
- **时间**：2026-07-17 · 9号会议室 · 主旨演讲
- **嘉宾**：熊飞宇（记忆张量，创始人兼 CEO，上海算法创新研究院大模型中心负责人）

## 一句话概要
记忆不是某个应用的附属功能，而正在成为各行业智能化的基础设施；记忆张量以「基本原理—基座模型—应用落地」三层方法论，推动 AI 从一次性生成走向有状态、可进化的长期智能。

## 核心观点
- 记忆的重要性来自认知的第一性原理，而非押中风口：更长的上下文、更大的数据库、更准的一次性检索，只解决了「如何把信息找回来」，并没有回答「过去如何改变未来」。
- 团队从第一天起践行三层方法论：三年前提出记忆分层理论 → 训练出忆立方基模 → 打造 MemOS 把能力带入个人与企业真实场景。
- 智能体记忆有五个维度——认知抽取、持续推理、自我进化、迁移转化、群体演化，把记忆从「记录信息」推向「形成认知、积累能力、驱动进化」。
- User Memory 要从「默认单一用户」走向多主体：一个家庭有不同成员、一辆车有不同乘客、一个游戏世界有大量 NPC，记忆需按多视角分别演化。
- 双产品协同：Cloudforce 让 Agent 真正开始工作，个人记忆产品让每一次工作都不再白白发生——「让所有的 AI 都记得同一个你」。
- 下一步是记忆原生模型：原生化（memory native）、状态化（stateful）、可进化（evolvable），让基模从「调记忆」走向「用记忆」。

## 内容整理

### 一个方向如何从少数人的判断成为行业共识
前年（2024）WAIC 在这里发布了忆立方模型，去年 WAIC 发布了记忆操作系统 MemOS，今年再回到这里。今天想汇报的不只是一家公司做了什么，而是一个方向——如何从少数人的坚持逐渐成为整个行业要共同面对的问题。让人激动的不是提前押中了风口，而是最早相信、持续构建并反复验证的那件事，终于被更多人看到。这背后不是偶然，而是始终从认知的第一性原理出发：单纯从工程角度，记忆容易被理解成更长的上下文、更大的数据库或更准的检索，但这些只解决了把信息找回来，没有回答过去如何改变未来。

### 三层方法论与记忆的五个维度
方法论分三层：基本原理探索（三年前的记忆分层理论）、基模训练（忆立方）、应用落地（MemOS）。在此之上，智能体记忆被拆成五个维度：一是**认知抽取**，把碎片化数据转化为事实、偏好、画像、事件与环境的认知，而非简单保存原始对话或文档；二是**持续推理**，沿时间线组织事件、理解环境与参与者的因果关系并追踪状态变化；三是**自我进化**，记忆随新信息和反馈不断修正、融合、遗忘，高价值经验结晶为 skill；四是**迁移转化**，从多任务、跨场景经验中提炼可复用的求解结构；五是**群体演化**，经验与 skill 可跨 Agent 共享、复用、迭代，一个 Agent 学会的能力成为所有 Agent 的共同资产。

### 从终端到行业：记忆作为基础设施与生态链接
在终端，与荣耀探索端云协同的安全记忆机制，与联想构建全域统一的智能记忆底座，并进入智能家居和智能座舱，让设备长期理解不同用户、家庭成员与乘客；在行业侧，记忆进入工业制造、CDMO、健康与金融证券——工业中记住设备状态与工艺经验，金融中记住用户的投研思路与脉络，企业 Agent 中跨任务保留目标、进度、反馈与责任链路。这些场景表面差异很大，底层问题却高度一致：AI 必须形成对服务对象和业务环境的持续理解。过去一年围绕英伟达、华为、阿里云等生态伙伴完成适配，把算力、数据库、Agent 平台与记忆系统连接，让记忆既能在云端规模化运行，也能进入本地设备与国产算力环境。

### User Memory 与个人记忆产品
现实中被服务的往往是多个主体。团队用一个多视角（多主体）的游戏 Demo 演示：NPC 太白因玩家表现而信任度上升，NPC 小山则因不满而配合度下降、开始顶嘴，随事件演化几方大吵起来——所有记忆都按不同视角分别演化并推演整体事件（可在展台与 Git 体验）。个人记忆产品的定位是「让所有的 AI 都记得同一个你」：首次登录即扫描电脑里的历史工作经验、生成总结并记住待办；通过 CLI 方式交叉调用，无需逐一做官方适配即可对接市面主流 Agent 与工具（飞书、OpenAI、Cursor、Claude 等），在一个工具上做到一半的任务可在另一处无缝继续，并能精准复用用户在此前某一轮提出的具体格式要求。在 LoCoMo 长期记忆评测中整体表现全面领先，token 消耗相比 OpenAI 降低 95.6%；在某智能体基准的五项任务中取得全面第一。

### 企业侧：Cloudforce
Cloudforce 与记忆产品是一套双产品协同：前者让 Agent 开始工作，后者让每次工作都沉淀下来。其核心能力有四：**skill 引擎**（把高手方法从一次性操作提炼为所有 Agent 可调用的能力）、**云电脑沙箱**（在安全隔离环境中操作真实系统、交付可用成果）、**持续记忆**（把过程、判断依据与结果沉淀为企业记忆）、**企业级管控**（管得住、看得清、可回溯）。目前已服务四个行业两百多家客户，高频重复任务的单场景效率最高提升约 180 倍，关键流程端到端耗时缩短 60%–75%，并与中国电信、中国联通、顺丰信息等展开合作。落地闭环遵循「人示范—学—做—验」：人通过录屏示范，AI 深度理解学习，带着记忆进入真实系统执行，再用执行结果校验学习质量（如销售把逐行录入 ERP 订单的重复工作交给 AI 完成）。

### What's Next：记忆原生模型
对未来的判断可概括为三个关键词：**原生化**（memory native，让记忆进入基座模型，成为模型在计算过程中自主形成、使用、管理记忆的原生能力）、**状态化**（stateful，大模型当前本质仍是无状态预测器，未来需要跨交互、跨时序的内在状态）、**可进化**（evolvable，让过去的经验在模型内部真正改变未来）。记忆的下一步是让基模从「调记忆」走向「用记忆」，从无状态预测走向有状态学习——这正是记忆原生模型，也由记忆张量 CTO 李志宇在本场论坛压轴展开。
