## 一句话概要
从模拟世界（Chatbot）、探索世界（RL/智能体）到走向真实世界，Agent 时代对推理提出"速度无上限"的新维度；未来交互必然走向多模态自然交互（NUI），并要靠端云协同 + 强化学习把 AI 送进普通人的生活。

## 核心观点
- 从 2024 年起就把大模型分为几个阶段：模拟世界（学人类说话的 Chatbot）→ 探索世界（用强化学习让模型完成任务）→ 走向真实世界（Agent）。
- Agent 已从 coding 破圈到金融、法律、HR、法务、财务等岗位，"人手一个 Agent"帮助日常工作。
- Chatbot 时代推理只需超过人类阅读速度（约 30 token/s）即可；Agent 时代，输出速度需求变成"无上限"——因为用户只要结果、越快越好。
- 优化目标随之升级：从"性价比"（同样的钱换更多智能）到新增"速度"维度。
- Agent 必然走向多模态：对人类最高效的输入是视觉、输出是语音，纯文字交互"不像话"；交互要走向自然交互（NUI）。
- 真正的大脑在云上，但端云协同才能兼顾隐私与体验；需用强化学习训练端上小模型，学会"何时该请教云端"。

## 内容整理

### 三个阶段：模拟世界 → 探索世界 → 真实世界
这套判断从 2024 年起用到现在。第一阶段是**模拟世界**：把数据灌进模型，让它学人类说话，你与它对话就像和人聊天。第二阶段是**探索世界**：从 2024 下半年、OpenAI o1 到 2025 年初的 DeepSeek，开始用强化学习，让模型去探索、完成任务，做对了就给奖励。逐渐地它不只是对话，而成为能在不同场景发挥作用的 Agent——最早最火是 coding，随后破圈到金融、法律，以及公司的 HR、法务、财务等岗位，几乎"人手一个 Agent"辅助日常工作。自家模型也顺应时代从早期版本迭代到最新一代，早年拿过一些榜单第一，到 Agent 时代其 coding agent 产品在 3 月做到全球调用量第一。

### Agent 时代：速度的需求变成"无上限"
左边那张"成本下降上千倍"的图很多人画过；而 Agent 应用给推理又加了一个维度——**速度**。为什么？2024 年的聊天机器人，模型推理只要超过人类阅读速度（约每秒 30 个 token）就够支撑对话体验。但进入 Agent 时代，输出速度的需求变成无上限：因为让 Agent 完成 task 时，用户不会去看它中间的思考过程，只要它尽快交付结果，越快越好。所以优化目标也从纯粹的"性价比"（模型又大又便宜、换来更好的智能性价比），演进到把"速度"作为新的坐标轴。（当年提出的分离思路，也曾被业界引用推导。）

### 交互走向多模态自然交互（NUI）
Agent 还在往多模态变化。原因是：人类进化几百万年，最高效的输入是视觉、最高效的输出是说话/语音。想象一下——我不放 PPT、不讲话，把演讲稿打印出来让大家自己读，效果好吗？不像话。而今天人和 Agent 的交互恰恰就是那样，只有文字。所以 Agent 要服务大众（而非只服务文字工作者、写代码的极客），交互一定走向 NUI——自然的视觉交互与语音交互。

### 端云协同：把 AI 送进普通人生活
有人问"端上跑个小模型是不是就好了"？但端上模型一定比云上模型小一百倍甚至更多，真正的大脑在云上。可只有云上模型也不行——以豆包手机为例，它会把所有屏幕截图传到云上，隐私和流量都是大问题。所以要做端云协同：端上模型与云上模型配合，用强化学习把端上小模型训练好——在训练环境里仿真一堆手机、配一个云上模型下发任务，通过奖励与惩罚，教会小模型"何时才适合请教云端"。这背后还涉及长期记忆（用户用手机一两年，端上、云上都要保留 context）、执行各种动作等，对 AGI Infra 提出更高要求。演讲者也表达希望与中兴在算力、终端等方面深入合作，让普通老百姓——而不只是少量代码/文字工作者——都能享受到智能体的好处。

## 金句
> Chatbot 时代，推理只要超过人类阅读速度就行；Agent 时代，输出速度的需求变成了无上限。
> 真正的大脑在云上，但只有云上模型也做不好——端云协同才是答案。
