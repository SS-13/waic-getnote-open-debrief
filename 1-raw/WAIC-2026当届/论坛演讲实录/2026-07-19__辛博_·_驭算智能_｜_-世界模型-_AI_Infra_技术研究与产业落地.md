- **论坛**：先进计算网络与算电协同论坛
- **时间**：2026-07-19 · 上海 · 617会议室 · 主旨演讲
- **嘉宾**：辛博（上海国创驭算人工智能科技有限公司，CEO）

## 一句话概要
驭算智能 CEO 辛博分享"世界模型 AI Infra"：主张 AI 前沿正从"预测下一个 token"转向"预测下一个物理世界状态"，并发布对标"Token 工厂"的"World State 方阵（WSF）"，探索世界模型推理加速与中国算力网下的商业闭环。

## 核心观点
- 驭算作为本次活动承办单位之一，由长三角国家技术创新中心立项、落地上海嘉定，以"多头结合"形式联合培育。
- 科技前沿正从"预测下一个 token"走向"预测下一个物理世界状态"；世界模型融合 simulation（产生 state）、generation（如 render）、action（输出 plans）三类工作，三者深度融合有望催生 world model foundation model。
- 一条规律洞察：当基模能力达到百 B 左右会"涌现"出足以释放大量需求与应用的智力水平（GPT-3 与 GPT-3.5 均约 175B）；而世界模型基模在 2025 年之前多停留在几十 B。
- 世界模型 Infra 与语言模型 Infra 在核心任务、典型算子、系统瓶颈与计量指标上都不同，带来三重升级：处理大量异构计算流水线、多层状态与记忆管理、从 token SLA 走向闭环行动 SLA。
- 技术成果覆盖网络结构到量化、芯片适配等六个方向，代表性工作包括"几何感知的 3D 生成加速"（约 2–3 倍）与"从模型结构学习跳过扩散过程中的冗余计算步骤"。
- 发布"World State 方阵（WSF）"；在中国算力网框架下推导出三种商业闭环——异构算力调度运营、EPCO 投资运营一体化、打包成 token 或以 MaaS 形式赋能，并参与"一带一路"Token 出海联盟，以"世界 state token"向海外市场供给。

## 内容整理

### 从预测 token 到预测物理世界状态
辛博先介绍驭算智能：由长三角国家技术创新中心立项、落地上海嘉定，作为本场承办方之一。进入正题，他指出自今年年初起行业尤为热议"世界模型"——因为语言模型已表现出可观的智力水平，科技前沿的目标要从"预测下一个 token"转向"预测下一个物理世界状态"。世界模型是个很大的话题：其中有的工作用来产生一个 state（如 simulation），有的用来产生一个 generation（如 render），有的用来给出 action 的输出（即 plans）。若这三类工作能深度融合，就有可能出现一个有理法的 world model / foundation model。

### 百 B 涌现规律与世界模型基模的成长
他分享了一个近期理解：从 2020 年 GPT-3（约 175B）到 2022 年底 ChatGPT（GPT-3.5 也约 175B）出圈，再到 agent workflow 出现，可以看到——当基模能力达到百 B 左右，涌现出的智力水平就足以让大量需求与应用场景被释放。反观世界模型，团队调研发现，2025 年之前主流世界模型基模大多停留在几十 B。为什么？这与语言模型 infra 与世界模型 infra 的差异有关。

### 世界模型 Infra 的三重升级
所谓 infra，简单说就是让模型训练和推理更高效、成本更低。语言模型 infra 与世界模型 infra 相比，由于核心任务与输入数据不同，其典型计算场景与 operator、真正的系统瓶颈都有很大区别；且世界模型最终不以 token 计量，因而形成了新的核心指标。由此带来三项必须面对的能力升级：一是处理大量异构计算的流水线；二是多层状态与记忆的管理；三是从 token SLA 走向闭环行动 SLA。他举例：给一本书做 summary，约 125k token 输入、产出 2.5k summary，约需 5P 算力，是典型语言模型工作流；而视频生成从网络结构到量化精度、再到大量芯片适配的软硬结合工作，完全是另一套。

### 推理加速成果与 World State 方阵（WSF）
团队在六个方向上都有进展。其一是"几何感知的 3D 生成加速"：利用对空间本身的理解做感知，并在网络结构与时间步上分别感知，整体推理加速可达 2–3 倍。其二是从模型结构层面学习——由于视觉模型的扩散过程分为很多步、部分步骤计算冗余，可学习"哪些计算可以不做"。辛博也提到，他早年跟随高文老师读书时主要做视频编解码，积累了相关基础。在本场项目发布环节，他发布了公司的"World State 方阵（WSF）"——名字对标"Token 工厂"，其中的 state 恰好与 token 对应。

### 算力网下的三种商业闭环与 token 出海
在中国算力网框架下，作为公司主体，驭算推导出三种可建立闭环的商业模式：异构算力的调度运营；EPCO 的投资运营一体化；以及打包成 token 或以 MaaS 形式赋能。依托该框架已汇聚大量可用算力（利用率可攀升至八九成），并期待与国展算力一同成长。最后，团队积极参与"一带一路"Token 出海联盟，希望以"世界 state token"的形式向海外市场供给、结算。
