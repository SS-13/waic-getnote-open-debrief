## 一句话概要
Agent 爆发让 Token 用量指数级增长，国产卡在推理场景已越过门槛；面对供应链风险与"软件不盈利"的隐忧，嘉宾共识是用联盟方式做标准对齐、协议共享与异构协同，让国产 Token 经济形成健康、可持续的商业模式。

## 核心观点
- Agent 爆发引发 Token 用量指数级增长，今天国产算力产能与 Token 产能的匹配仍有挑战。
- 国产卡在推理场景已"越过门槛"：编程 Agent、办公 Agent 背后的大几百 B 乃至 1T 以上主流模型，国产卡已能很好处理；训练场景也已完成精度对齐等实践。
- Token 统一了算法与算力的"度量衡"，从而加速产业循环、便于上下游结算与分工、扬长避短。
- 今年最大挑战是供应链风险：需求爆发太快导致供需周期错配，产能有风险、关键料价暴涨。
- Token 经济不是一颗芯片或一个超级节点能解决的完整命题，芯片必然异构；如何把各具特点的国产芯片整合进一个方案，是中兴作为系统集成商的关键任务。
- TCU 的关键是"每处最均衡"而非"单点最高"（HBM 大带宽但贵而供应有限，LPDDR 便宜、存储大但带宽小，各有适用场景）。
- 安全自主可控可走 RISC-V 开源开放路线；破解供应不确定性要靠尽快锁定 PO，而锁定 PO 的前提是生态成熟。
- 国产 Token 价格低，背后是国产模型、系统、超链、芯片与运营/投资方的价值；不能让"软件不盈利"演变成"Token 也不盈利"，要靠产业共建良性壁垒。

## 内容整理

### 生态的机遇与挑战

**阿里云（陈立伟）**：约半年内，Agent 爆发引发 Token 用量指数级增长，远超前两年聊天/对话机器人的需求，今天国产算力产能与 Token 产能的匹配仍有挑战。从需求看，国产卡在推理场景已越过门槛线——编程 Agent、各类通用办公 Agent 背后的主流模型今天多在大几百 B 乃至 1T 以上尺寸，国产卡已能很好处理，想象空间很大；训练场景上，过去几年不少客户已能用国产训练卡完成精度对齐与产能安排。如何在产能相对紧缺下完成国产算力布局与演进，需要生态协同、标准对齐、协议共享——这正是用"联盟"方式来做的必要性。

**海光（朱亚维，转写称"秦总"）**：Token 统一了算法和算力的度量衡，而统一度量衡的目的是加速产业循环——有了统一度量衡更利于上下游结算，结算的目的是分工。因此在这样的大环境下，各方聚焦自己的产业分工、通过上下游合作扬长避短，是解决挑战最基本的方案。海光正是围绕这一思路，在 CPU 与 DCU 上与中兴深度合作。

**昆仑芯（罗航）**：机遇不必赘述，重点谈挑战。第一大挑战是今年的供应链风险：需求爆发太快、供需周期不匹配，整个产能都有风险，各种料价暴涨，对产业生态并不友好。芯片公司不只是芯片公司，其实也是软件公司——要第一时间支持最先进的模型架构（如 DeepSeek、混元系列做了适配），这对整个行业是水涨船高的要求。硬件上昆仑芯有多层次投入：自研 Chip Link 协议极大提升吞吐，超级节点已发布 256 卡规模。他还提出深层忧虑：国产 Token 价格低，背后隐藏着国产模型、国产系统与超链、国产芯片，以及运营方、投资方的价值；过往形成"软件不盈利"的共识，但在 Token 快速增长的当下，不应让它再变成"Token 也不盈利"，这需要产业上下游共同奠基，并把获取的空间沉淀为国产生态自有的、良性循环与良性竞争的有效壁垒（也即所谓"标准"）。

**摩尔线程（董龙飞）**：讲生态，最重要的是协同。Token 经济不是一颗芯片、甚至不是一个超级节点能解决的，它是一套完整思路，其中的芯片往往是异构的。对中国芯片行业最大的挑战，是这些各有特点（memory 不同、带宽不同、算力不同）的芯片如何整合进一个 Token 经济方案——这正是中兴要完成的最重要任务。就像"好钢用在刀刃上""天生我材必有用"：HBM 存储大、带宽大但贵且供应有限，LPDDR 带宽小、但存储大且便宜，每个零件都有适合它的场景。把它们组合起来正是 TCU 的关键——TCU 不是把每个点都做到最高，而是把每处都做到最均衡。这既是芯片厂商、系统厂商要解决的最大挑战，也是最大机会。

**易行智能（吕建飞）**：机遇不赘述，谈到机遇想到"厚积薄发"——所谓厚积就是安全性、自主可控性，这本身又是挑战。面对挑战，易行智能基于 RISC-V 开源指令集做芯片，以开源开放的生态理念迎接挑战。此外是供应：今年见到中兴同事最大的一句话就是"货什么时候交"，供应难度非常大。如何解决不确定性？很简单——想获得好供应就尽快向中兴下单、锁定 PO；而锁定 PO 的前提是排除不确定性，这又要靠生态：一方面芯片企业把自己做到放心的程度，另一方面借中兴超级节点等运营优势减少不确定性。

### Token 经济的可持续模式
嘉宾进一步讨论了健康商业模式。2024 年以中兴等为代表，一批大模型厂商把自家模型 Token 定价直接砍掉 99%、降到 1%，字节、阿里等大厂随即跟进——当时这种定价对阿里云等一定是亏钱的，但那时 Token 消耗量并不大、场景多为聊天机器人，量很小。而对比今天，Token 用量已翻天覆地，推理模型参数规模、消耗算力、吃掉的基础设施与资本投入相比 2024 年发生巨大变化，靠亏本方式已不完全 work，各家核心定价也不再完全趋同。

阿里云给出三条提升性价比的路径：一是**大小模型结合**——简单任务用小尺寸模型、复杂任务用大尺寸模型；二是**调度**（阿里云做了十几年）——后台 Token 消耗曲线被内部戏称"牛马曲线"：都是生产力工具、上班时间用得高、下班和周末就少，这种规律带来巨大的调度空间，据此推出夜间折扣（把 Token 价格打到两三折）；三是围绕先进架构（如混合注意力 CSA 把推理计算复杂度从平方降到线性）持续做工程与算法创新降本。归根到底，中国基础设施完善、云厂商与政府投入大、企业竞争充分，会把 Token 价格整体拉低，但要走出一条健康、可持续、与别人不一样的路，仍要靠技术发展与产业共建。

## 金句
> Token 统一了算法和算力的度量衡——统一度量衡，才能加速产业循环、便于分工。
> 不应该让"软件不盈利"再变成"Token 也不盈利"，这是产业界共同努力的方向。
> 我们后台的 Token 消耗曲线，内部戏称"牛马曲线"——上班用得高，下班就少。
