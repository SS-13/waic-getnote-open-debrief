## 一句话概要
以"质为先、算为要、通为本"为纲，中国移动一手打造高效高质量的"Token 工厂"、一手构建超级 Token 入口，用自研评测体系帮国产芯片选好、用好，推动智算生态从"可用"走向"好用"。

## 核心观点
- "十五五"提出建设六张网，前两张（全国一体化算力网、新一代通信网）是中国移动主责主业，正走向"通感算智深度融合、全域覆盖"。
- 公司战略定位：**质为先、算为要、通为本**——用好算力要落到"打造 Token 工厂"和"构建超级 Token 入口"两极。
- 国产芯片生态大致分 GPGPU 与 ASIC（AC）两条路线，两条路线之间在实际使用上仍存在客观互通问题。
- 三大挑战：从"可用"到"好用"、从"单点突破"到"体系化创新"、从"国产替代"到"迎接全球竞争"，都还有一段路要走。

## 内容整理

### 六张网与"通感算智"融合
"十五五"规划提出建设六张网，其中前两张——全国一体化算力网与新一代通信网——正是中国移动的主责主业，对数字经济发展至关重要。通信网与算力网整体面向"通感算智深度融合、全域覆盖"的演进趋势，涵盖 5G/6G、算力网络、具身智能等关键节点；在"人工智能+"行动基础上，通信与算力都在与"智"做更深度的融合。公司据此提出**质为先、算为要、通为本**，并将"选好算、用好智"落到两极：打造 Token 工厂、构建超级 Token 入口。

### 打造 Token 工厂：夯实国产算力底座
在 Token 工厂侧，要夯实 IDC 资源与算力底座。当前国产芯片生态大致是两大阵营——GPGPU 路线与 ASIC（AC）路线，两条路线在最终使用上仍存在客观的互通问题。技术上，国产芯片还面临高端芯片生态、先进工艺制程等实际挑战。归结起来是三方面：从"可用"到"好用"、从"单点突破"到"体系化创新"、从"国产替代"到"迎接全球竞争"，都还有一段路要走，最终要解决"选型难、用型难"，让 Token 工厂更自主可控。

为此，中国移动围绕"全栈体系贯通、自研技术赋能"，构建了贯穿芯片—整机—集群的 AI 芯片评测体系，自研评测工具、提出指标体系与评测标准，输出如何科学选芯、软硬件适配、产品迭代优化的特色方案。到目前已帮助国产芯片解决 30 多项重大技术问题，涵盖底层硬件优化、驱动、算子优化、配套软件优化与协同生态等。

### 构建超级 Token 入口：选好、评好
在 Token 入口侧，要发挥运营商"超级网、超级用户"的优势，为用户选最合适、最好的模型，生产最高价值的 Token。做好入口有三方面挑战：一是模型准入把关要求高，如何选好模型再接入平台；二是推理成本管控，不同模型特点与适配场景差异大，要从推理成本与推理质量综合选出性价比最优方案；三是用户体验，要在网、算、智多个层面做全栈创新——这也是中国移动强调三网协同发展的原因。

作为工信部人工智能评测的重点行业牵头单位，中国移动主要面向国资央企及互联网公司生产的模型做权威评测，发布权威榜单与报告供国家决策与行业选型参考。从榜单动态看，国产模型最初基本处于"第三档"，逐步进到"第二档"，如今已在"第一档"占据更多席位。这几年累计对 100 多款主流大模型做常态化评测，持续跟踪不同版本，重点关注性能、成本、效率等综合表现。

## 金句
