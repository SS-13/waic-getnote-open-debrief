## 一句话概要
面对算力成本高企与利用率浪费，九章云极用"AI 工厂"（训练工厂 + Token 工厂）串起训练到推理的智能化生产，以"一度算力"统一计量、按需精细计费，并从算网存协同、模型优化、能源三条路径系统降本。

## 核心观点
- 算力成本已高到"单台八卡机抵一套房"：2026 年初至今 B 系列 GPU 涨价约 50%，根源是英伟达产能有限的供需关系；国产卡（如华为昇腾 950 系列）推理能力已较强但价格仍未打下来。
- 算力浪费来自两处：冯诺依曼体系中内存、CPU、GPU 之间的数据搬运与网络通信耗时（IO 等待），以及云端多用户抢占下的调度不佳导致系统整体变慢。
- 软件层方案是"AI 工厂"：训练工厂把基模型训练/微调成垂直模型，一键下发到 Token 工厂（推理工厂）自动封装成服务。
- "一度算力"以卡数为基准、精度到万分之一，CCI/VKS/DKS 各产品统一计量，用完即停、按需计费，不像传统"最少收一小时"。
- 降本沿三条路径：算网存协同、模型优化（蒸馏/量化/剪枝）、把能源作为可选变量。

## 内容整理

### 算力为什么又贵又浪费
张总从行业痛点讲起：B 系列（B200、B300）单台八卡机的价格可抵北京、上海一套房，2026 年 1 月至今 B 系列 GPU 已上涨约 48%–51%，主因是英伟达产能有限的供需关系；国产卡如华为昇腾 950 系列推理能力已较强，但价格仍未真正打下来。而"浪费"来自两方面：一是冯诺依曼体系里内存、CPU、GPU 之间必须做数据搬运与网络通信，存在传输耗时与 IO 等待（他打比方——两人约饭，一人先到也得等齐才能进门，效率就低了）；二是调度问题，云端多用户抢占资源，当一块 GPU 已占到 70%、调度不当仍把新任务塞进来，会让整个系统变慢。

### AI 工厂：训练工厂 + Token 工厂
九章的软件层方案是"AI 工厂"，含训练工厂与 Token 工厂，实现智能化的工业生产。训练工厂的流程很直接：数据进来，加上算力与工具链、强化学习平台，把基模型训练或微调成医疗等行业的垂直/专业模型；垂直模型可一键下发到 Token 工厂（推理工厂），自动封装成服务对客户提供调用。计量上，系统通过显存容量、浮点算力、显存带宽等参数做换算，对英伟达与国产芯片统一计量为"一度算力"——所有产品（CCI 云容器实例、VKS 弹性容器集群、DKS 独享算力集群）都基于"一度算力"统一计费，以卡数为基准、精度可到万分之一，算力拉起即计费、停掉即停止，避免了传统"用了就最少收一小时"的浪费。

### 阿拉丁 Cloud 3.0 与三条降本路径
AI 工厂的技术体系基于计算云平台最新版本"阿拉丁 Cloud 3.0"，底层是文件系统等基础设施。当前主要走三条降本路径：① **算网存协同**——消除数据等待、提升算力性能、全链路协调调度；② **模型优化**——蒸馏、量化、剪枝等性能优化；③ **能源作为变量**——过去电力调度是"把电从这调到那"，但计算中心一旦建成电源就固定了，九章改为基于不同任务去选择不同计算中心及其电源形式，把能源从固定参数变成可优化变量（并顺应绿电性价比已超过火电、煤电，以及国家对新建机房绿电配比的要求）。此外芯片层也在发生技术革命，如英伟达把 CPU 与 GPU 共封装、华为的 3D 堆叠等，都在显著提升芯片性能与效率。案例方面：北京巨声智能（2024 年创立）自购算力成本过高后转用九章 VKS 弹性集群，从八卡、十卡起步到最多 256 卡训练其大脑模型，每年在九章约一千多万用量；另有数字人训练案例采购一万多算力，成本下降 60%。九章定位为基于智算云的普惠算力倡导者与践行者，并与新能源方向共推相关标准。
