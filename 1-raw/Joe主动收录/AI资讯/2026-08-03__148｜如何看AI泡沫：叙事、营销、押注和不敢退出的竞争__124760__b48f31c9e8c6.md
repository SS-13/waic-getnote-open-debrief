## 得到大脑整理

### 🏛️ AI热潮的底层驱动力真的是技术吗？

**不是技术逻辑，而是国际政治经济叙事转型**。
- **叙事切换**：1990年代—2016年是**全球化叙事**，中国靠人口红利与制造业崛起 → 2016年后美国转向**国家竞争叙事**，AI（通用人工智能）成为新战略锚点。
- **三重绑定**：硅谷技术 + 华尔街资本 + 华盛顿政策 → 形成合力，**美股七巨头**股价飞涨。
- **泡沫战略**：美国纵容AI泡沫 = 用泡沫期建成**AI基建** + 锁定**全球顶尖人才** → 留下不可迁移的战略资产，与1999年互联网泡沫逻辑一致。
  说白了，美国是在用泡沫当"基建投资工具"，哪怕泡沫破了，基础设施和人才留在美国就是赚。

### 📢 市场上有哪三类AI营销话术？

**三类话术共同把AI塑造成"必赢赛道"**，推动资本进场。
- **话术一：偷换概念**：把**大语言模型**等同于通用人工智能（AGI，即机器能完成人类任何智力任务），但大模型本质是**统计模式匹配工具**，不具备理解、推理和因果认知能力。
- **话术二：规模定律**：宣称数据、参数、算力堆得越大，通用智能就会自然涌现 → 目前越来越多人承认**单纯扩规模走不到AGI**。
- **话术三：危机叙事**：渲染AI可能灭绝人类 → 本质是部分AI初创企业的**营销策略**，越说越危险越能吸引资本、维持高估值。

### 📉 过去十年中国AI经历了哪四轮泡沫？

**四轮泡沫均为对美国概念的跟随放大**，技术价值被过早、过度折现。

| 轮次 | 时间 | 核心领域 | 典型表现 |
| :--- | :--- | :--- | :--- |
| 第一轮 | 2016—2019 | 判别式AI（人脸识别） | 商汤7年亏**546亿元**，云从8年亏超**45亿元**，旷视终止IPO |
| 第二轮 | 2021年前后 | 元宇宙 | 六大平台虚拟地块周交易量峰值**10亿美元**，不到一年跌超**85%** |
| 第三轮 | 2022年底起 | 生成式大模型（百模大战） | 中美初创企业估值短期急升，**商业化模式不明朗**仍持续加码 |
| 第四轮 | 2023年起 | 具身智能 | 企业估值严重高估，朱松纯认为短期做出"机器人大脑"**基本不可能** |
- **跟随困境**：朱松纯用"下围棋 vs 打篮球"比喻 → 美国提概念、造趋势（布局），中国解释概念、论证趋势（追球）。
- **政策风向**：中央近年科技政策明确希望转向**自主引领**。

### ⚠️ 哪五种AI信仰正在被现实瓦解？

**泡沫持续的本质是对信仰的非理性押注**，目前五种信仰已出现松动。
- **算力信仰**："算力军备竞赛是通往AGI唯一门路" → 更多是算力供应商与资本联手制造的**焦虑叙事**。
- **数据信仰**："数据足够多就能解决一切问题" → 实际没有足够数据穷尽所有情况。
- **大模型信仰**："流畅对话 = 通用智能" → 前面已拆解，本质是统计匹配。
- **马斯克信仰**：宏大叙事更像维持资本市场信仰的工具 → 诺贝尔经济学奖得主**保罗·克鲁格曼**直斥为"庞氏骗局"。
- **天才少年信仰**：企业用"天才少年"标签制造话题、吸引资本 → 刚毕业研究生直接任首席科学家/技术副总裁。

### 💡 到底该怎么看待AI泡沫？

**泡沫不可避免，关键是区分类型、考验管理能力**。
- **泡沫是创新成本**：有时代意义的科技必然伴随泡沫，否则拉不动资本和人才大范围投入 → 估值泡沫是必须支付的**创新入场券**。
- **系统绑架 = 系统韧性**：AI已绑架资本、产业和大国竞争预期 → 泡沫破灭对各方影响都大，各方都会尽力维持，反而形成韧性。
- **两类泡沫要区分**：
  - **增量创新型泡沫**：为技术突破争取时间和资源 → AI总体属于这类
  - **消耗内卷型泡沫**：只烧钱换低价竞争和产能过剩 → 部分领域已出现
- **核心考验**：大国的**泡沫管理能力** → 既要发动集中资源，又要避免极端颠簸导致泡沫破裂。
