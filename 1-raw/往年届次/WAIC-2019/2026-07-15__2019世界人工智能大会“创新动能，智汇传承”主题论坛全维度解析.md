### **🏆 论坛基础概况**

本次论坛是2019世界人工智能大会（WAIC）的特色活动，核心信息如下：
| 项目 | 详情 |
| :--- | :--- |
| **论坛主题** | 创新动能，智汇传承 |
| **举办时间** | 2019年8月29日下午 |
| **举办地点** | 上海世博中心 |
| **主办单位** | 国家发展和改革委员会、科学技术部、工业和信息化部、国家互联网信息办公室、中国科学院、中国工程院、上海市人民政府 |
| **承办单位** | AI青年科学家联盟·梧桐汇 |
| **协办单位** | 上海交通大学、氪信科技 |
| **核心定位** | 聚焦AI人才培养与“明日之星”发掘，为上海“AI+”产业发展集思广益 |

### **📌 论坛三大核心亮点**

#### 1.  业界大咖与新生代共探AI发展，发布重磅行业报告

本次论坛邀请了海内外AI领域顶尖嘉宾，包括中国工程院潘云鹤院士、微软全球执行副总裁沈向洋，以及企业、高校的AI中生代力量，围绕人工智能社会角色与愿景、中国AI基础研究突破、大型互联网公司AI研发布局、产学研融合与高校人才培养等核心议题展开深度研讨。
论坛将正式发布**《AI IN CHINA人工智能研究与应用报告》**，该报告由10余位行业领军人物、专家学者共同撰写，客观呈现中国AI科研与应用的真实现状，重点覆盖六大前沿方向：
- 消费级场景：外卖、机酒预订、电影购票等交易类超级应用的AI落地，以及智能助手的发展前景
- 金融领域：AI技术助力金融机构落地“人工智能第一”战略，提供个性化金融产品与服务
- 算法研究：贝叶斯模型改进、不完全信息决策、对抗性攻击与防御技术
- 模型创新：基于非神经网络的深度学习模型的构建方案
- 脑智能前沿：依托中国唯一脑智能国家平台NEL-BITA，基于“飞行脑纳米级连接组”研究启发的视频编码方案

#### 2.  全球首发“A班生计划”，精准孵化AI明日之星

该计划是AI青年科学家联盟面向全球AI人才流动趋势推出的精准孵化项目，核心规则与权益如下：
| 项目维度 | 具体内容 |
| :--- | :--- |
| **选拔对象** | 20-30岁的高潜力AI青年，包含顶尖博士生、青年学者、融资阶段不超过A轮的AI初创企业创始人 |
| **首期规模** | 招募15人 |
| **专属权益** | 创业/学术导师一对一指导、国家重点实验室项目对接、孵化器/加速器与资本资源对接 |
| **设立初衷** | 帮助青年AI人才快速完成资源链接，缩短成长周期，加速成长为下一代AI领域领军人才 |

#### 3.  跨界战略签约，扩容AI青年科学家联盟生态

论坛期间AI青年科学家联盟将与互联网软件、汽车、金融、咨询、AI明星创业公司等多领域领军企业签署战略合作协议，打破产业边界，打造跨产业、国际企业间的连接器，既强化产业链上下游协同，也推动不同行业间的AI技术交流与合作。

### **📊 上海AI产业发展背景数据**

截至2019年，上海AI产业已进入发展快车道，位居全国第一梯队：
- 人工智能核心企业数量超1000家
- 泛人工智能企业总量超3000家
- 人工智能相关产业总规模超700亿元

### **📝 补充细节**
1.  AI青年科学家联盟的前身是2018年首届世界人工智能大会的特色论坛上，由氪信科技与上海交通大学联合发起，在上海市副市长吴清见证下正式成立，首批会员为20余位头部AI创业领军者与学界中坚力量；2019年大会期间联盟完成首次扩容，新增深圳鹏城实验室、阿里、美团等机构的专家成员。
2.  2019世界人工智能大会整体举办周期为8月29日-31日，主会场覆盖上海世博中心、上海世博展览馆，定位为全球顶尖的智能领域国际合作交流平台，大会官方注册预约通道已正式开放。
3.  当时中国人工智能领域投资规模已占到全球总量的60%，AI被明确认定为“关键生产要素”，人才储备成为决定城市AI发展速度的核心变量。
