### 📌 发布会基础概况

2019年6月18日上海市政府召开专题新闻发布会，由上海市副市长吴清介绍大会筹备进展，参会嘉宾覆盖央地多部门核心负责人：国家工信部科技司副司长朱秀梅、科技部战略规划司副司长张旭、上海市经信委主任吴金城、浦东新区副区长管小军共同出席，正式对外公布2019世界人工智能大会的核心安排。

### 🏛️ 大会核心基础信息

本次大会是经国务院批准的聚焦人工智能的大型国际会议，核心信息如下：
| 维度 | 具体内容 |
| :--- | :--- |
| **举办主题** | 智联世界 无限可能 |
| **举办时间** | 2019年8月29日-31日 |
| **举办场地** | 主会场：上海世博中心；分会场：徐汇滨江，覆盖浦江两岸 |
| **主办单位** | 国家发改委、科技部、工信部、国家网信办、中国科学院、中国工程院、上海市人民政府 |
| **承办单位** | 上海市经信委、上海市发改委、上海市科委、上海市网信办、浦东新区政府、徐汇区政府、上海市科协、东浩兰生集团、上海广播电视台 |

### 🏙️ 上海AI产业布局与先发优势

上海将人工智能定位为城市优先发展战略，目标打造人工智能“上海高地”，已形成四大核心先发优势：
1.  **企业集群优势**：全市人工智能核心企业超1000家，规模居全国前列，“东西集聚、多点联动”的产业格局成型，头部企业的“头雁效应”持续释放。
2.  **科技创新布局**：落地微软-仪电创新平台、上海脑科学与类脑研究中心等基础研发载体，亚马逊、BAT、科大讯飞等头部企业的AI实验室相继落户，本土独角兽依图发布首款AI云端芯片，技术影响力突出。
3.  **智慧应用品牌**：2018年12月在全国率先发布首个人工智能应用场景建设实施计划，面向全球开放10大应用场景、60项创新产品，通过“揭榜挂帅”机制打造AI新技术首发首用标杆。
4.  **产业生态赋能**：2019年5月获批建设上海（浦东新区）人工智能创新应用先导区、上海国家新一代人工智能创新发展试验区，打造标杆示范项目，推动AI与实体经济深度融合。

配套落地保障举措方面，上海明确两大核心方向：
- 产业端：聚焦智能驾驶、智能机器人、智能硬件、智能传感器、智能芯片、智能软件六大重点赛道，编制产业发展路线图形成“上海方案”，推出多层次企业引育计划，构建“人字形”产业空间布局，推动张江、徐汇西岸等区域产业集聚。
- 资本端：推动上海人工智能产业投资基金组建运作，依托科创板打通产业与资本的对接通道，同时推动AI与航空航天、高端装备、无人驾驶等领域深度融合，面向全球开放应用场景。

### ✨ 2019大会四大核心亮点

本届大会延续“高端化、国际化、专业化、市场化、智能化”办会方针，设置**高端论坛、主题活动、应用展示、智能体验**四大板块，核心亮点如下：
1.  **高端论坛高度聚焦**：设置2场高峰论坛、10场行业主题论坛，覆盖机器学习、AI芯片、无人驾驶、AI+5G、AI+医疗、AI+工业、AI投融资、AI法治安全等细分赛道，主论坛规模约2000人，数百位演讲嘉宾中国际嘉宾占比达40%。
2.  **应用展示内容丰富**：规划15000平方米展示空间，设置四大核心展区：行业生态展区、AI城市应用展区、无人驾驶展区、创新前沿展区，徐汇滨江额外配套AI人文艺术体验区，集中展示L4级以上无人驾驶系统、全球首发AI“黑科技”产品。
3.  **主题活动多元务实**：设置50场同期会议，包含8月31日的AI开发者日、行业首创成果发布会、SAIL奖发布、战略咨询专家委会议、AI应用方案全球揭榜、投融资对接会等特色活动，预计专业听众达20000人次。
4.  **智能体验全面落地**：打造“1+N”智能化会务体系，集成AI新闻主播、实时翻译、智能会议助手、5G直播、机器人服务等应用，同时在会场周边落地无人银行、智慧零售等民生AI场景，浦东新区打造覆盖8大应用场景的“城市AI生活新画卷”，徐汇滨江打造融合艺术与科技的活力应用现场。
