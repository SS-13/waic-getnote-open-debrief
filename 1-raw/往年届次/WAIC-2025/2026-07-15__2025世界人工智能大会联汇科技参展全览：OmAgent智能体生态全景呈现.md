### 📌 WAIC 2025大会基础概况

本届**世界人工智能大会（WAIC 2025）**核心信息如下：
| 项目 | 详情 |
| :--- | :--- |
| **举办时间** | 展览期7月26日-29日 |
| **举办地点** | 主会场覆盖上海世博中心、上海世博展览馆 |
| **大会主题** | 「智能时代 同球共济」 |
| **核心目标** | 塑造具备广泛共识的人工智能全球治理框架，推动AI向善普惠发展 |
| **联汇科技展位** | 上海世博展览馆H1馆C430 |

联汇科技是连续三年深度参与WAIC的AI行业先锋，本届以「技术平台、行业应用、开源生态」三大维度为核心，打造未来智能体沉浸式体验展区。

### 🚀 技术平台创新跃迁：OmAgent智能体平台

联汇科技依托自研多模态大模型，推出**业界首个支持多模态感知融合的具身智能体构建系统——OmAgent智能体平台**，突破传统AI应用落地壁垒：
1.  **核心能力**：提供从感知接入、认知决策到行动执行的端到端完整框架，支持音、视、图、文全维度连接与解析，可对接摄像头、机器狗、无人机等各类智能设备。
2.  **落地场景**：已在工地、公安、电力、零售等多个行业落地，覆盖安全巡查、低空经济、合规检查、周界安防等任务，可实现视频检索、行为分析、监控告警、数据自动解读撰写等智能化功能。
3.  **应用广场矩阵**：平台内置9类开箱即用的数智员工助手，覆盖多行业刚需场景：
    - 工地安监助手、合规检查助手、低空巡检助手
    - 机房值班助手、无人零售助手、企业咨询助手
    - 周界安防助手、政务咨询助手、企业培训助手
4.  **现场体验**：观众可通过实时互动，直观感受平台指数级拓展力，体验跨领域场景智能化边界重构的技术能力。

### 🤖 具身智能应用实景落地

OmAgent具身智能应用作为新一代具身智能的“大脑”，可赋能各类智能载体实现无缝互联与协同作业：
1.  **核心特性**：设备接入后自动完成视频采集、协同巡检等任务，原生支持文本、语音自然指令响应，具备**「即插即用」零模型训练部署**的行业领先能力。
2.  **现场体验区亮点**：
    - 以机器狗、Homer AI助视眼镜等产品为载体，完整动态演绎“感知-认知-决策-行动”的智能闭环。
    - 现场展示的赋能机器狗可实现“听得懂，找得到，撞得到”，直观呈现多模态感知交互、任务自主拆解、实时环境决策的卓越性能。
3.  **三大标杆应用**：
    | 应用名称 | 适配载体 | 核心场景 |
    | :--- | :--- | :--- |
    | OmAgent低空大脑 | 无人机 | 铁路巡检、电力巡查等低空作业场景 |
    | OmAgent机器狗应用 | 机器狗 | 工业厂区特种巡检、复杂环境作业 |
    | OmAgent安全巡检 | 智能监控终端 | 园区安防、周界异常预警 |

### 🌐 开源社区生态共建

联汇科技秉持“技术开源、生态共建”战略，通过开放核心AI能力降低行业开发门槛：
1.  **开源成果**：已在GitHub开源OmAgent、VLM-R1等多个创新项目，构建覆盖基础模型、开发工具、应用框架的全栈开源体系。
2.  **生态价值**：为开发者提供从科研探索到商业落地的全链路开放创新支撑，赋能开发者高效开发创新型智能体应用，共同推动AI技术普惠普及。
3.  **官方入口**：
    - 联汇科技官网：www.hzlh.com
    - 开源社区地址：www.github.com/om-ai-lab
