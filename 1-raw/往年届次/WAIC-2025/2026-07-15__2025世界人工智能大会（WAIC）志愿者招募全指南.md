### 🏆 WAIC 2025 大会核心概况

**大会基础信息**
- 本届是WAIC创办以来的**第8届**，此前七届累计汇聚超过6550位国际顶级科学家、专家学者、企业家、投资人、政府官员等各界行业领袖，是全球人工智能领域的标杆性年度盛会。
- 举办时间：**2025年7月26日-7月28日**
- 大会核心板块：涵盖高端论坛、展览展示、评奖赛事、应用体验、投资孵化等多元内容，为全球AI从业者搭建科研成果分享、行业经验交流、合作机会探索的核心平台。
- 长期发展规划：后续WAIC将持续延伸品牌影响力，定期输出前沿AI资讯，强化创投孵化与产业对接能力，推进AI普惠教育落地，成为推动全球科技创新、产业进步、社会责任落地的人工智能领域核心引擎。

### 📋 志愿者招募核心信息

本次大会计划招募**400名优秀志愿者**，志愿者将提前深度参与WAIC 2025的各项服务保障工作，近距离接触全球AI行业前沿内容。

#### 岗位组别明细

| 岗位组别 | 核心工作职责 |
| :--- | :--- |
| **媒体组** | 对接大会各类媒体，响应媒体咨询问题，配合完成媒体接待相关工作 |
| **签到组** | 负责现场咨询引导、证件发放、观众入场查验等流程类工作 |
| **服务组** | 承担场馆内不同功能分区的访客指引服务 |
| **物料组** | 负责场馆内各类后勤物资的管理、配送与补给工作 |
| **机动组** | 统筹后勤工作整体调度，灵活应对现场突发问题，衔接配合各工作组完成任务 |

#### 工作时间与地点安排

| 工作时段 | 对应工作地点 |
| :--- | :--- |
| 2025年7月7日-7月29日 | 媒体组专属办公区 |
| 2025年7月26日-7月28日 | 世博中心 |
| 2025年7月26日-7月29日 | 世博展览馆 |

### ✅ 志愿者招募要求与权益

#### 招募准入条件
1.  身份要求：年满18周岁的在校大学生，2025年7月常驻上海；
2.  服务素养：形象端庄，能够为所有嘉宾提供周到友好的服务；
3.  能力要求：学习能力出色，可在培训阶段熟练掌握岗位所需的全部技能知识；
4.  优先条件1：英文听说读写流利，语言表达能力优秀，具备良好的沟通推介能力；
5.  优先条件2：媒体相关专业背景，或拥有相关岗位工作经验。

#### 志愿者专属收获
1.  获得深度参与世界级AI盛会的实践经历，积累行业视野与服务经验；
2.  颁发WAIC 2025大会官方专属志愿者证书；
3.  结识来自各领域的优秀同行伙伴；
4.  参与干货满满的专业岗前技能培训；
5.  表现优异者可获得额外丰厚实质回报。

- 本次招募面向在沪在校大学生，7月全程驻留上海是硬性要求，外地申请者需提前规划行程确保符合时间要求。
- 大会除志愿者招募外，还开放了公众购票通道，普通AI爱好者也可通过购买早鸟票参与到这场全球AI行业盛会中。
- 往届WAIC志愿者的服务场景覆盖国际访客接待、AI互动体验区辅助、场馆人流引导等多个环节，能够近距离接触全球前沿AI应用成果与行业领军人物。
