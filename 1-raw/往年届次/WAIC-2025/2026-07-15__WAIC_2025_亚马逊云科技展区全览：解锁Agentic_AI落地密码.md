### 🎯 核心定位：Agentic AI成为本届展区核心主角

亚马逊云科技作为全球云计算先行者，将在本次WAIC 2025完成纽约峰会新品的国内抢先剧透，聚焦主动规划、可执行复杂任务的“数字伙伴”形态，将Agentic AI打造为企业智能化的核心引擎，面向不同技术能力的用户快速交付AI能力，落地高效生产力。

#### 四大Agentic AI基础技术方向

展区锚定AI落地的四大关键技术环节，覆盖从选型到落地的全流程：
1.  **Agentic AI构建**：覆盖从专业开发者到业务人员的全人群，提供从零起步全托管、企业内嵌、开源自建三类构建路径，完整展示搭建逻辑、调用流程与工具清单，解决选型决策难题。
2.  **模型定制化**：面向企业独有知识体系与数据资产，现场演示模型蒸馏、微调、剪枝等主流策略，在保障效果的同时控制成本与模型规模，将通用大模型转化为企业专属AI。
3.  **RAG（检索增强生成）**：依托Amazon Bedrock的向量数据库与文档索引能力，让大模型成为适配企业业务的“专属知识库”。
4.  **多模态能力**：覆盖文本、图像、音视频等全类型信息，实现多模态输入的统一理解与生成输出，通过滚动演示与互动装置直观展示落地效果。

### 🔧 两大核心基石产品

展区重点展示Amazon Bedrock与Amazon Nova两大技术底座，降低企业构建生成式AI方案的门槛：
1.  **Amazon Bedrock**：为企业提供便捷的生成式AI应用构建与扩展路径，集成多家头部AI厂商的高性能模型，支持企业按需选择适配模型，灵活平衡成本与性能，大幅缩短生成式AI项目的落地周期。
2.  **Amazon Nova模型家族**：全系主打高性价比，覆盖三大产品序列：
    - 理解类模型：包含Micro/Lite/Pro/Premier四个档位，是图像识别、视频分析等多模态场景的理想选型；
    - 创意类模型：包含Amazon Canvas、Amazon Reel，支持通过文本或图片提示低成本生成高品质图像、视频内容；
    - 语音类模型：代表产品Amazon Sonic，可实现类人实时语音对话，支持多轮交互、函数调用与丰富音色自定义。

### 📌 九大落地场景全景呈现

展区将通过9个贴近日常业务的真实场景，直观展示生成式AI的落地价值：
| 场景名称 | 核心能力 |
| :--- | :--- |
| 智能内容创作 | 辅助文案生成、创意设计，激发内容产出灵感 |
| 智能开发助手 | 依托Amazon Q Developer实现代码自动生成、错误诊断、测试建议，成为开发者编程搭档 |
| 智能学习场景 | 自动梳理知识、生成复习计划，打造随身专属AI家教 |
| 办公知识助手 | 自动完成会议纪要、文档撰写、方案提炼，降低办公事务负担 |
| 智能翻译中心 | 覆盖多语种、专业术语场景，实现全场景实时翻译，打破语言壁垒 |
| 客服智能应答 | 7×24小时全天候响应，结合企业知识库与语义理解能力，精准回应用户咨询 |
| 内容审核系统 | 自动识别图文视频中的敏感内容，秒级拦截风险信息，守护品牌合规底线 |
| 数字人与虚拟角色 | 支持出镜讲解、在线直播、虚拟导览，打造高互动性的新一代品牌代言人 |
