### **🏆 WAIC 2025大会基础概况**

本届大会全称为**2025世界人工智能大会暨人工智能全球治理高级别会议**，主题为「智能时代 同球共济（GLOBAL SOLIDARITY IN THE AI ERA）」，核心定位是汇聚全球AI前沿力量，打造全球AI浪潮第一现场。
- 举办时间：2025年7月26日-7月28日
- 举办地点：中国上海
- 官方购票通道：可通过大会专属二维码完成购票，参与全程大会活动。

### **🤝 核心生态论坛：智造未来-先进技术赋能制造业转型升级**

该论坛是WAIC 2025生态板块的重磅专场，聚焦中阿制造业数字化转型合作，核心信息整理如下：
| 项目 | 详情 |
| :--- | :--- |
| **举办时间** | 2025年7月28日 09:00—12:30 |
| **举办地点** | 上海世博展览馆1B号会议室 |
| **核心主题** | 先进技术驱动的制造业转型与生态构建 |
| **主办单位** | 阿联酋投资部、阿联酋中国创新中心 |
| **协办单位** | 声通科技股份有限公司 |

#### 论坛核心议题与亮点
1.  **政策与战略解读**：阿联酋投资部官员将分享「阿联酋国家投资战略下的先进制造发展」，明确制造业是阿联酋先进技术国家战略落地的核心支柱。
2.  **技术落地实践**：围绕政策引导、本地化生产、人才和算力等关键要素，共商技术落地与产业生态构建的落地路径。声通科技董事长汤敬华将带来「可信智能交互的发展和实践」主题演讲，展现中国企业在AI底层技术与终端融合领域的全球竞争力。
3.  **全球供应链视角**：探讨全球供应链重塑背景下阿联酋的窗口价值，解读其成为全球先进制造与技术转移生态中枢的发展路径。
4.  **出海服务支撑**：迪拜官方认证孵化器「阿联酋中国创新中心」将为出海企业提供一站式业务对接与全方位孵化支持，助力中国企业高效落地中东市场。

#### 论坛核心参与生态矩阵

本次论坛聚合了中阿两地的全链条产业资源，形成完整的智造转型支撑体系：
| 资源类别 | 代表机构 | 核心价值 |
| :--- | :--- | :--- |
| 官方政策支持 | 阿联酋投资部、阿联酋驻沪总领馆 | 提供权威产业政策解读与落地保障 |
| 产业园区载体 | 阿联酋RAKEZ、THI园区（阿联酋首个国际工业园区） | 其中THI园区设立1亿美元先进制造专项基金，为产业落地提供空间与资金支撑 |
| 资本力量 | 阿联酋主权基金、家族办公室、PE+ Capital等 | 为AI与制造产业融合注入资本动力，多家机构已将THI园区、制造自由区纳入全球战略布局 |
| 中国代表企业 | 声通科技（可信智能交互领导者）、格创东智（工业大模型+AI平台解决方案提供商） | 分享中国AI制造技术的阿联酋落地经验 |
