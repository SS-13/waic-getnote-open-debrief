### **🏆 WAIC 2025大会基础概况**

本次大会全称为**2025世界人工智能大会暨人工智能全球治理高级别会议**，主题为「智能时代 同球共济」（英文：GLOBAL SOLIDARITY IN THE AI ERA），是全球AI领域的顶级行业盛会。
| 项目 | 详细信息 |
| :--- | :--- |
| **大会举办时间** | 2025年7月26日-7月28日 |
| **展览开放时间** | 2025年7月26日-7月29日 |
| **举办地点** | 中国·上海 |
| **展览地点** | 上海世博展览馆 |
| **核心定位** | 汇聚全球AI先锋力量，探讨技术跃迁、自我边界与未来文明的发展方向 |

### **📱 重磅参展产品：Rokid Glasses AR智能眼镜**

智能眼镜头部企业Rokid作为全球最早布局AR赛道的企业之一，深耕光学、声学、交互算法领域十余年，携全新量产新品Rokid Glasses亮相本次WAIC，展位号为**H3-D101**，该产品是其十余年技术积累的集大成者，标志着AR+AI技术从“可用”迈向“易用”的关键节点。

#### 核心参数与特性

| 维度 | 详细规格 |
| :--- | :--- |
| **整机重量** | 仅49克，实现“无感佩戴”体验 |
| **外观设计** | 一体化结构布局，将主板、电池等核心组件嵌入纤薄框架，外观接近传统眼镜，兼顾时尚性与实用性 |
| **显示技术** | 搭载衍射光波导技术，可在透明镜片上呈现清晰细腻的虚拟界面，实现虚拟信息与现实视野的无缝融合 |
| **影像配置** | 1200万像素专业级摄像头，支持高清拍照、视频录制，配备拍摄状态指示灯保障用户隐私 |
| **AI能力** | 深度整合通义千问、Deepseek、豆包等主流大模型，可实现物体识别、实时翻译、数学计算、日程提醒、天气预报、导航辅助等功能 |
| **场景价值** | 覆盖卡路里计算、跨国交流、健康管理、应用通知接收等多场景，成为用户生活与工作的智能助手 |

### **📢 大会衍生内容生态**

WAIC 2025推出首份官方刊物**《WAIC UP!》**，定位为「AI时代进化指南」，口号为“WAIC UP! WAKE UP MORE！”。该刊物邀请全球AI及跨领域先锋力量共同输出思考与智慧主张，旨在唤醒大众对AI技术价值的关注，共同勾勒以人为中心的未来智慧文明全景图，用户可通过专属绿色二维码解锁该内容。
