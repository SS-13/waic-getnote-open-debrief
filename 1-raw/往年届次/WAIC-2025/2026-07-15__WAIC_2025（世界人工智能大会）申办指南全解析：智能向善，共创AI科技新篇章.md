### **🏆 大会基础概况**

**大会背景**
世界人工智能大会（WAIC）自2018年起已连续七年在上海成功举办，是全球人工智能领域顶级的学术与行业交流、展览展示、合作洽谈核心平台，汇聚全球AI领域顶尖科学家、企业家、政府官员、国际组织代表、投资人及初创团队。2025年大会规模与层级持续进阶，定位为高端开放的国际交流平台，聚焦前沿话题、传递权威声音、荟聚全球智慧、策源创新思想，推动全球人工智能实现共商共建共治共享。

| :--- | :--- |
| **会议时间** | 2025年7月5日至7日 |

### **📋 会议论坛申办全流程**

#### 1. 重点话题方向

大会鼓励申办单位围绕12大核心领域策划选题，推动产学研用深度融合：
**智能算力、AI数据、大模型、具身智能、AI终端、AI for Science、AI赋能新型工业化、Fintech、人才、AI可持续、AI安全治理、AI国际交流与合作**。
申办主体面向具备承办基础的国内外领军企业、科研院校、行业组织、创新投资机构和媒体机构开放。

#### 2. 多元参与形式

大会提供分层级的会场选择，同时支持特色活动申办：
| 会场类型 | 容纳人数 |
| :--- | :--- |
| 小型会场 | 120-150人 |
| 中型会场 | 200-300人 |
| 大型会场 | 300-500人 |
| 超大型会场 | 500-800人 |
| 开幕式会场 | 1000人以上 |
除常规专业论坛外，还可申办闭门研讨交流活动、展区公开演讲、业内学术交流会等特色场景。

#### 3. 申办全步骤
1.  **提交申请**：填写《世界人工智能大会参会申请表》提交至对应板块负责人
2.  **填写方案**：按照大会提供的线上论坛方案模板完善并提交内容
3.  **会场预定**：预选申办论坛的举办时间与场地
4.  **方案遴选**：申办单位进行方案汇报，根据反馈调整内容直至通过评审
5.  **合作确认**：论坛方案落地，锁定场地并签订正式合作协议

#### 4. 关键时间节点

| 阶段 | 时间区间 |
| :--- | :--- |
| 论坛方案提交 | 2025年3月5日-3月14日 |
| 方案评审会 | 2025年3月15日-4月10日 |
| 确定申办单位 | 2025年4月11日-4月30日 |
| 落地筹备阶段 | 2025年5月1日-会前，完成签约、方案落地、观众组织及对外宣传 |

#### 5. 遴选与权责规则
- **遴选机制**：沿用行业公认的**“赛马”机制**，专家评审维度包含议题内容质量、嘉宾份量、国际嘉宾占比、国际组织参与情况、成果数量、策划亮点六大核心指标。
- **权责说明**：办会费用由申办单位自筹，大会提供嘉宾接待、会务服务、媒体宣传等基础性通用资源；获批论坛统一纳入WAIC 2025管理体系，接受大会品牌授权与统筹管理，申办单位负责方案起草、组织实施、内容把关、会务执行全流程，同时遵守大会在组织、内容、嘉宾、安全、外事、品牌宣传等方面的规范要求。

### **🎤 行业专家演讲申报说明**
- **征集对象**：全球人工智能领域顶尖思想领袖、资深高校教授、具备深厚专业积累的行业精英，覆盖AI技术研发、应用实践、学术研究等全赛道。
