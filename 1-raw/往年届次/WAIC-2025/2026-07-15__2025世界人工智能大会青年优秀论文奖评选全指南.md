### 🏛️ 活动背景概况

世界人工智能大会（WAIC）是经国务院批准举办的人工智能领域顶级国际盛会，此前已连续成功举办7届，2025年7月将在上海迎来第8届大会。
本次启动的「世界人工智能大会青年优秀论文奖（WAICYOP）」评选活动已成功举办5届，是面向全球AI领域青年学者的权威学术展示平台，2025年度评选的组织架构如下：
| 角色 | 参与单位 |
| :--- | :--- |
| 主办单位 | 世界人工智能大会组委会 |
| 指导单位 | 中国科学技术协会 |
| 承办单位 | 上海市科学技术协会、上海科技发展基金会、全球高校人工智能学术联盟 |
| 协办单位 | 上海市计算机学会、上海市人工智能学会、AI青年科学家联盟（梧桐汇） |
| 支持单位 | 上海人工智能实验室、中国工程院信息与电子工程学部、微软亚洲研究院 |

### 📋 核心评选规则

#### （一）奖项设置

本次评选共设置两类奖项，总获奖名额不超过20篇：
1.  世界人工智能大会青年优秀论文奖：获奖数量不超过10篇
2.  世界人工智能大会青年优秀论文提名奖：获奖数量不超过10篇

#### （二）参评硬性条件
1.  时间要求：参评论文需在2022年1月1日之后，于正规学术期刊或学术会议公开发表
2.  成果要求：在智能科学与技术相关领域的基础理论、应用研究、关键技术创新等方向取得突出成果
3.  年龄要求：论文第一作者在成果发表时年龄不超过40周岁

#### （三）覆盖论文领域

本次评选覆盖人工智能全赛道核心方向，包含但不限于：人工智能基础理论、机器学习、计算机视觉与模式识别、自然语言处理、智能芯片与系统、大模型、具身智能（智能机器人）、AI for Science等13个细分领域。

### 🛣️ 多元参评渠道

为覆盖全球不同类型的青年科研工作者，本次评选设置三类参评通道：
1.  单位推荐：由相关学术组织、高等院校、科研院所、科技企业直接推荐参评论文
2.  专家推荐：由人工智能相关领域正高级职称专家署名推荐参评
3.  个人自荐：符合参评条件的论文第一作者可直接向评审办公室自荐参评

### 🔍 全流程评选机制
1.  组织架构：设立由AI领域知名专家组成的评审专家委员会，下设评审执行委员会负责初评工作，评审办公室负责全流程日常组织实施
2.  评选阶段：整体分为初评、复评、终评三个递进环节，最终由评审专家委员会审定出全部获奖名单

### 📝 参评材料与申报安排

| 材料类型 | 提交要求 |
| :--- | :--- |
| 论文原文 | 参评论文的PDF版本 |
| 推荐表 | 单位推荐需加盖公章+负责人签字、专家推荐需专家本人签字，个人自荐无需提交 |
| 作者登记表 | 参评论文第一作者信息登记表PDF版本 |
| 补充材料 | 其他可佐证论文成果价值的相关证明材料 |

关键时间与渠道信息：
- 申报系统官网：www.waicyop.cn
- 申报截止时间：**2025年5月7日（星期三）**
- 官方文件下载渠道：WAICYOP评选官网、上海市科学技术协会官网（www.sast.gov.cn）
- 咨询联系方式：评审办公室设在上海市科学技术协会，可通过指定电话、邮箱对接工作人员咨询细节。

### 📌 配套生态服务

本次WAIC 2025除青年论文评选外，还同步推出多项配套活动：
1.  首发官方刊物《WAIC UP!》：定位为「AI时代进化指南」，邀请全球AI跨领域先锋分享前沿思考，探索技术跃迁、未来智慧文明的无限可能
2.  全维度活动申报通道：2025世界人工智能大会的论坛申办、展览早鸟报名、全球AI创新项目征集、WAIC CONNECT精准产业对接等板块均已同步开放申报。
