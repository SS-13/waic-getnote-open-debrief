### 📌 大会基础背景概览

首届世界人工智能大会于**2018年9月17日-19日**在上海成功举办，是全球顶级的人工智能交流合作平台。官方同步启动2018年大会高光时刻系列回顾，同时官宣**第二届世界人工智能大会将于2019年8月29日-31日，在上海世博中心&上海世博展览馆举办**，大会定位升级为“高端化、国际化、专业化、市场化、智能化”，将汇聚全球AI领域顶尖资源，为产业注入全新动能，驱动新时代高质量发展。

首届大会核心基础数据如下：
| 维度 | 具体数据 |
| :--- | :--- |
| 参会的图灵奖/诺奖级学术领军人物 | 50余人 |
| 参会产业界代表 | 100余人 |
| 参与展示的AI相关企业 | 超150家 |
| 总参会观展人次 | 20万 |

### 🏛️ 顶层重视与战略指引

国家及上海市各级主管部门对首届大会给予了高度重视与全方位支持，构建了清晰的AI产业发展顶层指引体系：
1.  **最高层战略定调**：习近平总书记为大会发来贺信，从战略全局高度阐明新一代人工智能发展趋势，明确“人工智能赋能新时代”的核心方向，传递中国愿与世界各国共同推动AI技术造福人类的开放态度。
2.  **主管部门部署落地**：刘鹤副总理亲临大会并发表重要讲话，明确中国AI产业发展核心路径：坚持需求导向、强化基础研究投入、激发市场主体创新活力、大力推进AI领域人才培养。
3.  **地方落地规划**：中央政治局委员、上海市委书记李强作开幕致辞，明确将人工智能列为上海优先战略选择，提出加快建设AI发展的“上海高地”；时任上海市市长应勇主持开幕式，围绕共享AI产业机遇、深化全球交流协作提出具体发展要求。
4.  **全域联动支持**：共有61家单位（覆盖国家部委、兄弟省市、央企、重点高校）、20余位省部级领导出席大会，形成跨层级、跨领域的协同推进格局。大会同期围绕AI对生产生活的影响，以及法律、安全、就业、伦理、政府治理等前沿议题展开系统性研讨。

### 🚀 首届大会核心成果全景

首届大会以**“人工智能赋能新时代”**为主题，设置论坛、展览、体验、大赛四大核心板块，坚持“高端化、国际化、专业化、市场化”办会方针，集中呈现全球AI技术前沿趋势，落地了一批标志性产业成果：
大会整体运营核心数据：举办1场主论坛、35场主题论坛及特色活动，吸引40多个国家的7.2万名专业嘉宾到场，总参会观展人次达20万。

#### 1. 打造AI产业风向标，聚焦前沿技术

大会首次集聚全球AI领域70余位“政产学研用投”全链条领军人物，其中中外院士50余人、重量级嘉宾超200位，海外嘉宾占比约40%。参会顶尖代表包括图灵奖得主Raj Reddy、诺贝尔化学奖得主Michael Levitt、AI泰斗Michael I. Jordan，以及李飞飞、吴恩达、姚期智等行业顶尖学者；同时谷歌、微软、亚马逊、英伟达、阿里、腾讯、百度、华为等全球头部科技企业核心负责人悉数到场并发表主题演讲。
大会现场发布全球AI产业地图、全球人工智能技术成熟度曲线、AI@SH行动报告等12份权威专业成果报告，成为当年AI产业发展的标杆性参考内容。

#### 2. 链接全球创新资源，构建产业载体

大会落地了一批高规格AI创新载体，快速推动全球创新要素向上海集聚：
| 载体类型 | 落地数量与具体项目 |
| :--- | :--- |
| 人工智能研究院 | 3个：亚马逊AWS研究院、微软上海暨微软-仪电研究院、科大讯飞（上海）研究院 |
| 人工智能创新平台 | 8个：京东、腾讯、华为及机器人、工控安全等方向创新平台 |
| 人工智能创新中心 | 10个：安谋、阿里巴巴（上海）、小鹏汽车、百度（上海）等创新中心 |
| 大会合作企业 | 13家战略合作伙伴、20家支持合作单位 |

同时140余家国内外顶级科技企业，围绕“AI+交通”“AI+健康”“AI+零售”“AI+金融”“AI+教育”“AI+智造”“AI+服务”7大场景，打造沉浸式体验展区，让参会者直观感受到AI技术落地的趋势。

#### 3. 完善产业生态体系，强化制度供给

大会通过联盟、基金、政策组合拳，构建完善的AI产业发展支撑体系：
-  成立5个创新联盟：包括全球高校人工智能学术联盟、全国人工智能创业投资服务联盟等，打通产学研协同链路；
-  设立4支产业基金：包括上海人工智能产业基金、G60科创走廊AI产业基金等，为AI创业项目提供资本支撑；
-  发布3项行业倡议：围绕人工智能法治建设、数据流通与个人信息保护、AI安全发展形成共识倡议；
-  出台专项扶持政策：正式发布《上海人工智能高质量发展22条实施办法》，为AI企业提供精准政策赋能。

### 🔮 第二届大会前瞻与长期发展方向

首届大会的成功举办为上海AI产业发展奠定了坚实基础，2019年举办的第二届世界人工智能大会，将以发挥AI产业“头雁效应”为核心目标，成为推动上海AI技术与经济社会协同高质量发展的全新机遇。
上海后续将持续放大大会的带动溢出效应，以推动AI与实体经济深度融合为主线，以提升AI科技创新能力为核心方向，全力打造全球领先的AI“创新策源高地、应用示范高地、制度供给高地、人才集聚高地”，全面提升城市核心竞争力，赋能实体经济升级与居民高品质生活。
