### 🏆 大会参展基础概况

2020世界人工智能大会（WAIC）于7月8日以线上展览形式开幕，7月11日正式落幕，是该大会首次采用云端办会模式。中国建设银行作为本次大会的**卓越合作伙伴**，以“智建美好 无界家园”为主题参展，是全场150+家参展企业中，AI+金融板块唯一被大会官方探营的企业。
本次大会整体线上参观人次达2,368,068，建行参展传播核心数据如下：
| 传播维度 | 核心数据 |
| :--- | :--- |
| 合作媒体数量 | 30+家（覆盖中央级、全国性、地方及新媒体平台，含人民网、新华网、中国新闻网等头部媒体） |
| 新闻总浏览量 | 100万+ |
| 线下联动网点数 | 300+个（上海市全量网点参与互动传播） |
| 整体曝光量 | 1000万+人次 |
| 大会官方排名 | 大会点赞榜前三 |

### 📱 三大云场景参展核心布局

建行践行金融科技“**始于技术，终于信任**”的核心宗旨，围绕“无界”核心概念，打造了覆盖五大方向的“AI+金融”服务体系：无界·便民、无界·助企、无界·运营、无界·出海、无界·家园，通过三大线上场景完成全维度展示。

#### 1. 云展览：16大科技展项全景呈现

采用海派特色3D场景化形式搭建线上虚拟展馆，覆盖从普惠民众到赋能企业、从对内智慧运营到跨境金融服务的完整业务生态，核心展项包括：
- 线上虚拟金融管家「智能班克」
- 扫码刷脸无介质办理业务的「智慧办理」
- 面向听障群体的智慧助聋服务平台「云翻译」
- 服务小微企业融资的「建行惠懂你」APP
- 智慧政务、智能社区、智能港湾等民生类科技服务

#### 2. 云直播：13项智能业务互动传播

围绕四大直播主题，由建行专业主播团队完成全业务线直播展示，直播间用户互动热度极高，刷屏点赞成为常态，核心展示业务包括：
| 直播主题 | 核心展示内容 |
| :--- | :--- |
| 特色网点 | 5G+智能银行 |
| 无界便民 | 建行手机银行APP |
| 无界助企 | 建行龙财富、小微快贷 |
| 无界家园 | 跨境快贷、跨境撮合、跨境e+、安心养老智慧服务平台 |

#### 3. 云会议：行业前沿深度发声

建行技术专家团队深度参与大会核心论坛，与全球AI领域顶尖科学家、企业家共探行业发展方向：
- 在「AI沙龙」板块，发布“AI+金融”标杆应用**智晟债券信用分析系统**，为债券市场频发的信用风险问题提供智能化解决方案
- 在「主题论坛」中发表《人工智能即服务设计及应用》主题演讲，前瞻性探讨AI技术未来落地路径

### 🔍 关键洞察与后续规划

本次参展是国有大行首次在全云端AI大会中完成全链路数字化品牌展示，实现了技术能力、普惠服务、品牌传播的三重突破。后续建设银行将持续落地“金融科技”战略，深化“AI+金融”场景探索，打造覆盖机构赋能、企业助力、大众普惠的全链条智能金融产品，构建“智建美好，无界家园”的开放金融生态。
