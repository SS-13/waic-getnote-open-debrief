### 📌 论坛基本概况
- **举办时间**：2020年7月10日
- **举办地点**：上海世博中心
- **所属活动**：2020世界人工智能大会（WAIC）云端峰会
- **核心定位**：聚焦青少年创新发展，聚力服务青少年拥抱和融入人工智能新时代，现场同步完成上海少年科学院人工智能分院成立、青少年人工智能科普读物发布两大重磅成果。

### 🌟 三大“青春云对话”亮点环节

本次论坛的互动环节打破次元壁、跨界融合，成为全场关注度最高的内容：
1.  网红主播李佳琦与虚拟偶像洛天依开展趣味“青春对话”
2.  “围棋天才”柯洁回顾自身与AlphaGo的经典人机大战经历
3.  奥运冠军王励勤品评乒乓球机器人Pong Bot（庞伯特）的技术特点

### 🎤 嘉宾核心观点汇总

#### 1. 技术与发展方向解读

| 嘉宾身份 | 核心观点 |
| :--- | :--- |
| 上海交通大学研究员、2019年求是杰出青年学者 卢策吾 | 当下大众可见的光鲜AI应用背后都依托多年技术积淀，这些应用仅展现了人工智能的冰山一角，大量未解决的科学、技术问题等待青少年“后浪”开拓探索。 |
| 中国科学院院士、上海交通大学副校长 毛军发 | 人总有一天要输给机器，大众需要建立相应心理预期；工业化时代以教师为主的教育体系，必须全面转型为智能化时代以学习者为核心的教育体系。AI三大基础要素为数据、算法、算力，我国在超算领域处于领先水平，发展高端人工智能必须充分依托人的大脑思考能力。 |

#### 2. 教育领域实践与理念分享

| 嘉宾身份 | 核心观点 |
| :--- | :--- |
| 黄浦区卢湾一中心小学校长 吴蓉瑾 | 作为上海市信息化标杆培育校，学校已将AI落地多个教学场景：校门口AI人像辨识系统可对长时间逗留的非校内人员自动向保安预警，筑牢校园安全防线；搭载AI技术的手写笔可无感知采集学生全学科作业数据上传云端，同步存入个人学习档案，实现“去屏化”教学。明确强调AI只能作为教学辅助工具，教育工作者必须始终占据主导地位。 |
| 上海纽约大学名誉校长 俞立中 | 教育的本质是人与人互动、感化的过程，技术永远无法替代学校教育。青少年人工智能教育分为三个递进层面：一是建立AI基础概念，激发兴趣与想象力；二是开展AI实践，引导青少年探究人类思维模式；三是鼓励青少年挖掘AI多元应用场景。 |
| 上海大数据联盟秘书长、上海超算中心主任 周曦民 | 希望青少年找到适配自身的AI应用“按钮”，借助技术提升学习生活质量，青少年最核心的成长要素是拥有独立想法与思路。AI自动识别作业对错、提炼知识点等生活化场景，能让青少年直观感受AI的独特魅力。 |
| 上海科技馆馆长 王小明 | 场馆教育具备受众基数大、个性化需求突出的特点，AI技术可完美适配科技馆科普教育的高质量发展需求；AI时代最核心的变革是思维升级，未来科技馆将重点探索科技与人文知识深度融合的研发方向。 |
| 深兰科技创始人、深兰科学院创始院长 陈海波 | 目前AI在教育领域落地存在核心技术层面的瓶颈，并非教育本身的问题，AI发展仍存在两大“天花板”，同时针对“虚拟老师”的落地可行性给出了专业分析。 |
