### 🏛️ 峰会基本概况

2020世界人工智能健康云峰会是2020世界人工智能大会的专题云端峰会，于**2020年7月10日-11日**在上海以线上形式举办，主题为**智联世界·共享健康（Intelligent Connectivity, Shared Health）**。
本次峰会的组织架构层级清晰，汇聚了全球多领域核心参与方：
| 角色 | 参与主体 |
| :--- | :--- |
| 指导单位 | 联合国世界卫生组织（WHO）、联合国国际电信联盟（ITU） |
| 主办单位 | 世界人工智能大会组委会办公室 |
| 承办单位 | 上海市经济和信息化委员会、中国信息通信研究院、国家卫生健康委医疗管理服务指导中心、上海市卫生健康委员会 |
| 协办单位 | 中国信息通信研究院华东分院、工业互联网创新中心（上海）有限公司、互联网医疗健康产业联盟、ITU&WHO医疗健康人工智能焦点组等7家机构 |
| 战略合作伙伴 | GE医疗 |
| 战略合作媒体 | 海星健康 |

峰会汇聚全球AI领域专家、学者、产业界人士及监管部门代表，聚焦后疫情时代人工智能在公共卫生领域的新应用、新问题、新思路，围绕健康产业发展趋势、技术创新、落地应用等核心议题展开深度研讨。

### 🎤 核心嘉宾与重磅观点

本次峰会嘉宾阵容覆盖国际组织高管、国内监管部门负责人、顶尖院士、临床专家及头部企业高管，核心发言亮点如下：
1.  **国际与监管致辞嘉宾**：WHO首席信息官Bernardo Mariano、ITU标准局副局长Reinhard Scholl、国家卫健委规划发展与信息化司司长毛群安、工信部科技司副司长朱秀梅等先后致辞，从全球协作与产业政策层面为AI+医疗发展指明方向。
2.  **院士专家团**：李兰娟、毛军发、董家鸿、宁光、葛均波、戴尅戎6位中国工程院/科学院院士，以及加拿大国家工程院院士宋梁到场分享，覆盖传染病防控、医学工程、精准医疗等多个细分领域。
3.  **战疫双侠高峰对话**：复旦大学上海医学院副院长吴凡提出从大数据分析维度强化重大突发公共卫生事件检测预警的专业建议；张文宏教授明确提出“大数据的产生不是剥夺人类的需求，而是做增量”的核心判断，为AI医疗数据应用划定价值导向。

### 📢 峰会重磅发布与成果落地

本次峰会集中落地了多项行业标志性成果，推动AI医疗产业从概念走向实体：
- 揭牌成立**中国人工智能产业发展联盟AIIA医学人工智能专委会**，搭建跨产学研的行业协作平台。
- 启动**MedNet全球医学AI科研平台项目**，打通全球医学AI科研资源共享通道。
- 正式发布《2020世界人工智能医疗产业发展白皮书》，梳理行业发展现状与未来趋势。
- 发布人工智能医疗器械创新合作平台多项成果，同步公开工信部人工智能抗疫产品（肺炎CT辅助诊断产品）测试结果，为抗疫AI产品落地提供官方认证依据。

### 🦠 后疫情时代AI+健康产业走向

2020年新冠疫情全球大流行成为AI医疗产业加速发展的关键催化剂，峰会各方形成多项行业共识：
1.  **AI在抗疫中的实战价值**：李兰娟院士总结AI在疫情防控中覆盖公共卫生研判、基因检测、药物研发、互联网医院、情绪管理等多个场景，发挥了不可替代的支撑作用。
2.  **企业抗疫落地案例**：
    - 联影智能通过海陆空三维驰援体系，依托医疗设备、影像设备和医疗AI软件从云端支撑疫情防控。
    - 点内生物将新冠CT读片时长从传统15分钟压缩至1分钟，大幅提升临床诊断效率。
3.  **产业发展共识**：全球医药巨头纷纷加码AI医疗，以更低资本投入、更短研发周期、更低风险实现产业价值最大化；AI已成为应对突发公共卫生事件、强化公共服务体系的核心支撑力量，我国AI与医药器械的深度融合将引发全球产业新浪潮。上海市卫健委副主任张浩指出，疫情激发了大量公共卫生信息技术应用需求，AI体温检测、大数据流调、重点人群筛查等应用已快速落地推广。

### 🔄 AI变革健康产业全链条

AI技术正从临床效率、基层医疗、产业生态等维度重塑健康产业全链路：
1.  **助力分级诊疗强基层**：针对我国分级诊疗“强基层”的核心医改目标，安德医智提出通过智慧医疗技术快速提升基层医院诊疗能力，突破传统医生培养周期过长的瓶颈。
2.  **细分场景落地成效**：
    | 企业/场景 | AI落地实际价值 |
    | :--- | :--- |
    | 珍灵医疗（消化道早癌筛查） | 2019年主动发现99例早癌，为国家节省近30万相关医疗费用 |
    | 森亿医疗（智慧医院方案） | 帮助三甲医院医护每月节省600小时工时，深静脉血栓诊疗成本下降37% |
    | 傅利叶智能（康复治疗） | 破解我国康复治疗师30万缺口难题，未来可实现1名治疗师带领10台康复机器人提供个性化精准康复服务 |
3.  **巨头生态布局**：GE医疗加速向AI医疗转型，2019年推出Edison（爱迪生）数字医疗智能平台，联合国内本土企业共建数字医疗应用生态，提出“找到行业真实痛点、落地解决问题才是生态最大价值”的务实发展理念。

### 🚀 AI+医疗的广阔发展空间

峰会从技术融合、产业规模、上海落地实践等维度，勾勒出行业未来的发展蓝图：
1.  **AI赋能医疗决策的三大路径**：西门子医疗Wido Menhardt博士提出，AI可从三方面支撑明智医疗决策：提升临床与运营效率、自动化标准化辅助临床决策改善患者预后、辅助患者管理推动远程医疗与协作医疗落地。
2.  **跨技术融合趋势**：5G与AI的深度融合将催生更多医疗新模式，行业预判5年后大量云化医疗服务可达到基础医生诊疗水平，覆盖更多偏远地区患者。
3.  **产业规模预判**：根据国务院《新一代人工智能发展规划》，2020年我国人工智能核心产业规模目标超过1500亿元，其中医疗人工智能占比将达到全行业的五分之一。
4.  **国内产业格局**：截至2020年国内已有114家医疗智慧企业，形成北京、长三角、珠三角三大产业集群，覆盖疾病筛查预测、医疗影像诊断、病例文献分析、新药发现等全细分领域。
5.  **上海先行实践**：2019年底上海率先启动AI应用场景建设实施计划，峰会披露第二批三大标杆示范场景：徐汇区心血管全周期智能服务平台、瑞金医院全场景“认知”智慧医院、上海儿童医学中心AI儿科分级诊疗体系，为全国AI医疗落地提供城市样本。
6.  **行业发展判断**：尽管医疗场景复杂度高，AI医疗整体仍处于发展初期，但“AI+人类专家”的新型诊疗模式将全面超越传统模式，未来在慢病管理、患者随访等场景拥有广阔想象空间，最终将革命性改变现有医疗服务与管理形态。
