### **🏆 大会基础概况**

2020世界人工智能大会（WAIC）云端峰会由上海市人民政府主办，是当年全球AI领域的标杆性行业盛会，核心信息如下：
| 项目 | 详情 |
| :--- | :--- |
| **举办时间** | 2020年7月9日-7月11日 |
| **举办形式** | 线上为主、线上线下结合的云端模式 |
| **大会主题** | 智联世界 共同家园（INTELLIGENT CONNECTIVITY INDIVISIBLE COMMUNITY） |
| **举办地点** | 中国上海 |
| **参展规模** | 约150家企业线上参会参展，覆盖微软、亚马逊、阿里、腾讯、华为、科大讯飞等头部AI企业，以及阿斯利康、高通等AI深度应用企业 |

### **📌 深兰科技核心战略升级**

作为上海本土AI独角兽企业，深兰科技在本届大会完成新一轮业务升级，明确将**四大主力赛道**作为未来核心发力方向：
1.  工业智能化
2.  农业智能化
3.  城市智能化
4.  AI生物安全

### **🚀 重磅新品发布：MetaMind自动化机器学习平台**

本次大会上深兰科技正式推出自研的MetaMind自动化机器学习平台，是其赋能产业升级、助力数字新基建的核心产品，核心参数与优势如下：
| 维度 | 详细说明 |
| :--- | :--- |
| **技术底座** | 集成深兰自研深度学习、机器学习、图像分类/检测/分割、文本分类/匹配、序列标注、时序预测等全栈AI技术 |
| **研发背景** | 背后团队曾拿下十余个机器学习、计算机视觉、自然语言处理、语音领域的世界级算法赛事冠军 |
| **核心效能** | AI应用开发周期缩短80%以上，人力成本节约90%以上，无需专业算法工程师参与建模，注册账号即可自主使用 |
| **性能表现** | 最终产出的AI模型性能不低于专业算法工程师人工建模的水平，大幅降低产业AI落地门槛 |

### **🔍 四大赛道落地成果深度拆解**

#### 1. 工业智能化：新基建浪潮下的智造者

深兰科技创始人陈海波在大会论坛中明确提出核心观点：新基建的核心是**数字基建**，人工智能是数字基建的核心支撑底座，将为全行业的数字化转型、智能升级提供底层能力。
深兰工业智能化板块的两大核心落地方向：
- 质检识别智能化：实现高精度质量检测与全区域安全管理，支持本地化AI模型一键执行
- 字符识别智能化：在食品、医药、物流等多行业场景落地，针对身份证、车票、银行卡、产品包装等识别场景，达成100%识别准确率、0.2秒/张的识别速度。

#### 2. 农业智能化：AI赋能智慧农业升级

围绕农业生产全链条打造智能化解决方案：
- 农作生产无人化：搭载AI视觉、自动导航等技术的智能农机，可实现复杂环境下长时间无人作业，作业精度可达<100μm
- 农业技术服务平台化：打造面向农业从业者的自动机器学习开放平台，实现“人人可用、人人参与、人人共享”的农业AI生态
- 土壤改良智能化：依托AI和生物科技实现大面积土壤提质，助力绿色可持续农业发展。

#### 3. 城市智能化：构建智慧运行体系

覆盖城市运行的核心民生场景：
- 交通智能化：面向智能汽车、智慧交通行业，提供网联化、智能化、电动化趋势下的领先CVL（计算机视觉）技术方案
- 环卫智能化：融合自动驾驶、计算机视觉、深度学习技术，为室内外消毒清洁场景提供成熟AI产品与解决方案。

#### 4. AI生物安全：疫情下的硬核技术突破

深兰在本届大会展出的基于三代测序的核酸检测一体机，曾在大会AIWIN医疗赛道夺魁，是疫情期间AI技术落地医疗领域的标杆成果：
- 核心能力：融合AI与三代测序技术，不仅可输出常规病毒阴阳检测结果，还能提供样本病原物种信息、病毒浓度数据，可实时跟踪病毒变异情况
- 独特优势：具备广谱病原体识别能力，除已知病毒外还可识别未知相似病毒，检测速度、准确度大幅提升，设备便携不受场地限制
- 应用价值：为疾病防控、公共卫生安全领域提供全新技术路径，推动AI医疗普惠落地。
