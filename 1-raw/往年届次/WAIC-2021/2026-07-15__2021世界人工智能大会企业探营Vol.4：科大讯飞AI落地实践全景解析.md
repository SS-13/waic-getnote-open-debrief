### 🏛️ 2021 WAIC（世界人工智能大会）基础概况

本届大会是“十四五”开局之年的顶级AI行业盛会，核心信息如下：
| 项目 | 详情 |
| :--- | :--- |
| **大会主题** | 智联世界 众智成城 |
| **举办地点** | 中国上海 |
| **会议时间** | 2021年7月8日-7月10日（上海世博中心SECC） |
| **展览时间** | 2021年7月7日-7月10日（上海世博展览馆SWECC） |
| **办会方针** | 高端化、国际化、专业化、市场化、智能化 |
| **核心定位** | 聚焦城市数字化转型战略，汇聚全球顶尖科学家、企业家、政府官员等多元主体，搭建国际科创协作平台，助力打造人工智能世界级产业集群 |
| **配套服务** | 上线云平台2.0，支持用户注册登录观看大会精彩回放 |

本次大会推出「企业探营之旅」系列活动，以**AI让城市更有爱**为核心主题，实地探访头部AI企业的落地应用场景，挖掘一手行业资讯，本次探访对象为具备“能听会说能理解”技术特性的科大讯飞。

### 📊 科大讯飞核心AI落地场景实践

科大讯飞以解决社会刚需为技术研发出发点，围绕民生服务与城市治理打造多维度落地产品，核心布局覆盖四大领域：

| 落地领域 | 核心产品/方案 | 落地价值与应用数据 |
| :--- | :--- | :--- |
| **智慧教育** | 因材施教解决方案 | 可智能批改作业、精准分析学生学情，生成个性化习题避免无效重复训练，为师生减负。目前已覆盖中国31个省级行政区，深度合作38000余所学校，服务超1亿师生。 |
| **AI公益** | 讯飞输入法方言保护计划 | 依托智能语音技术推动方言数字化留存，以立体形式保护乡音文化，是AI技术赋能文化传承的典型实践。 |
| **智慧医疗** | 智医助理全科辅助诊疗系统 | 针对性解决国内优质医疗资源匮乏、基层诊疗能力不足的痛点，大幅提升基层医生电子病历规范率与合理诊断能力，减少不合理用药与过度治疗，补齐基层医疗服务短板。 |
| **智慧城市** | 城市超脑 | 打通数据从汇聚到应用的“最后一公里”，将海量城市数据转化为治理工具，辅助宏观决策与高效治理，实现城市“能感知、会思考、可进化、有温度”的运行目标。 |

#### 标杆民生案例：天津“银发”智能服务平台

该平台聚焦老年群体关爱场景，通过家庭水、电、燃气使用数据搭配智能感知设备，远程识别老人日常起居状态：例如可通过用水用电数据判断老人是否正常起床、洗漱、用餐。当监测到异常情况时，平台将自动联动家属、社区网格员完成核实与现场处置，最大程度降低老年人意外事件发生概率。

### 🚩 产业战略方向

2021年作为“十四五”开局之年，科大讯飞将**新基建**作为核心产业发展战略方向，依托AI技术赋能城市数字化转型，驱动城市智能化升级，最终实现“让世界享受AI的乐趣”的企业愿景。
