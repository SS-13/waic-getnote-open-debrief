### 🏆 活动基础概况

本次论坛是**2023世界人工智能大会（WAIC）**的核心重点活动之一，完整信息如下：
| 项目 | 详情 |
| :--- | :--- |
| **论坛主题** | 算网共生 数智未来 |
| **举办时间** | 2023年7月6日 |
| **举办地点** | 上海世博中心430会议室 |
| **指导单位** | 世界人工智能大会组委会办公室 |
| **主办单位** | 中国联合网络通信集团有限公司 |
| **出席核心嘉宾** | 上海市经济和信息化委员会副主任张英、上海市通信管理局副局长贺丰、上海联通党委书记&总经理沈洪波 |

论坛以“云、网、算、安、数、用”一体化算力网络为核心底座，目标是构建自主可控、算力聚合、智算共享的算力产业链，推进上海算力产业发展，赋能千行百业数字化转型，夯实数字中国建设基座。

### 📜 政策与行业背景
1.  **国家顶层指引**：2023年2月27日中共中央国务院印发《数字中国建设整体布局规划》，明确将夯实数字中国建设基础作为核心任务，算力被定义为数字经济时代的关键生产力，是数字产业化的核心构成、产业数字化的赋能关键。
2.  **地方落地导向**：上海市政府密集发布算力建设指导意见及人工智能利好政策，目标将上海打造成为全国算力供给最充沛的城市之一。
3.  **企业响应定位**：上海联通在中国联通新发展战略牵引下，锚定“数字信息基础设施运营服务国家队”职责使命，主动对接网络强国、数字中国建设的国家战略要求。

### 🤝 核心产业动作：“算筑申城”上海市算力产业联盟成立

上海联通牵头产业链各方正式发起成立该联盟，是本次论坛的核心里程碑事件：
- **联盟定位**：搭建算力产业创新合作与促进平台，聚集算力产业中坚力量，推动算力发展从“建好算力”向“用好算力”升级，实现数字信息基础设施、数实融合应用、数字技术融合等多维度创新合作，支撑上海国际数字之都建设。
- **首批核心成员**：覆盖算力芯片、云服务、互联网头部企业三大赛道，包括上海联通、沐曦、天数智芯、摩尔线程、燧原科技、寒武纪、京东科技、华为、阿里、商汤、百度、腾讯等行业头部主体。

### 📊 上海联通算力布局核心指标

上海联通深度服务“东数西算”国家战略，已形成全国第一梯队的算力供给能力：
1.  **多元算力体系**：建成覆盖“通用、智算、超算”的全品类算力供给体系。
2.  **智算规模目标**：2023年底智算规模将达到**420Pflops**，算力规模位居全国前列。
3.  **分层算力架构**：形成以5个大型数据中心为核心、区域数据中心为辅助的梯度算力布局。
4.  **前沿布局方向**：正在推进独立智算中心建设，加速国产算力芯片的现网落地应用，自主升级算网大脑实现算力资源智能调度，构建以算力为核心的新型信息基础设施。

### 🎯 两大重磅战略合作签约

论坛现场上海联通与两家产业链伙伴完成战略签约，精准覆盖大模型应用与信创算力两大核心赛道：
| 合作方 | 合作核心方向 | 价值目标 |
| :--- | :--- | :--- |
| **京东科技** | 围绕大模型开展深度协同，依托运营商大数据、大计算优势，结合京东大模型基础能力，攻关通用大模型核心技术，搭建多模态大模型的数字政府、数字城市应用体系 | 为城市智能化决策提供核心技术引擎，赋能数字政务高质量发展 |
| **沐曦** | 在信创产业、算力中心、算力网络、云平台算力建设、数字化应用等领域全面合作 | 打造稳固算力基础设施，共建安全可靠的信创产业底座，形成开放普惠的国产算力应用生态，保障国家信创产业自主化与数字经济高质量发展 |

### 🖼️ 大会同期成果展示

在2023 WAIC世博展览馆的上海联通独立展位中，集中对外展示两大核心内容：
1.  以新一代智算为代表的多元算力体系、“网随算动”的先进算力网络技术。
2.  算力赋能千行百业的落地实践案例，覆盖医疗、交通、文旅等多个民生与产业领域。

### 🔮 未来发展规划

上海联通将持续以“国家队、主力军、排头兵”的责任定位，深度融入上海城市经济社会发展，为数字经济、数字社会、数字政府建设输出“第一算力引擎”，支撑上海建设具有世界影响力的社会主义现代化国际数字之都，助力中国式现代化建设。
