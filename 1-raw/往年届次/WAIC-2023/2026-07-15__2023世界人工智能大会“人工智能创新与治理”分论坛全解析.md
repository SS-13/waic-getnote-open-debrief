### 🏆 论坛基础概况

本次分论坛是2023世界人工智能大会（WAIC，大会主题“智联世界 生成未来”，举办时间2023.07.06-07.08，地点上海）的核心分论坛之一，于7月7日上午在上海世博中心举办，由**南方都市报**联合**清华大学人工智能国际治理研究院**共同主办，核心目标是汇聚各界智慧，探索助推人工智能向善发展的可行路径。

### 📄 核心发布成果

本次论坛共发布两大重磅行业成果：
1.  **国内首份智库媒体发起的生成式AI治理倡议书**
    南方都市报联合近40位各界人士共同发布《生成式AI伦理与治理倡议书》，这也是国内首个由智库媒体牵头推出的生成式AI治理规范类倡议文件。
2.  **《人工智能医学影像伦理手册》**
    由中国科协-复旦大学科技伦理与人类未来研究院、上海人工智能实验室联合发布，填补了AI医学影像细分领域的伦理规范空白。

### 📋 《生成式AI伦理与治理倡议书》核心内容

#### 七大核心原则

涵盖确保安全、信息披露、人工把关、敏捷治理等七大维度，为生成式AI行业划定基础伦理底线。

#### 关键实操治理建议

| 建议方向 | 具体要求 |
| :--- | :--- |
| 内容标识规范 | 对生成式AI产出或编辑的信息，需添加公众可明确识别、不可删除的专属标识，逐步形成统一行业标准，与真实人工信息做明确区分 |
| 数据权益保护 | 模型训练数据来源必须合法，未经用户授权不得擅自使用人脸、指纹等生物识别信息，重点强化未成年人权益保护 |
| 用户救济机制 | 当AI生成内容引发诈骗、诽谤等损害用户利益的事件时，相关主体需主动保障用户财产、名誉权益，配套完善的权益救济渠道 |

#### 联署参与阵容

倡议书获得近40位各界代表联合署名支持，覆盖全国政协委员、高校学者、科技企业代表、专业律师等群体，还首次引入公众人物参与联署：知名演员蓝盈莹、歌手炎明熹共同发声，呼吁全社会反对技术滥用，推动AI向善发展。

### 💡 与会嘉宾核心观点汇总

论坛汇聚了国内外跨领域权威嘉宾，从法治建设、全球协作、产业实践等多个维度输出了AI治理的前沿思考：
| 嘉宾身份 | 核心观点 |
| :--- | :--- |
| 江必新（中国法学会副会长、最高法原党组副书记副院长） | 需建立高度智慧型法治，以“创新友好型治理”破除体制机制障碍，让AI产业发展更健康有活力 |
| 薛澜（国家新一代人工智能治理专业委员会主任） | 中国AI治理已正式迈入**敏捷治理**时代，多主体协同的新型治理模式正在加速形成 |
| 鲁乙己（中欧数字协会主席） | 面对AI技术的复杂性，各国需开展建设性对话、合作制定统一监管框架，加强国际协作 |
| 璩静（百度副总裁） | 文心大模型3.5在数据质量、生成效果、内容安全性上已实现全面升级，坚持技术发展与安全可控双轮驱动，才能让大模型重塑数字世界、提升全人类福祉 |
| 商建刚（上海政法学院数字法学研究中心主任） | 该倡议书是协同治理的有效举措，充分体现了软法治理的核心原则 |
| 吴焦苏（中科院人工智能联盟标准组成员） | 这份倡议书将成为AI产业健康发展的重要“指南针” |
| 黄道丽（公安部第三研究所专家） | 除隐私风险、伦理风险外，AI技术还可能催生“犯罪基础设施”，形成新型网络安全威胁 |
