### 📋 论坛基本概况

本次论坛是2023世界人工智能大会（WAIC）的平行论坛，核心信息如下：
| 项目 | 详情 |
| :--- | :--- |
| **举办时间** | 2023年7月8日 |
| **举办地点** | 上海世博中心金厅 |
| **主办单位** | 交通银行 |
| **指导单位** | 世界人工智能大会组委会办公室 |
| **协办单位** | 上海金融业联合会、新华社上海分社、中国经济信息社 |

### 💡 核心观点：行业高层研判

#### 交通银行行长刘珺：通用AI对数字经济的四大影响

刘珺指出，银行业需拥抱通用AI，拓展金融服务的深度与广度，其核心判断包括四点：
1.  **金融中心竞争本质是科创竞争**：未来国际金融中心的竞争，将围绕AI大模型等科创能力展开，上海打造AI创新高地需要加大基础研究尤其是算法领域的投入。
2.  **高质量数据是AI发展胜负手**：大模型性能优化依赖高质量数据，只有干净、高质量的数据才能完成模型精调，实现价值跃迁。
3.  **AI技术从“单点感知”走向“全面认知”**：通用人工智能的崛起本质是技术范式变革，金融业需要建立数据、技术、平台、服务统一规范，建设跨业务技术的智能化生态。
4.  **通用AI成为第四次工业革命分水岭**：ChatGPT的强适配性推动全行业将AI视为核心能力，加速AI全面嵌入业务流程。

#### 交通银行副行长钱斌：AI可解决金融行业四大结构性问题

钱斌在主旨演讲中提出，人工智能可帮助金融业破解发展痛点，目前头部机构已在三大方向布局落地：
- **可解决的核心问题**：金融发展不平衡不充分、数据要素向数据资产转化、金融科技人才短缺、经营效能（客户体验/运营效率/风险防控）提升四大问题。
- **三大落地方向**：
    | 方向 | 具体价值 |
    | :--- | :--- |
    | 升级客户服务能力 | 生成式AI改变人机交互模式，赋能差异化产品创新，实现从人性化、个性化到感性化的体验升级，可提升精准营销匹配度，更好满足个性化需求 |
    | 提升内部运营效率 | 优化银行内部流程，降本增效 |
    | 精准金融风险防控 | 依托AI技术提升风险识别与管控能力 |

### 🚀 交通银行“新时代金融”赋能“新智慧服务”发布

本次论坛正式发布了交行AI赋能服务成果，核心内容如下：
- **核心产品**：将“云上交行”服务部署于政务平台，以工具化形态整合音视频、调度、运营等**12项子能力**。
- **应用场景**：在现有虚拟政务窗口、政务服务村居延伸的基础上，拓展覆盖政务、交通、医疗、健康、就业等民生领域场景。
- **核心优势**：具备金融级安全能力、国有银行品牌背书、同业首创模式、全信创认证四大特点。

### 🎙️ 圆桌讨论核心方向

论坛尾声，六位来自产学研用的嘉宾围绕AI对金融行业的影响，以及AI领域潜在法律风险展开讨论，核心关注风险点包括：网络安全、数据安全、隐私保护、算法歧视、知识产权。
参与嘉宾包括：主持人复旦大学法学院许多奇教授，以及华为昇腾计算张迪煊、腾讯云王麒、德勤咨询尤忠彬、临芯投资李亚军、交通银行周彦倜。
