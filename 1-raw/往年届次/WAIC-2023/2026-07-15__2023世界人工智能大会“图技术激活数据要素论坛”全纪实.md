### 📌 论坛基础概况

本次论坛是2023世界人工智能大会（WAIC 2023）的唯一图技术专项论坛，核心信息如下：
| 项目 | 详情 |
| :--- | :--- |
| **举办时间** | 2023年7月6日13:30-17:30 |
| **举办地点** | 上海世博中心6F-620 |
| **指导单位** | 世界人工智能大会组委会办公室 |
| **主办单位** | 浙江创邻科技有限公司 |
| **协办单位** | 浙江邦盛科技有限公司 |
| **论坛定位** | 集学术交流、应用实践、行业趋势于一体的高规格行业盛会 |
| **核心主题** | 探讨数据要素时代下图技术在千行百业的场景化落地路径，加速产业数字化转型 |

### 🎤 核心嘉宾分享亮点

本次论坛汇聚了产业界头部企业技术负责人、行业权威机构代表与顶尖学术专家，各嘉宾的核心观点与成果如下：
1.  **创邻科技创始人兼CEO张晨博士**
    以《图数据库——激活数据要素的新基建》为主题分享，提出图技术可覆盖数据资产“采、析、用、治、运”全流程，针对性解决大数据治理中长期存在的“数据孤岛”“数据可知不可用”“关联性差”等痛点，是打通数字互联互通的核心技术基座，能够为企业数智化升级、数据安全合规提供底层支撑。
2.  **《金融电子化》杂志社执行董事杨文艳**
    深度解读并正式发布**《金融业图数据库建设发展调研报告》**，明确图数据库作为算力与数据存储的核心载体，是金融行业数字化转型的关键基础设施，可实现底层数据互联互通，最大化释放数据资产价值。
3.  **邦盛科技CTO王新根博士**
    分享《时序大数据流（图）实时计算与智能决策及行业应用》，提出“热数据”是数字经济时代的核心价值载体，将图技术的多跳关联查询能力与流计算技术融合，可突破传统单维单跳计算的局限，目前已在银行交易反欺诈、实时反诈、爬虫机器人防御等场景落地应用。
4.  **中国银联大数据图计算平台负责人潘骏**
    分享银联图技术落地实践：依托银行卡组织天然的四方关系图谱属性，银联自2019年从平台、底图、模型三大方向推进图数据库建设，截至2022年已完成**200亿点边规模的统一关系底图**投产，广泛应用于智能风控、业务运营、云闪付用户经营等核心场景，有效突破了大规模数据关联分析的性能瓶颈。
5.  **蚂蚁集团图平台负责人洪春涛博士**
    解读全球首个金融图数据库基准测试标准**LDBC FinBench**，该标准由蚂蚁发起、多机构联合共建（创邻科技为核心参与单位），可模拟真实金融业务的数据分布与查询特征，为金融行业选型图计算产品提供量化、客观的评测依据，填补了该领域的行业空白。
6.  **之江实验室图计算研究中心副主任陈红阳教授**
    介绍面向科学计算的高性能大规模图计算平台——朱雀图计算平台，其自研的朱雀图预训练大模型，可构建融合领域知识的大规模分子图预训练体系，是生物制药领域“类GPT”应用的核心基础，可支撑药物设计、靶点发现等前沿科研场景，推动AI从“感知智能”向“认知智能”进阶。
7.  **香港科技大学（广州）李佳助理教授**
    发布图异常检测评测基准**GADBench**，该基准可从多维度客观评估各类图异常检测算法的性能表现，通过大量实验验证发现：传统算法实现环境信息聚合后，效果可在部分场景下优于图神经网络，图神经网络与传统算法的融合将成为未来技术探索的主流方向。

### 📚 论坛重磅成果发布

论坛压轴环节，创邻科技与电子工业出版社联合推出国内首本图技术专业著作**《图数据库：理论与实践》**正式亮相，该书由张晨博士担任第一作者，系统梳理图数据库的技术体系与落地实践经验，目前可通过扫码入群免费获取电子试读本。

### 🔍 关键洞察
1.  本次论坛首次在WAIC平台将图技术定位为“激活数据要素的新基建”，打破了行业对图技术仅作为细分数据库品类的认知，明确其是打通数据关联、释放全域数据价值的底层核心技术。
2.  金融行业成为图技术落地的标杆赛道，从标准评测、大规模生产落地到行业调研体系已形成完整闭环，为其他行业的图技术应用提供了可复用的参考路径。
3.  图技术的边界正在快速拓展：从传统的关联查询分析，延伸至实时流图计算、科学大模型预训练、异常检测评测等前沿领域，正在成为AI迈向认知智能的核心支撑技术。
