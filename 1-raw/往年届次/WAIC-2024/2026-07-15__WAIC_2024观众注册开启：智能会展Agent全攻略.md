### **🏆 大会基础概况**

本次活动全称为**2024世界人工智能大会暨人工智能全球治理高级别会议**，英文缩写WAIC 2024，举办地点为中国上海，核心信息如下：
| 项目 | 详情 |
| :--- | :--- |
| **论坛举办时间** | 2024年7月4日-7月6日，地点：上海世博中心SECC |
| **展览举办时间** | 2024年7月4日-7月7日，地点：上海世博展览馆SWEECC |
| **大会主题** | Governing AI for Good and for All / 以共商促共享 以善治促善智 |
| **参会规模** | 凝聚超过1000位人工智能全球领军人物，共商AI前沿技术、产业动向、向善治理 |
| **当前进度** | 距开幕式倒计时1天，观众注册通道已正式开放 |

### 🤖 WAIC AI Agent超级会展智能体详情

该智能体由**上海市人工智能行业协会**牵头打造，是本次大会的核心智能化服务亮点，将AI技术与会展服务深度融合，为观众带来个性化、全流程的观展体验。

#### 开发与技术支撑体系

WAIC AI Agent由多方头部企业协同开发，技术底座扎实：
1.  联合开发方：澜码科技、新华智云
2.  底层大模型来源：阶跃星辰、书生、MiniMax、商汤等上海本地知名大模型厂商，以及上海人工智能实验室
3.  功能扩展合作方：阿里、携程、高德团队
4.  核心技术能力：集成先进的感知、规划、记忆和任务调度能力，全面提升观展使用体验。

#### 8大核心观展服务功能

用户通过简单的自然语言问答，即可获取以下全场景服务：
1.  出行规划
2.  天气查询
3.  无人驾驶体验
4.  智能换装
5.  随行展位查询
6.  嘉宾金句
7.  虚拟大讲坛
8.  就餐信息

#### 双端口覆盖全流程观展体验

WAIC AI Agent同时支持微信、支付宝双端口适配，覆盖观展前、观展中、观展后全周期需求：
| 使用阶段 | 微信小程序端 | 支付宝端 |
| :--- | :--- | :--- |
| **观展前** | 扫码进入WAIC云平台完成预约注册 | 首页下拉唤起智能助理，获取大会基础介绍、论坛议程、往届亮点，一键查询天气、预订酒店、呼叫网约车 |
| **观展中** | 随时随地调用8大智能服务功能 | 抵达会场附近后进入定制页面，获取AI问答及数字化观展服务：查询参展企业展示内容、背景知识，自动总结论坛观点等 |
| **观展后** | 延伸多元生活服务 | 获取上海本地游玩攻略，精准搜寻平台内专属美食、休闲优惠券 |
