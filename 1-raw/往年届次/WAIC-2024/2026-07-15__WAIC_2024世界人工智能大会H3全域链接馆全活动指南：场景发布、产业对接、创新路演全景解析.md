### 🏆 大会基础概况

本届**WAIC 2024（世界人工智能大会暨人工智能全球治理高级别会议）**主题为「以共商促共享 以善治促善智」，凝聚超1000位人工智能全球领军人物，聚焦AI前沿技术、产业动向与向善治理。
- 论坛举办时间：2024年7月4日-7月6日，地点为上海世博中心SECC
- 展览举办时间：2024年7月4日-7月7日，地点为上海世博展览馆SWEECC
- 专属观赛通道：扫描官方WAIC标识二维码即可进入云平台观看大会全程直播，观众注册通道已正式开启。

### 📍 H3全域链接馆空间布局

H3馆是本届大会核心特色展馆，定位为前沿创新项目展示舞台与全球观众交流合作中心，整体功能分区清晰：

| 功能区域 | 区域定位 |
| :--- | :--- |
| VIP休息区 | 高端参会嘉宾专属休憩空间 |
| X会议室 | 多功能配套会议空间 |
| Future Tech创新项目路演区 | AI初创项目路演、资本对接专属区域 |
| 「AI+」应用场景展示中心 | 圆形核心展区，集中展示AI落地成果 |
| 产业对接会专区 | 分行业供需对接活动举办区 |
| 「AI+」应用洽谈中心 | 供需双方闭门撮合会议空间 |
| 「AI+」应用场景发布中心 | 行业场景需求官方发布专区 |
| Future Tech 100展区 | 100+AI创新项目集中展示区，覆盖H3-3、H3-4板块 |

#### （三）Future Tech创新路演：孵化AI+未来

作为本届大会创新亮点，该板块汇聚AI初创企业CEO、政府产业基金代表、头部企业战投、投资界大咖与金融机构，实现AI潜力项目与资本精准对接，整体活动规模包含：30场创新项目路演、4场主题演讲、3场圆桌对谈、3天8大主题投融资对接会。
1.  **7月4日路演日程**：聚焦大模型安全、AI测试、基座大模型等技术方向，首日上午为开幕式致辞与头部机构主题分享，下午依次举办4场技术路演，16:00-17:00开启投融资对接会。
2.  **7月5日路演日程**：聚焦具身智能、矿山无人驾驶、AR/VR工具、碳科技、生物AI等赛道，全天设置12场项目分享，15:55开启圆桌对谈，16:00-17:00举办投融资对接会。
3.  **7月6日路演日程**：聚焦AI Agent、工业智能、3D生成引擎、量子AI、算力互联等前沿方向，全天设置13场项目分享，15:55开启圆桌对谈，最终举办2024 Future Tech未来之星创新项目路演闭幕仪式。

### 🎁 Future Tech人气之星加油站活动规则

7月4日-6日展区设置投票活动，观众与投资人均可参与为100+创新项目投票，选出AI明日之星，完整流程如下：
1.  领取贴纸：每位观众可前往H3-B017服务台领取1张创投星探贴纸，每人每天限领1次，数量有限先到先得。
2.  投票支持：将贴纸粘贴到Future Tech 100展区心仪项目的接待台，完成投票表达支持。
3.  每日评选：当日统计贴纸票数，选出每日人气项目TOP3，获奖项目可获得组委会惊喜奖品，三天奖项不重复。
4.  终选排名：7月6日16:00统计3天总贴纸分数，选出最终人气之星TOP3。
5.  优胜权益：获奖项目可获得「2024 WAIC Future Tech创新项目人气之星」称号、WAIC Circle全年宣传曝光与产业投融资对接服务、定制《AI奇点说》内容曝光、2024 WAIC系列活动优先参与权、2025 WAIC Future Tech免费参展资格。
