## 内容分层

- `reports/`：可独立阅读或汇报的主题报告与卡片。
- `figures/`：将既有研究压缩为便于浏览、分享或投屏的图像和合集。
- `reports/0717_old/` 与 `reports/0718_old/`：保留的历史卡片版本。它们不是当前默认引用版本。

本目录保留了早期方案 `reports/WAIC-2018-2026-普通人视角与知识库治理.pptx`，以便回溯；本次跨年报告不包含知识库使用方法，请从主题目录进入。
