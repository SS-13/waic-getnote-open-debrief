# AI 治理控制环

**识别场景 → 分级 → 部署前测试 → 最小权限授权 → 运行监测和留痕 → 偏离检测 → 人工接管/熔断 → 事件报告 → 补偿救济 → 更新标准。**

控制环把治理嵌入产品生命周期。它不是单一法规文本，而是根据中国政策、国际原则、风险分级规则和 2026 治理论坛讨论形成的可运行综合框架。

每一环都应有可核验输出，例如资产清单、测试报告、权限记录、运行日志、接管记录、事故报告和救济结果。
