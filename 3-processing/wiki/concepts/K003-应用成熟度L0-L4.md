# 应用成熟度 L0-L4

| 级别 | AI 承担什么 | 核心治理问题 |
|---|---|---|
| L0 展示 | 证明能力存在 | 演示边界和证据标注 |
| L1 助手 | 识别、问答、推荐、生成 | 幻觉、版权、人工复核 |
| L2 工作流 | 串联步骤并形成成品 | 系统接入、领域验收 |
| L3 代理执行 | 调工具、下单、调度、持续运行 | 身份、权限、日志、回滚 |
| L4 物理执行 | 移动、抓取、驾驶、康养 | 安全、可靠性、责任、售后 |

该模型描述 AI 承担的任务责任，不等同于技术先进程度或市场规模。
