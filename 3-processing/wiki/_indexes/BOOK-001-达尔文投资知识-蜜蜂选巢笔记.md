# 《我从达尔文那里学到的投资知识》：蜜蜂选巢笔记

## 来源与使用边界

- 资料：`我从达尔文那里学到的投资知识.epub`，结语“蜜蜂通过重复一个简单的过程而获胜”。
- 本页是结构化读书笔记和知识库治理映射，不替代原书，也不复刻原文。
- 蜂群案例用于设计信息处理流程，不证明任何单条 WAIC 或外部资料的真实性。

## 结论的结构化整理

蜂群面对多个候选巢址时，并不依靠一只“最聪明”的蜜蜂直接下令，而是把复杂选择拆成重复过程：

1. 侦察蜂分别考察候选地点，并以共同的质量线索形成判断。
2. 发现较好地点的蜜蜂以更强信号吸引同伴，但同伴仍会自行前往勘察。
3. 随着多轮独立复查，较优地点会获得更多支持；支持不是一次性投票，而是被后续观察持续修正。
4. 书中用 A/B/C 三处候选点说明信号会如何放大：A 的支持份额在示例轮次中从约 57% 升至 76%，再到 88%。
5. 机制的价值不在保证每一次都选中绝对最优，而在以简单、可复用的规则，让群体长期避免被单次直觉或复杂噪声主导。

## 对知识库的启发

| 蜂群机制 | 知识库对应动作 | 防止的错误 |
|---|---|---|
| 独立侦察 | 为来源登记原始出处、版本和证据边界 | 只看标题或转述就下结论 |
| 统一评价 | 用 SQS 和 CCS 的固定评分卡 | 每次凭感觉换标准 |
| 信号强度 | 用等级表达证据强度与适用范围 | 把热度或写作气势当作可信度 |
| 跟随后再勘察 | 寻找独立原文、数据、反证和高保真版本 | 盲从权威或多数转载 |
| 多轮收敛 | 新证据触发复审、tension 和 Claim 更新 | 一次定性后永久不改 |
| 质量而非数量 | `canonicalSourceId` 与谱系去重 | 同一新闻被十家转载后虚增权重 |

## 不应误读

- 多来源不天然等于独立来源；同一个发布会、新闻稿或数据集只能算一个谱系。
- 高 SQS 只提高来源对其直接事实的证明力，不会自动提高更强的因果、效果或预测结论。
- 低分线索不必删除，但必须留在观察池，等待独立复核。
- “收敛”不是压制少数意见；若出现可信反证，应建立 tension 并降低或限定 Claim。
