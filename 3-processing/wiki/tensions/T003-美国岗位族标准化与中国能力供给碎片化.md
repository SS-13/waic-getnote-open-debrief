# 美国岗位族标准化与中国能力供给碎片化

## 张力

如果只搜索职位名，中国市场会显得“缺少 FDE”；如果只看 WAIC 解决方案和平台能力，中国又已具备大量 FDE 所需的流程、集成、知识、治理和交付要素。两者并不矛盾，比较的单位不同：前者比较岗位命名和组织边界，后者比较能力供给。

## 当前解释

- **美国可观察到的路径**：AI 产品公司将客户部署定义为明确职责，进一步拆分工程、技术交付、平台和应用 AI 角色，并要求现场经验回流产品。
- **中国可观察到的路径**：云厂商、集成商、行业软件商和客户数字化团队共同提供部署能力，职责常以解决方案、实施、产品、算法/应用工程和项目交付分布。
- **不能推出的结论**：岗位命名不统一，不等于企业没有部署人才；平台演讲中出现治理功能，也不等于客户已完成规模化部署。

## 需要验证的信号

1. 企业招聘是否开始稳定使用 FDE 或等价职责描述。
2. 项目验收是否从“模型上线”转向采用率、质量、成本、事故与 ROI。
3. 现场定制工作是否沉淀为可复用技能、评测、连接器和治理模板。
4. 企业是否形成同时覆盖业务、数据、平台、安全、法务和一线负责人的长期责任机制。
