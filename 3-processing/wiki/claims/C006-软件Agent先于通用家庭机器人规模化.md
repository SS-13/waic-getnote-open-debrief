# 软件 Agent 先于通用家庭机器人规模化

## Claim

在当前样本中，数字化输入、流程明确、输出可验收且失败可回滚的工作流，比开放家庭环境中的通用机器人更接近规模化；具身智能会先在工业、物流、巡检、药房等边界清晰的场景积累可靠性和经济性。

## Evidence

- WorkBuddy 现场陈述的核心形态是把知识、工具和 Agent 放入同一工作台，承接办公和内容流程。[完整文字稿 L221](../../../2-data/完整文字稿/7月17日WAIC直播完整文字稿【整理过】.md#L221)
- 具身智能受访者把未来一至两年的重点放在工业和商用，并将家庭描述为最复杂场景。[第 1 组逐字稿 L32](<../../../2-data/流水席逐字稿/05 罗振宇、快刀青衣WAIC直播精华__WAIC流水席__WAIC流水席第1组嘉宾：云深处、千寻、交泰、绳肌妙算、陶世、永轴智造等.md#L32>) [L111](<../../../2-data/流水席逐字稿/05 罗振宇、快刀青衣WAIC直播精华__WAIC流水席__WAIC流水席第1组嘉宾：云深处、千寻、交泰、绳肌妙算、陶世、永轴智造等.md#L111>)
- 7 月 18 日访谈将商用、工业和家庭放在不同时间层，说明家庭落地仍属于预测而非已验证结果。[完整文字稿 L526](../../../2-data/完整文字稿/7月18日WAIC流水席第3-4组嘉宾访谈完整文字稿.md#L526)

## Boundary

“先规模化”是基于任务边界、回滚成本和当前样本的战略判断，不是对具体年份或市场规模的确定预测。厂商给出的“两年”“三至五年”均按预测处理。
