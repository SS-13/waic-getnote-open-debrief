### 📌 论坛基础概况

本次论坛是2023世界人工智能大会（WAIC 2023）的重点活动之一，于**2023年7月7日**在上海张江科学会堂举办，主题为「未来互联网 赋能新金融」，核心聚焦人工智能、区块链、WEB3等数字技术的融合路径，探讨技术对金融业的赋能、融入与重塑方向。
| 项目信息 | 具体内容 |
| :--- | :--- |
| **联合主办** | 上海金融信息行业协会、上海张江（集团）有限公司、清华大学全球私募股权研究院 |
| **承办单位** | 上海金融数据港 |
| **支持单位** | 上海市人工智能行业协会 |
| **重磅嘉宾** | 2007年图灵奖得主、中国科学院外籍院士约瑟夫·希发基思（Joseph Sifakis），上海市经信委软件和信息服务业处处长裘薇，张江集团党委书记/董事长袁涛，清华大学全球私募股权研究院院长肖星，清华大学经济管理学院副院长何平等 |

### 🏙️ 上海区块链产业发展现状与政策布局

上海市经信委软件和信息服务业处处长裘薇在致辞中披露了上海区块链产业的核心发展数据与未来规划：
1.  **产业基础**：全市已有264家区块链备案企业，数量位居全国第二；主导区块链国际标准10余项，投资海外区块链企业和开源项目超过500个。
2.  **窗口期判断**：当前全球正处于下一代互联网生态布局的关键机遇期，区块链产业生态形成的窗口已经到来。
3.  **即将发布的“上海方案”四大发力点**：
    - 以城市链重点工程重塑产业基础
    - 以关键技术布局引领产业未来
    - 以重大场景建设带动产业发展
    - 以创新生态培育激发产业活力，全面提升区块链产业核心竞争力与融合创新力。

### 🏭 张江区域产业承载能力

张江集团作为上海全球科创中心的核心承载主体，已形成成熟的数字技术产业集聚生态：
- 旗下布局张江人工智能岛、张江数链产业园、金融数据港三大核心载体，汇聚互联网、大数据、AI、区块链领域的头部领军企业。
- 金融数据港是全国范围内集聚度最高的金融科技产业集群，目标打造具有国际影响力的金融科技产业集聚区，孕育了浦东最具活力的金融科技生态系统。

### 🎤 核心嘉宾观点精华

本次论坛汇聚了学界、产业界的顶尖专家，输出了多项前沿判断：
1.  **清华大学全球私募股权研究院院长肖星**：金融区块链和WEB3技术是人工智能与新技术融合的核心方向，将为金融行业带来重大变革，校级研究机构将为该领域的技术融合提供学术支撑、政策智力支持与人才储备。
2.  **图灵奖得主约瑟夫·希发基思**：发表《测试系统智能》主题演讲，提出AI系统要达到人类级别的性能，必须具备“常识”能力，需要拥有类人的态势感知能力，能够自主理解环境知识、应对全新场景，这是构建可信智能生态的核心前提。
3.  **清华大学经管学院副院长何平**：提出智慧金融的技术架构类比——物联网是眼睛、大数据是血液、云计算是心脏、人工智能是大脑，区块链则是智慧金融的神经组织；未来智慧金融将和智慧城市、智慧制造深度融合，形成完整的智慧生态。
4.  **上海市银行卡产业园总经理闵浩**：介绍园区20年发展历程中，已成为中国金融基础设施和金融数据聚集度最高的区域，持续落地智慧金融实践与金融数字化创新项目。

### 🏆 2023新金融区块链应用创新成果发布

2023年5月上海市经信委指导相关机构启动该征集活动，历时2个月评选，最终12个标杆应用脱颖而出，覆盖银行、保险、证券、金融科技四大赛道：
| 赛道类型 | 代表获奖主体 |
| :--- | :--- |
| 银行 | 工商银行、招商银行上海分行、浦发银行、上海银行 |
| 保险 | 人保财险、太平洋财险、三井住友海上火灾保险（中国） |
| 证券 | 中泰证券、国泰君安、湘财证券 |
| 金融科技 | 中银金科、银联商务 |
这批成果集中展示了元宇宙、Web3浪潮下，区块链技术在金融领域落地的最新实践进展。

### 🚀 行业生态重大举措
1.  **国内首家区块链+WEB3创投联盟成立**：由上海金融信息行业协会、上海金融数据港、清华大学全球私募股权研究院等6家机构联合发起，为产业链提供行业指导、创投孵化、风险投资、行业咨询、创业空间、法律服务的一站式全链条服务，搭建安全高效的产业协作平台，推动形成完整成熟的区块链与WEB3产业生态。
2.  **金融数据港科技创新中心启动**：中心设置展示中心、培训中心、孵化加速器、大企业创新中心四大功能板块，由诺贝尔经济学奖得主托马斯·萨金特领衔的全球金融科技实验室已率先入驻，目标打造张江金融科技的“会客厅、集聚地、适配区”。

### 💡 圆桌研讨核心共识

论坛最后环节，来自高校、银行、保险、证券、投资机构的专家共同围绕金融Web3发展路径展开研讨，达成共识：Web3作为新一代互联网迭代方向，金融业需要主动拥抱数字经济趋势，推动技术与实体经济深度融合，为中国经济高质量发展注入新动能。
