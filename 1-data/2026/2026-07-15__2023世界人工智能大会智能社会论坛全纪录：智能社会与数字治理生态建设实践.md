### 📅 论坛基础概况

本次论坛是2023世界人工智能大会（WAIC）的重要分论坛，核心信息如下：
| 项目 | 详情 |
| :--- | :--- |
| **举办时间** | 2023年7月7日 9:00-12:00 |
| **举办地点** | 中国上海杨浦滨江 |
| **论坛主题** | 智能社会与数字治理生态 |
| **指导单位** | 世界人工智能大会组委会办公室 |
| **主办单位** | 同济大学、上海市杨浦区人民政府 |
| **承办单位** | 国家智能社会治理实验综合基地（上海杨浦）、上海市人工智能社会治理协同创新中心、上海自主智能无人系统科学中心、中国（上海）数字城市研究院 |
| **协办单位** | 上海市杨浦区融媒体中心 |

论坛核心目标：应对智能技术发展潜在的伦理、法律和治理风险与挑战，构建公平规范的数字治理生态，超前探索智能社会的运行模式、法律法规、标准规范、政策体系、体制机制，推动负责任的人工智能发展，赋能人类美好生活。

### 🎤 致辞环节核心观点

本次论坛邀请了国内外多领域代表出席并发表致辞，核心内容汇总如下：
1.  **同济大学党委常委、常务副校长 吕培明**：人工智能是引领新一轮科技革命和产业变革的战略性技术，也是城市数字治理、治理能力现代化的核心路径。同济大学已整合校内外资源，聚焦城市数字化转型、智能社会治理、城市更新等方向开展多学科攻关与人才联合培养，支撑国家和上海数字化转型战略落地。
2.  **上海市教育委员会副主任 叶霖霖**：数字化转型需要教育领域先行，加快推进人工智能标准、伦理和法律研究。上海市教委将持续支持同济大学人工智能相关学科建设与人才培养，推动产学研用协同，助力上海市人工智能社会治理协同创新中心产出更多成果。
3.  **中共上海市委网信办信息化协调处处长 单滨**：杨浦区是全国唯一区校协同共建的智能社会治理基地，此前已在政校联动、实验推进、技术应用等维度取得显著成效，未来将进一步强化协同、提升惠民惠企力度，持续营造智能治理的良好氛围。
4.  **上海市杨浦区委常委、常务副区长 尼冰**：杨浦是全国首批、也是唯一由政校联合申报的国家智能社会治理实验综合基地，后续将推动理论与实践贯通、规范与发展统一、单点探索与全域推广结合，输出智能社会治理的上海示范、全国模板。
5.  **联合国教科文组织社会科学及人文科学部门助理总干事 加布里埃拉·拉莫斯（Gabriela Ramos，视频致辞）**：为平衡人工智能发展的利弊，联合国教科文组织已发布人工智能伦理领域首份全球准则性文书《关于人工智能伦理的建议》，呼吁各国政府用好完善程度评估方法论、伦理影响评估等工具，推动人工智能向善发展。

### 📑 重磅成果发布与机构揭牌

本次论坛首次发布多项前沿研究成果，同时完成重要机构揭牌：
1.  **三大核心研究成果发布**
    | 成果名称 | 编制主体 | 核心内容 |
    | :--- | :--- | :--- |
    | 《人工智能大模型伦理规范操作指引》 | 同济大学团队 | 结合中国国情与国际通用伦理准则，明确AI大模型开发与应用的伦理原则、技术开发具体要求，引导开发者与用户共同推动技术进步与伦理规范协同。 |
    | 《生成式人工智能风险评估框架（1.0）》 | 同济大学团队 | 基于AIGC风险事件数据库，通过定性、聚类分析归纳形成AIGC风险清单，对照生成流程梳理各节点风险因素，搭建完整的风险评估分析体系。 |
    | 《面向新商业模式的高级别自动驾驶法律责任白皮书》 | 同济大学+百度联合团队 | 研究自动驾驶致害民事归责的影响因素，参考域外责任分配规则，回应我国自动驾驶场景下的责任划分与风险分担机制，提出针对性立法建议。 |
2.  **杨浦区智能社会建设成果**：构建四大“新”特色——政校联动新模式、社会实验新方向、技术落地新空间、智能治理新样板。
3.  **“人工智能合规服务中心”揭牌**：由尼冰与吕培明共同揭牌，依托杨浦与同济大学的区校协同优势，为AI企业全生命周期提供伦理融入、风险评估、合规审查服务，助力上海城市数字化转型。

### 🎙️ 主旨演讲核心洞察

四位跨领域顶尖专家围绕AI治理、智能社会建设发表前沿观点：
1.  **英国皇家工程院院士 郭毅可《人工智能治理的挑战》**：AI创造力已成为现实，将倒逼“知识定义”“内容权属”“教育模式”等基础问题重新定义。AI治理的核心目标是建立知识世界新秩序，关键难点在于“进化的反向性”，需要推动人机协同，让机器理解人性、实现人机共情，为治理筑牢科学基础。
2.  **清华大学智能社会治理研究院院长 苏竣《推动基于社会实验的智能社会治理，构建人文智能社会》**：以ChatGPT为代表的生成式AI正在重塑知识生产传承校验、社会信任、权威生成三大社会运行机制，智能社会治理将面临经济、政治、文化、社会、生态五大维度风险，需要通过系统性的AI社会实验，探索中国特色治理路径，最终构建人文导向的智能社会。
3.  **耶鲁大学法学院蔡中曾中国研究中心研究员 陆凯《美国的人工智能治理》**：受联邦权力边界与政治环境限制，美国短期内出台全国性AI硬法的概率较低，当前治理模式以现有部门监管规则延伸覆盖AI场景为主，法院判例、非政府组织、行业自律是核心治理力量，联邦层面出台的多为引导性“软法”，未来美国与全球其他国家在AI治理领域存在大量对话合作空间。
4.  **同济大学教授 陈启军《城市数字孪生牵引城市数字化转型》**：城市数字化转型需要聚焦“转什么、怎么转”的核心问题，以破除数据孤岛、变革服务范式、搭建安全韧性平台三大方向为抓手，通过城市数字孪生技术牵引上海全域数字化转型落地。

### 💡 圆桌对话与论坛收尾

本次圆桌对话由上海交通大学教授李仁涵主持，来自民政、高校、科技管理部门的5位跨界专家围绕“智能社会与数字治理生态”主题展开深度交流，输出大量兼具前瞻性、实操性的治理思路，形成跨学科的思想碰撞。
论坛闭幕式上，上海市杨浦区委常委、宣传部部长卢刚总结，本次论坛作为区校联合打造的高规格国际论坛，已完成全部议程并产出多项标志性成果，后续杨浦区将持续联动同济大学，超前探索智能社会治理机制，支撑国家治理体系和治理能力现代化建设。
