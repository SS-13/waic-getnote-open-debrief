### 🏛️ 论坛基础概况

本次论坛是2020世界人工智能大会（WAIC）云端峰会的核心分论坛之一，于7月9日-11日举办，由全球RPA领域创新领军企业云扩科技承办，主题为「人机协作，重塑未来工作方式」，也是该领域的首届行业年度盛会。
RPA（机器人流程自动化）作为企业软件市场增长最快的细分赛道之一，被Gartner评为影响企业未来发展的10大科技之首。云扩科技承办本次顶级行业盛会，标志着其在AI+RPA领域的创新渗透进入全新阶段，也彰显了其以智能RPA引领人机协作变革的行业定位。

### 🎙️ 行业大咖核心观点汇总

本次论坛汇聚了投资机构、国际咨询机构、产业端的多位重磅嘉宾，围绕智能自动化的行业势能与发展趋势展开深度探讨：

| 嘉宾身份 | 核心观点 |
| :--- | :--- |
| 红杉资本中国基金合伙人 郑庆生 | 互联网与移动互联网渗透率提升推动了10年产业大爆发，人类行为实现空前的数据化、在线化，为AI+RPA等技术的高速发展奠定了基础，行业正站在历史性发展节点。 |
| 金沙江创投主管合伙人 朱啸虎 | 未来将迎来企业服务的黄金20年，中国不缺软件工程师，但成熟的企业服务产品供给不足；云扩科技的产品化能力、赋能第三方生态的能力，是中国RPA赛道实现突破的核心关键。 |
| Forrester副总裁、首席分析师 Craig Le Clair | 后疫情时代全球企业数字化进程大幅提速，部分企业仅用2个月就构建了过去5年的数字化能力，智能自动化将呈现三大核心趋势：人机协作落地智能生产力、AI+RPA实现智能文本提取、企业组建「自动化突击队」推动智能自动化规模化落地。 |

### 💬 圆桌对话：AI+RPA产业落地实践

论坛设置「对话·RPA+AI先行者」主题圆桌，嘉宾围绕四大维度展开深度交流，输出了大量产业落地的实操经验：
1.  **RPA的价值本质**：RPA的核心作用是解放人力、提升生产力，目前已在财务、采购、人力资源、物流等多类业务场景实现落地。
2.  **标杆企业实践**：全球最大物流一体化服务商马士基已从RPA 1.0阶段迈入RPA 2.0民用化阶段，依托云扩RPA机器人实现业务能力升级，同时大幅优化客户体验。
3.  **落地核心认知**：
    - 马士基创新加速器项目总经理吴瑾：企业落地RPA的最大挑战并非技术本身，而是全员以开放心态拥抱变革，将机器人视为协作伙伴而非替代者。
    - Plug and Play中国执行董事、CEO徐洁平：RPA是企业数字化转型的优质「敲门砖」，能够高效降低AI技术落地门槛，推动人机协同模式普及。
    - 德勤中国首席数字官赵文华：RPA+AI将为企业带来三大核心价值：升级产品服务体系、优化内部运营效率、辅助科学决策；未来企业最稀缺的人才是能够深度理解商业需求、适配多元技术能力的复合型管理者。

### 🚀 云扩科技全新产品矩阵发布

云扩科技创始CEO刘春刚在本次论坛上，正式发布5款全新RPA+AI产品，与原有云扩RPA编辑器、云扩机器人、云扩控制台共同组成完整的产品体系，构建起「全业务自动化能力-人工智能应用能力-人机协作能力」三层递进的**Encoo组织智能生产力模型**：

| 全新产品名称 | 核心定位与价值 |
| :--- | :--- |
| 云扩Spark | 人人可用的自助式流程发现工具，赋能一线业务人员自主梳理重复工作流程，自动输出自动化机会点评估与ROI测算，掌握RPA落地主动权。 |
| 企业流程银行 | 企业私有流程自动化智库，帮助企业沉淀RPA流程资产，实现跨部门自动化经验共享，破解大型企业RPA规模化落地难题。 |
| 云扩AI HUB | 拖拽可用的人工智能应用中心，聚合全球顶级AI能力，帮助企业低成本、低门槛将AI技术集成到端到端业务流程中。 |
| 云扩DocReader | 灵活定制智能文档理解工具，依托OCR、NLP、机器学习技术，仅需少量样本即可快速训练文档识别模型，解决企业80%非结构化文档无法高效解析的痛点。 |
| 云扩工作台 | 千人千面的人机协作平台，打破传统RPA厂商「前台机器人单设备调度」的模式，为每位员工提供自定义的人机交互界面，适配个性化协作需求。 |

### 📊 落地标杆与行业愿景

云扩的创新合作伙伴国药化学试剂，是这套全新智能生产力产品线的首批使用者：其已在30余个业务场景部署云扩RPA机器人，每月执行数十万次自动化交易，单流程平均降低50%以上的运营成本。
云扩科技始终秉持「让RPA简单智能，人人可用」的使命，希望通过产品体系降低AI+RPA的使用门槛，让所有员工都掌握人机协作能力，将人力从重复劳动中解放出来，聚焦高价值的创造性工作，最终推动全行业生产力变革，加速新一轮商业进化。
