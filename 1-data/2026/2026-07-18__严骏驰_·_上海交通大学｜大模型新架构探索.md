- **论坛**：记忆张量·从一次性 Agent 到记忆原生智能时代论坛
- **时间**：2026-07-17 · 9号会议室 · 主旨演讲
- **嘉宾**：严骏驰（上海交通大学，学界代表）

## 一句话概要
在 scaling 空间趋于饱和之际，为大模型寻找一个新的可扩展维度：通过为每个 token 在每一层挂载可学习的记忆向量，以「扩展语义深度而非词表规模」的方式，把记忆原生地注入架构。

## 核心观点
- Scaling 已被广泛认同但空间在饱和，需要为大模型找到一个新的、可扩展的维度。
- 传统架构中 token 的身份信息只在输入时被处理一次，在后续几十层计算中被逐渐稀释——缺少一条直达的记忆通路。
- 新架构让每个 token 在每一层都携带一条可学习的记忆向量，全程参与训练与推理；扩展的是每个 token 的语义深度，而非词表规模，记忆以查表方式稀疏读取。
- 长期看模型容量上限将由大容量存储决定，而不是昂贵的 GPU 显存。
- 该设计与 Dense、MoE 架构正交，是一个 plugin，可加装在预训练好的模型上、在后训练阶段即可获得增益，无需从头重训。
- 模型内参数化记忆与模型外记忆基础设施应分层并存。

## 内容整理

### 一个新的可扩展维度
这项工作从去年下半年起陆续探索，随后也看到 Meta、DeepSeek 乃至谷歌出现类似想法，即把记忆能力更原生地注入大模型架构。核心问题是：能否为大模型找到一个新的、可扩展的维度？因为 scaling 虽被广泛认同，但空间正慢慢饱和。思路是把类似记忆的想法、embedding 技术引入架构，进一步拓展 scaling 能力。

### 「专用 Token」：让记忆全程参与计算
传统做法里，token 的身份信息在输入时被 Transformer 处理一次、查询一次，但在后面若干层甚至几十层的计算中被慢慢稀释，因为没有一条直接通路。新架构引入一个专用的 token（一个带谐音梗的命名），使每个 token 在每一层都可以携带一条可学习、带记忆的向量，全程参与模型的训练和推理。要强调的是：扩展的是每个 token 的语义深度，并不修改或扩展词表规模，因此记忆以查表方式稀疏读取——表可以做得很大（字典里单词数量不变），推理时存储量可控。由此，长期看模型容量上限将由大容量存储决定，而不是昂贵的 GPU 显存，这是设计的基本哲学。

### 与主流架构正交、增益立等可取
该设计不是用它替代某个 Dense 或 MoE 架构，而是与它们正交——既可用在稠密模型，也可用在混合专家模型，是一个能给不同版本模型带来较大增益的 plugin。而且增益立等可取：不需要 from scratch 重新预训练，只要拿一个已经预训练好的开源模型，加装一个随机初始化的记忆模块，在后训练过程中对架构做一个小修改即可拿到收益。

### 模型内记忆与模型外记忆的分层并存
关于「记忆内生于模型」还是「外置为独立基础设施」，初步判断是分层并存：模型内的参数化记忆在训练时写入、推理时及时读出，承载通用、精确、需长期保存的知识（如历史、金融领域常识等，类似数据库，甚至在训练过程中存储）；会话内的上下文承载当前任务的工作记忆；而模型外的记忆基础设施负责持有可编辑、可管理的长期记忆。同时认为模型内记忆的容量远没有触及饱和。

## 金句
> 我们扩展的是每个 token 的语义深度，并不是去修改或扩展词表的规模。
> 长期来看，模型容量的上限将由大容量的存储来决定，而不是昂贵的 GPU 显存。
> 它跟 Dense、MoE 是正交的，就是一个 plugin，增益立等可取。
