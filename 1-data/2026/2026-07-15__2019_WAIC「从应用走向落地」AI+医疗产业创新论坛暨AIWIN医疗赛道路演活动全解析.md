### 📌 活动基础概况

本次活动属于**2019世界人工智能创新大赛（AIWIN）系列活动**，由世界人工智能大会组委会发起，核心聚焦AI技术在医疗领域的商业化落地路径，打通产业资源对接通道。
- **活动主题**：从应用走向落地——“AI+医疗”产业创新与发展论坛暨AIWIN医疗赛道项目路演及对接会
- **举办时间**：2019年7月26日 9:00-16:30
- **举办地点**：上海市徐汇区枫林路420号A座601会议室

### 🤝 主办与合作主体矩阵

本次活动构建了多层级的办会与合作体系，覆盖指导、主办、承办、战略伙伴等多个维度：

| 主体类型 | 参与机构 |
| :--- | :--- |
| **指导单位** | 世界人工智能大会组委会 |
| **主办单位** | 世界人工智能创新大赛组委会、徐汇区人民政府 |
| **承办单位** | 枫林集团、摩尼科技 |
| **全程战略合作伙伴** | 太平洋保险（CPIC） |
| **战略合作伙伴** | 腾讯 |
| **合作伙伴** | 汇丰银行（HSBC） |

### 📅 全流程议程拆解

活动分为上午产业论坛、下午项目路演两大板块，整体安排紧凑且覆盖成果发布、行业研讨、资源对接全链路：

| 时段 | 环节内容 | 核心价值 |
| :--- | :--- | :--- |
| 9:00-9:30 | 会议入场签到 | 参会人员核验入场 |
| 9:30-10:00 | 开场领导致辞 | 官方层面明确AI+医疗产业导向与支持政策 |
| 10:10-10:15 | 2019 AIWIN「AI+医疗」阶段总结 | 复盘赛事前期进展，梳理赛道创新成果 |
| 10:15-10:25 | 发布「AI+医疗」创新加速计划 | 推出专项产业扶持机制，赋能参赛项目落地 |
| 10:25-11:00 | 行业主旨演讲 | 头部专家分享AI+医疗前沿技术与落地经验 |
| 11:00-11:45 | 圆桌论坛：通往「AI+医疗」的市场落地之路 | 聚焦行业痛点，探讨商业化落地的可行路径 |
| 12:00-13:30 | 午餐时段 | 参会嘉宾自由交流对接 |
| 13:30-14:00 | 路演环节签到 | 路演项目方、投资机构入场核验 |
| 14:00-16:30 | AIWIN医疗赛道项目路演 | 优质AI医疗项目集中展示，对接资本与产业资源 |

### 🔍 补充细节
1.  本次活动落地于上海徐汇枫林区域，该区域是上海顶尖的医疗健康产业集聚带，依托属地产业资源为AI医疗项目提供了天然的落地场景支撑。
2.  活动配套双报名通道：参会者可扫描专属二维码完成本次论坛路演的报名，同时2019世界人工智能大会的整体注册预约系统已同步开放，可通过WAIC官方小程序完成全大会的参会注册，还可关注WAIC微信公众号获取更多产业活动资讯。
3.  活动核心定位跳出了单纯赛事展示的属性，通过发布「创新加速计划」，为AI医疗创业项目提供从技术打磨到市场落地的全周期扶持，是WAIC推动AI产业从技术走向商用的典型落地动作。
