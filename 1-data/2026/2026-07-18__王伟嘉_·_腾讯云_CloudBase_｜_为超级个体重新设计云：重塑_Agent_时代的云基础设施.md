- **论坛**：WAIC Future Tech·AI Agent 时代的一人公司与 Token 经济论坛
- **时间**：2026-07-17 · 世博展览馆 H4 创新舞台 · 主旨演讲
- **嘉宾**：王伟嘉（腾讯云 CloudBase，产品负责人）

## 一句话概要
王伟嘉提出，Web coding 已进入「谁能让代码真正上线运行」的下半场，云基础设施需要从「为人设计」转向「为 Agent 设计」，而当下最稀缺的不是 token 成本或生成速度，而是 Agent 的注意力。

## 核心观点
- 大厂难以覆盖各类垂直领域，反而最适合为超级个体提供「对 Agent 友好、AI 原生」的云基础设施。
- Web coding 上半场比拼生成代码的效果与 UI 美观，下半场比拼「生成的代码能不能真的上线、变成生产级可访问的应用」。
- 从 context engineering 到 harness/loop engineering，工程重心转向「让 Agent 拥有足够上下文并能长期工作」。
- AI 原生云基础设施需具备工具化、结构化、沙箱化等特征，让云从「人机界面」变为 Agent 可读、可验证、可反馈。
- 2026 年最稀缺的资源不是 token 成本或生成时间，而是 Agent 的注意力——上下文窗口业界最优仍是 100 万，占用过半后模型注意力就会涣散。
- AI 是「新的电力」：只有围绕它重构工作流程（如流水线之于电力革命），生产力才会真正爆发。

## 内容整理

### Web coding 的下半场
王伟嘉指出，现在有一批产品拥有可观的 AI 收入和高额估值，但近一年它们比拼的已不再是谁的页面更酷炫、生成更快更省——那是上半场（比如新发布的 Kimi K3 就很擅长生成美观的前端页面）。下半场真正的分水岭是：生成出来的代码是不是真的能变成一个线上的、对所有移动端用户可访问的生产级应用。换句话说，谁能让 Agent 把代码、数据、身份以及后端的存储、运维、部署都串联起来，谁就赢得下半场——这正是云基础设施要提供的服务。

### 从上下文工程到「让 Agent 长期工作」
他梳理了工程范式的演进：先是 context engineering（上下文工程）——给 Agent 一个好指令已经不够，更重要的是它有没有完成工作所需的足够上下文。比如你让它「把今天开会的会议纪要做成一个真正的产品」，可这份纪要在哪？AI 根本读不到，于是工程上要解决「AI 能否真正读到你的会议纪要」。今年上半年又火了 harness engineering，近两个月还诞生了 loop engineering，二者解决的是「Agent 能否长期工作」：和 DeepSeek 聊天是一分钟内完成的短时任务，而生产级线上环境是 7×24 永不落幕的。由于 Agent 没有眼睛、四肢和耳朵，整个云平台都需要为 Agent 重新设计。

### AI 原生云基础设施的三个特征
王伟嘉认为，一套 AI 原生的云基础设施至少要具备三点。其一是**工具化**：传统人类工程师靠登录控制台或命令行来运维，而 Agent 需要的是 MCP 协议、类似 skill 的文档以及各种 SDK，供它以代码方式调用。其二是**结构化**：传统平台的信息面向人类可读，比如一条自然语言的报错信息，并不是能直接喂给 Agent 的结构化信息，这会阻碍 Agent 接入真实系统。其三是**沙箱化**：Agent 本质是概率型的大语言模型，会带来成本和权限隔离上的挑战。综合来看，云基础设施要从过去的人机界面，转变为 Agent 可读、可验证、可反馈的形态。

在腾讯 CloudBase 的实践上，他们把 serverless、后端服务、云端多租户托管、权限与计费能力重新组织打包成一套「对 Agent 友好」的基础设施，并切成两条线：一条面向超级个体和开发者，去适配 AI coding——提供 MCP 工具赋予 AI coding 操作云端资源的能力，提供 skills 让 AI Agent 具备「如何操作云端资源」的知识，并为市面上多种 AI coding 工具做了单独的插件；另一条线则让用 CloudBase 完成应用开发所需的资源，无论在生成时间还是 token 消耗上都更优。

### 最稀缺的是「Agent 的注意力」
但王伟嘉强调，最重要的并不是速度或省下的成本，而是**Agent 的注意力被节省了**。站在 2026 年看，LLM 上下文窗口业界最优仍是 100 万，尚未做到千万甚至上亿，何时能做到也是未知数。因此当下最稀缺的未必是 token 成本或生成时间，反而是 Agent 的注意力：当上下文窗口占用超过一半时，模型注意力就会涣散，很可能不再遵循你的指令。他进一步把 AI 类比为「新的电力」——如果人的智能可以被近乎无限供给，就会变成一种新的生产力。但业界也在探讨，为什么 AI 提效、替代人的智能没有想象中那么快？他借用了一个比喻：蒸汽时代向电气化革命过渡时，如果只是把蒸汽机原地换成电动机，最多带来 10%–20% 的提升，因为传统蒸汽工厂的产线是围绕「动力轴」布局的；真正的生产力爆发来自后来的流水线生产——工厂布局不再基于动力，而是基于生产流程。言下之意，AI 的价值同样要靠重构工作流程来释放，而非原地替换。

## 金句
> 当下最稀缺的可能未必是 token 的成本或生成的时间，最稀缺的反而是 Agent 的注意力。
> AI 是一种新的电力——但只有把产线从「动力轴」改成「流水线」，生产力才会真正爆发。
