### 📌 大会基础概况

2020世界人工智能大会是该盛会举办的第三年，首次以云端峰会形式举办，核心信息如下：
1.  **举办周期**：主会期为7月9日-7月11日，为期3天
2.  **延期安排**：明星展「AI家园云展览」延长开放至7月31日，官网后续将上线大会全量精彩内容视频回看
3.  **核心成果**：首次实现「百台同播，千网同发，亿人同观」的传播效果，彻底打破前两届线下举办时的场地承载限制，让全球海量用户无需到场即可沉浸式参与AI行业盛会。

### 🎯 新媒体互动整体布局

大会筹备阶段提前启动新媒体运营，从7月初开始在微博、知乎两大主流平台同步发起多维度互动活动，覆盖普通网民、行业大咖、科技企业等多元主体，掀起全民讨论热潮。

### 🔍 微博平台互动项目详情

大会官方微博于7月2日发起#你最希望人工智能帮你做什么#有奖互动活动，活动数据与参与情况如下：
| 维度 | 核心数据/详情 |
| :--- | :--- |
| 话题传播量 | 微博话题总阅读量突破1亿 |
| 参与主体 | 覆盖普通网民+数十位行业大咖 |
| 核心大咖代表 | 李开复（创新工场董事长兼CEO）、张钹（中科院院士、清华大学AI研究院院长）、徐立（商汤科技联合创始人兼CEO）、胡郁（科大讯飞轮值总裁）、袁岳（零点有数董事长）等 |
| 代表性观点 | 李开复提出趣味畅想：希望拥有真正智能化的私人助手，当他和太太吵架时，AI可以自动帮忙买花向太太道歉 |
| 网民脑洞方向 | 覆盖全生活场景：AR/VR增强视频通话沉浸感、AI陪护机器人解放全职妈妈、5G+AI赋能在线教育/线上医疗、AI助力老年群体提升生活质量、实时同声传译、AI辅助弱势群体就业等 |

### 🧩 知乎平台「AI家园的无限可能」圆桌生态

大会在知乎发起的线上圆桌论坛，聚焦AI长期发展趋势，形成了高浓度的产业级讨论内容，核心运营数据如下：
| 维度 | 核心数据/详情 |
| :--- | :--- |
| 总浏览量 | 累计达446万 |
| 参与内容量 | 产出近1400篇学术向、产业向深度回答 |
| 核心参与主体 | 李开复、陈运文（达观数据创始人）、卢刚（动点科技创始人）、夏华夏（美团首席科学家）等行业大咖，以及微软亚洲研究院、科大讯飞、商汤科技、支付宝、云从科技、华为计算等头部科技企业 |
| 标杆议题1：AI 20年内的生活改变 | 1. 李开复发起定向提问，限定讨论场景为20年内可落地的地球场景，排除外太空、纯虚拟科幻内容<br>2. 陈运文判断：未来20年50%的流程性办公工作将被AI自动化<br>3. 卢刚判断：AI应用将成为全民常态，如同当下无处不在的云服务，绝大多数服务都将实现「Powered by AI」<br>4. 网民产出创意内容：有用户以小说形式畅想2040年AI赋能「生化材环」传统天坑专业，实验机器人助手通过模仿学习解放科研人员的体力劳动，让从业者专注于创新 |
| 标杆议题2：近两年AI有趣进展 | 微软亚洲研究院分享前沿成果：实现将数据存储在普通玻璃介质中的创新存储技术，引发5.4万次浏览 |
| 标杆议题3：AI时代不可被替代的就业方向 | 1. 科大讯飞提出核心判断：AI不会替代人类，用AI解决社会刚需是当下核心发展方向<br>2. 支付宝提出趣味观点：和「爱」相关的三类工作无法被AI替代，分别是创造性探索类工作、需要设定目标的工作、带有情感交互属性的工作 |

### 💡 补充细节
1.  本届大会的云端转型不仅解决了线下参会的流量瓶颈，更通过双平台分层运营实现了破圈传播：微博侧主打轻量化全民畅想，降低AI话题的参与门槛；知乎侧主打深度产业讨论，沉淀高价值行业内容，形成了覆盖大众认知与产业共识的完整传播闭环。
2.  李开复在大会主论坛还发表了《从「AI+」到「+AI」：以技术重构中国经济》的主题演讲，将宏观产业判断和趣味个人畅想形成呼应，成为本届大会新媒体传播的标志性记忆点。
