- **论坛**：记忆张量·从一次性 Agent 到记忆原生智能时代论坛
- **时间**：2026-07-17 · 9号会议室 · 主旨演讲
- **嘉宾**：高仲（华为，计算首席专家）

## 一句话概要
Agent 全面涌现让模型结果开始进入生产系统，也把基础设施的关注点从「模型参数够不够」转到「如何支撑有状态、可协同的智能体规模化落地」；华为以全栈协同与新一代互联架构应对算力异构、KV Cache、条件记忆等新挑战。

## 核心观点
- Agent 大规模涌现后，模型产生的结果已从 PoC/展示走进生产系统，真正帮助完成业务交付；工程落地在成本、时延、吞吐、稳定性上已跨越主要约束点。
- 关注焦点从「模型参数够不够、能不能更大」转向「如何基于 Agent 实现基础设施工具化能力的落地」。
- Agent 任务由模型动态决定（基于上一步的动作、结果、状态决定下一步），带来资源异构性与随机性，CPU 与 GPU 需要重新深度协同，算力配比趋向 1:1。
- 后训练与推理越来越重要，纯卷预训练收益变低；模型正从通用基座变成「以智能体为中心」的基座，需要在环境中大量交互、以任务完成度和工具调用结果为奖励形成正向循环。
- 记忆真正没解决好的是「隐性经验」，它是智能体自我进化的关键；规模化落地要抓标准化、分布式（状态与计算/存储解耦）。

## 内容整理

### 从展示走进生产系统
从去年到今年，AIGC 与 Agent 的全面涌现让人印象深刻。Agent 一开始让人觉得很强，能做纯聊天模型做不到的事，但用久了会发现仍有很多问题——记忆正是让它更有效、更智能地完成任务的关键。更大的变化是：模型产生的结果不再停留在 PoC 和展示，而是开始进入生产系统、帮助完成实际业务交付。以数据分析 Agent 为例，在中国五百强企业的部署从 12% 提升到 50%，是一次跨越式变化。随之，To B 落地要解决的问题也变了：以前关注模型参数够不够、能不能更大，如今焦点转到如何基于 Agent 实现基础设施工具化能力的落地。

### 算力结构：异构性与随机性
整体算力可分为通算与智算两部分。AIGC 场景下 CPU 大幅参与，某些任务中 CPU 端到端时间占比可达 90% 以上。工作流对任务调度带来两点新挑战：一是异构性（系统涉及 CPU、GPU 及各类工具负载，资源层面异构），二是随机性（Agent 的规划与执行由模型决定，基于上一步的动作、结果、状态决定下一步，而非人预先定好的静态步骤）。由此 CPU 与 GPU 需要高度协同，算力中心的比例正往接近 1:1 演变。

### 训练与推理的重心转移
Agent 带来模型训练三点变化：其一，推理与后训练越来越重要，纯卷预训练收益变低；其二，模型从通用基座变成以智能体为中心的基座，需要在环境中大量交互、验证，以任务完成度和工具调用结果作为正向奖励，形成循环、找到最佳路径；其三，训练算力配比将发生较大变化。推理侧，prefill 是计算密集型、decode 是带宽密集型；通过 KV Cache 缓存已算部分、只算当前 token，可大幅降低响应时延与成本。在 Agent 场景，KV Cache 命中率要求普遍在 90% 以上，意味着只有约 10% 需要重新计算。记忆的角色也在变：从提示词工程（怎么问），到 harness（在局部空间约束下把单次任务丝滑跑完），再到 loop agent（基于意图让 Agent 自主规划、执行、观测、评估，跨时间维度持续自主运行）。

### 记忆与规模化落地的关键
记忆里 RAG、向量查询这类知识检索已较成熟，真正没解决好的是经验、尤其是隐性知识——正如人真正的能力多来自实践中积累的隐性经验，它能帮助更智能地解决复杂问题；记忆也是智能体自我进化的关键。规模化落地要抓三点：标准化（跨 Agent、多 Agent 协同需要标准，业界已有 Open Agent Framework 等知识层雏形，但记忆本身的标准化仍待补）；分布式（Agent 有状态，需把状态与计算、存储解耦，才能做大规模分布式）；以及避免绑定单一情景、模型、设备或实例。

### 条件记忆与全栈协同创新
以 DeepSeek 为例，V4 引入了条件记忆，让模型内部具备内部记忆能力。但从基础设施看，若这部分记忆全用 GPU 来算，会挤占本就有限且昂贵的 HBM 容量（最大也就几百 G），存在浪费，思路是把它卸载到 CPU。为此华为基于新一代互联架构（会上称「零区」）解决堆叠式瓶颈：单机内 CPU、GPU、NPU、内存、SSD 变为对等（peer to peer），不再都经 CPU 中转；跨节点具备内存级 NoSQL 语义，交互从传统 TCP/IP 的微秒、毫秒级降到纳秒级，把 CPU—内存—盘—网络整系统拉通。未来创新方向是做全栈的协同与优化：从芯片硬件，到 AI 云化改造（MCP 化、SGI 化等，含训推 TPU 与含记忆、隔离运行环境、编排调度的 AI Core），到模型及服务层，再到与行业伙伴的生态协同创新。

## 金句

> 你真正的能力是在工作中通过实践积累下来的隐性经验——这正是记忆现在还没很好解决的点。
> 记忆也是智能体自我进化的一个关键。
