### **🏛️ 论坛基础概况**

本次论坛是2023世界人工智能大会（WAIC）的张江分会场活动，核心基础信息如下：
| 项目 | 详情 |
| :--- | :--- |
| **举办时间** | 2023年7月7日 |
| **举办地点** | 上海张江科学会堂 |
| **论坛主题** | 新AI，新制造 |
| 指导单位 | 世界人工智能大会组委会办公室 |
| 主办单位 | 清湛人工智能研究院、次方元 |
| 支持单位 | 清华大学人工智能研究院 |
| 战略合作单位 | 中国信通院、中国人工智能学会 |
| 参会人群 | 国内外知名专家、高校教授、企业代表、投资机构、产业协会、专业媒体业内同仁 |

论坛聚焦数智化技术引领的新一轮工业革命趋势，围绕AI为制造业带来的新机遇与新挑战展开深度研讨，推动产业上下游协同交流，助力产业高速发展。

### **🎙️ 核心嘉宾主旨观点汇总**

本次论坛汇聚了中外院士、顶尖高校学者、产业界专家，围绕大模型时代AI与制造业融合的前沿方向输出了重磅观点：
1.  **张钹（中科院院士、清华大学教授、清湛人工智能研究院院长）**
    指出ChatGPT验证了“AI行为主义”的落地可能性，引爆了新一轮AI产业浪潮；同时明确当前大模型存在无法自主排查错误的短板，制造业落地大模型产品时，必须重点关注错误信息的治理机制。
2.  **Jivka Ovtcharova（德国国家工程院院士）**
    分享德国工业4.0体系下虚拟工程学的研究成果：该技术以算法为核心，依托VR/AR/MR等交互技术实现人机深度互动，是一项长期工程，核心价值是解决复杂团队决策类工业难题。
3.  **张建伟（德国国家工程院院士、汉堡科学院院士）**
    在《大模型AIoT赋能工业4.0》演讲中，结合高端制造领域前沿科学问题，梳理了人形机器人未来发展的可行性、落地需求、现存技术鸿沟以及完整的技术发展路线图。
4.  **孙富春（清华大学计算机系教授、中国人工智能学会副理事长）**
    从“为何要具身”、“具身大模型技术”、“产业影响”、“发展趋势”四个维度系统解读**具身大模型**这一前沿方向，同步公开了清华大学团队在该领域的最新研究成果。
5.  **产业界嘉宾核心观点**
    - 立林聂振鹏：针对智能家居AI落地现存痛点，提出“主动智能”“智能康养”新理念，通过AI设备、服务机器人覆盖全年龄段用户的智能体验升级。
    - 英伟达李铭：英伟达已搭建完成“GPU+DPU+CPU”完整算力产品架构，为制造业边缘AI应用落地提供全栈算力支撑。
    - 梅卡曼德韩卓：AI与3D视觉技术的融合为智能制造打开巨大增量空间，机器人与自动化赛道仍有极广阔的发展前景。
    - 清湛杨磊：拆解制造业数智化转型核心痛点，提出工业人工智能的四大发展维度，发布国内首份面向工业场景的MLOPS产业图谱。

### **📢 重磅发布与产业成果**

论坛中场环节推出多项填补行业空白的发布与评选成果：
1.  **工业MLOPS产业图谱发布**
    清湛人工智能研究院正式发布面向工业产业的“人工智能持续研发及持续运营（MLOPS）”产业图谱，该成果填补了国内工业级MLOPS平台领域的空白，可有效支撑数据驱动的AI自动化工具在工业特定场景落地，补齐了国内该领域长期落后海外的短板。
2.  **【中国新制造】AI产品创新先锋奖揭晓**
    以业绩为导向、数据为核心评选出3家获奖企业，由中国信通院与中国人工智能学会联合颁奖：
    - 梅卡曼德（北京）机器人科技有限公司
    - 厦门立林科技有限公司
    - 中电鹏程智能装备有限公司
3.  **长三角产业推介**
    南通创新区进行产业推介：依托长三角一体化发展机遇，南通与上海产业协同联动，将通过完善载体配套、优化专项政策服务，重点推动人工智能产业项目落地，驱动区域经济转型升级。

### **💡 圆桌论坛核心共识**

论坛最终围绕“新格局下制造业新思考”主题开展闭门研讨，形成三大核心共识：
1.  从覆盖广度看，AI已经渗透到制造业全流程环节，其中设计、质检等场景的AI应用已发展至相当成熟的阶段；但从技术深度看，AI在制造业的价值挖掘仍有极大提升空间。
2.  AIGC技术在制造业场景的落地，可显著提升研发、生产、管理全链路的工作效率，相比传统AI产品具备代际级体验优势。
3.  参会嘉宾结合自身产业实践，共同畅想了AI在制造业中更多待落地的创新场景，为后续产业协同创新指明了方向。

### **🔍 补充细节**
- 本次论坛是2023 WAIC“生成未来”年度主题下，聚焦实体制造产业的核心垂直论坛，精准呼应了当时全球生成式AI爆发后，产业界对AI落地实体经济的迫切探索需求。
- 论坛发布的中国MLOPS上下游供应商图谱，完整覆盖了基础硬件、算法与模型开发、场景开发、数据基础服务、算力服务、数据应用服务六大产业链环节，是国内较早系统梳理工业AI研发运营全栈生态的权威图谱。
