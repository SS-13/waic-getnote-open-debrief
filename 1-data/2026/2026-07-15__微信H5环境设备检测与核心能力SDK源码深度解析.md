### 🔍 核心模块总览

这份源码是微信公众号生态下的H5基础能力集成SDK，覆盖设备环境探测、JSAPI桥接、网络请求路由、数据埋点上报、DOM事件封装、富文本安全渲染六大核心能力，是微信内部用于保障公众号页面在不同端侧兼容性的底层基础库。

### 📱 设备与环境探测体系

该模块通过解析User-Agent字符串，完成全平台的设备、浏览器、操作系统识别，核心识别维度如下：

| 识别对象 | 关键匹配规则 | 标识属性 |
| :--- | :--- | :--- |
| 微信内置浏览器 | `MicroMessenger` 关键字匹配 | `Device.browser.WeChat` |
| 鸿蒙系统 | `OpenHarmony` 关键字匹配 | `Device.os.harmony`，类型码42 |
| iOS全系列 | `iPhone`/`iPad`/`iPod` 匹配 | `Device.os.ios`，自动处理版本号下划线转点格式 |
| 安卓系统 | `Android` 关键字匹配 | `Device.os.android` |
| Windows/MacOS | 对应UA标识匹配 | 标记PC端属性，用于区分移动端逻辑 |
| 微信版本号 | 支持十进制、十六进制双格式解析 | 提供`gtVersion`/`ltVersion`/`eqVersion` 三个版本对比方法 |

同时内置了多项能力检测函数：
1.  **H5视频支持检测**：判断安卓4.1以上、微信4.2+环境是否支持HTML5视频播放
2.  **自动播放检测**：iOS10以下系统默认禁用自动播放，返回false
3.  **iOS锁定模式检测**：iOS16+环境下检测WebAssembly、WebGL等能力是否被禁用

### 🌉 WeixinJSAPI桥接层

该层封装了微信原生能力的调用逻辑，解决跨域、异步回调、权限校验等问题：
-  **生命周期管理**：通过`ready`方法监听`WeixinJSBridgeReady`事件，确保原生桥初始化完成后再执行调用
-  **异步调用封装**：`invoke`/`call`方法自动等待页面鉴权完成，支持跨顶层窗口调用，处理跨域场景下的降级逻辑
-  **事件回调管理**：通过`JSAPIEventCallbackMap`维护事件监听队列，支持同一事件多个回调注册与移除
-  **防重复调用**：内置`dedupePromise`机制，避免同一接口短时间内重复发起请求

### 🚀 智能网络请求路由

核心的`AjaxRouter`模块实现了三层请求降级策略，保障网络请求在微信环境下的稳定性：
1.  **优先走原生传输**：符合配置规则的请求优先调用微信原生`webTransfer`接口，绕过WebView的网络限制，提升请求成功率
2.  **次选JSAPI请求**：二次打开场景下优先使用微信`request` JSAPI，自动处理`pass_ticket`鉴权重试逻辑
3.  **兜底XHR请求**：前两种方式失败后自动降级为标准XMLHttpRequest，兼容所有环境

同时内置了全链路请求埋点，自动记录请求耗时、错误码、重试次数，对接微信内部监控系统。

### 📊 全链路数据埋点体系
-  **实时批量上报**：默认每4条埋点数据聚合一次上报，1秒超时自动触发兜底发送，降低网络请求数
-  **页面离开上报**：通过`onbeforeunload`事件触发`leaveReport`机制，确保页面退出前的埋点数据不丢失
-  **性能指标采集**：自动统计接口耗时、页面加载时长、用户交互行为，对接微信内部`jsmonitor`监控平台
-  **异常兜底**：上报失败自动降级为图片打点发送，极端场景下保障数据可达

### 🎯 DOM事件与交互封装

针对移动端交互痛点做了深度适配：
1.  **Tap事件**：替代原生click，解决移动端300ms点击延迟问题，同时避免滚动场景下的误触
2.  **长按事件**：兼容PC端鼠标长按与移动端触摸长按，500ms触发阈值
3.  **双击事件**：300ms间隔内两次点击触发，适配视频双击缩放场景
4.  **可见性监听**：封装页面前后台切换事件，适配不同浏览器的前缀差异
5.  **方向监听**：自动监听屏幕横竖屏切换，提供统一的方向回调接口

### 🛡️ 富文本安全渲染引擎

针对公众号图文内容做了安全过滤与增强渲染：
-  **标签白名单过滤**：自动移除危险标签，仅保留微信生态内合法的链接、小程序卡片、位置POI标签
-  **关键词高亮**：支持搜索场景下的关键词精准定位高亮，处理中英文混排、emoji字符边界问题
-  **特殊元素适配**：自动识别时间点标签、话题标签、音乐卡片，渲染为可交互元素
-  **语言排版优化**：自动识别英文长文本，添加左对齐样式，避免中英文混排错乱
