### 🎯 论坛基础概况

本次论坛是2023世界人工智能大会（WAIC）的核心专题论坛之一，核心信息如下：
| 项目 | 详情 |
| :--- | :--- |
| **举办时间** | 2023年7月7日 |
| **举办地点** | 中国上海世博中心 |
| **指导单位** | 世界人工智能大会组委会办公室、工业和信息化领域科技伦理专家委员会 |
| **承办单位** | 中国信息通信研究院（CAICT） |
| **论坛主题** | 科技向善 伦理先行 |
| **参会规模** | 线下100余人，线上观看人数超3万人 |

### 🗣️ 致辞环节核心观点汇总

本次论坛由中国信息通信研究院总工程师、工业和信息化领域科技伦理专家委员会副主任委员兼秘书长敖立主持致辞环节，多位嘉宾从不同维度提出AI伦理治理的核心方向：
1.  **工信部视角（工业和信息化部科技司副司长任爱光）**：提出AI产业发展三大核心指引
    - 持续提升技术创新能力，驱动AI产业高质量发展
    - 坚持创新发展与风险防控并行，搭建完善科技伦理治理体系
    - 强化科普宣传与国际对话协作，构建良性的科技伦理治理生态
2.  **上海市落地视角（上海市经济和信息化委员会副主任张英）**：明确上海推进AI健康发展的三大落地路径
    - 迭代完善行业治理相关制度体系
    - 针对性强化大模型全流程风险管理
    - 持续深化AI领域的国际交流与合作
3.  **国际协作视角（联合国教科文组织东亚多部门代表处Shahbaz Khan）**：提出AI普惠的三大目标
    - 保障AI技术能够切实赋能学习场景
    - 推动全人群具备基础的AI核心素养
    - 避免AI技术进一步拉大全球数字鸿沟
4.  **专家委员会视角（北京理工大学副校长、工业和信息化领域科技伦理专家委员会主任委员魏一鸣）**：明确后续四大核心工作方向
    - 持续为监管部门提供决策咨询支撑
    - 常态化开展科技伦理审查的专家复核工作
    - 大力推进科技伦理相关培训与公众科普
    - 深度参与科技伦理治理领域的国际交流合作

### 📝 主题演讲核心内容

演讲环节分为学术视角与产业实践两大维度，覆盖AI伦理治理的全链条认知：
| 参与主体 | 分享方向 | 核心内容 |
| :--- | :--- | :--- |
| **学术界嘉宾** | 多维度挑战解析 | 中国科学技术大学陈小平、华东政法大学马长山、耶鲁大学Karman Lucero分别从人工智能的伦理挑战、法律挑战、治理挑战三大视角输出前沿研究观点 |
| **产业界嘉宾** | 落地实践经验 | 商汤科技、华为、百度的相关负责人，分享企业在AI伦理治理领域的自研技术工具与实际落地的成熟经验 |

### 📢 重磅倡议发布

本次论坛首次面向行业发布两份征求意见稿，填补细分AI领域的伦理规范空白：
1.  中国信息通信研究院科技伦理研究中心副主任毕春丽发布 **《生成式人工智能伦理自律公约（征求意见稿）》**，为生成式AI行业的企业自律提供统一参考框架。
2.  清华大学信息国家研究中心助理研究员顾心怡发布 **《脑机接口伦理倡议书（征求意见稿）》**，针对脑机接口这一前沿高风险技术领域，提前明确伦理红线与行为指引。

### 💡 圆桌研讨核心议题

圆桌交流环节由毕春丽主持，3位高校学者+3家头部科技企业代表，围绕 **「生成式人工智能伦理治理发展现状与未来应对」** 主题展开深度研讨，覆盖学术研究、监管落地、企业实操等多个层面的痛点与解决方案。

### 🔍 补充细节
1.  本次论坛汇聚了工业和信息化领域科技伦理专家委员会、中国人工智能学会人工智能伦理与治理委员会、上海市人工智能伦理专家委员会三大权威智库的核心专家，是国内AI伦理领域最高规格的行业研讨活动之一。
