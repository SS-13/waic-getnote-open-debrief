### 🏆 赛事启动背景与基本概况

本次大赛是**2020世界人工智能大会（WAIC）云端峰会AIWIN盛典**的重磅发布项目，由上海市经济和信息化委员会副主任张英等5位行业、产业代表共同启动，是AIWIN 2021赛季的首个赛事。
- **主办单位**：AIWIN组委会、上海人工智能发展联盟医疗专委会
- **承办单位**：上海枫林生命健康产业发展集团、上海市大数据股份有限公司、亚马逊AWS、上海人工智能产业投资基金、AI SPACE
- **赛事定位**：邀约全球自然语言处理（NLP）和知识图谱方向的企业、开发者，基于全球最大新冠研究开放数据集产出前沿科研工具与成果，助力新冠疫情科研攻坚。

### 📊 核心赛事基础：CORD-19数据集详解

新冠开放研究数据集（CORD-19）是本次赛事的核心支撑资源，由Allen人工智能研究院联合扎克伯格基金会、微软研究院、IBM等多家顶尖机构共同打造，核心参数如下：
| 数据集指标 | 具体详情 |
| :--- | :--- |
| **总论文规模** | 近20万篇冠状病毒相关学术论文 |
| **全文论文数量** | 8万余篇 |
| **覆盖研究范围** | 新冠、SARS、MERS等各类冠状病毒研究 |
| **核心数据来源** | PubMed检索论文、WHO维护论文、bioRxiv/medRxiv预印本论文 |
| **设立初衷** | 解决新冠科研论文爆发式增长后，科研人员无法手动快速获取前沿资讯的痛点，通过AI技术加速科研成果转化 |

### 📋 赛事规则全梳理

#### （一）赛事命题要求

赛事采用开放命题模式，参赛项目需基于CORD-19数据集，通过NLP技术分析产出对科研成果解读、病毒研究、药物研发、公共卫生管理有实际价值的新知识或新工具；允许合规使用外部补充数据，但必须在提交材料中完整列明数据来源、获取方式、元信息及使用方式。

#### （二）参赛对象划分

赛事分两大组别精准覆盖不同参赛群体：
1.  **企业组**：面向生物医疗方向知识图谱类企业、生物医药领域人工智能企业，需提交企业营业执照副本，重点展示技术落地能力或现有AI应用在新冠诊疗防控场景的优化效果。
2.  **开发者组**：面向所有非企业身份的开发者（含在校学生），重点展示AI技术创新与应用能力。

#### （三）全赛程时间节点

赛事周期覆盖近5个月，设置6个标准化评审阶段：
| 赛程阶段 | 时间区间 | 核心评审/提交要求 |
| :--- | :--- | :--- |
| 报名/初赛提交 | 7月28日-9月4日 | 提交项目提案、初步成果，企业组同步提交商业计划书（BP） |
| 初审 | 9月5日-9月21日 | 评审重点为项目提案可行性与初步成果质量 |
| 复赛提交 | 9月21日-11月1日 | 提交完整项目文档、最终产出物 |
| 复审 | 11月2日-11月16日 | 评审重点为产出物的技术性与实际成果价值 |
| 终评准备 | 11月16日-11月30日 | 入围队伍筹备线下终评答辩 |
| 终评答辩 | 12月中上旬 | 线下现场答辩，由专业评委现场决出最终获奖名单 |

#### （四）官方配套技术支持

赛事推荐使用AWS的Amazon SageMaker机器学习开发环境，AWS为使用该工具的参赛企业提供专属算力支持与技术指导，帮助参赛团队降低开发门槛、提升产出效率。

### 🎁 六大赛事奖励体系

本次赛事构建了覆盖企业成长、开发者激励的全维度奖励矩阵：
1.  **SAIL奖推荐资格**：AIWIN获奖团队可直接进入WAIC“卓越人工智能引领者奖（SAIL奖）”项目池，参与顶级行业奖项评选。
2.  **枫林集团成长加速**：符合扶持资格的获奖企业，可获得枫林集团在生命医药领域的专属产业资源支持，加速企业落地发展。
3.  **AWS算力扶持**：符合条件的获奖企业可获得亚马逊AWS提供的额外专属算力资源支持。
4.  **产业生态服务**：获奖企业优先纳入AI SPACE、上海人工智能产业投资基金的双创赋能体系，在资金、办公空间、数据资源等方面获得全链条扶持。
5.  **开发者现金奖励**：面向开发者组别设置12万元专属奖金池，激励优秀技术创新成果。
6.  **人才菁英计划**：年龄在16-35岁的获奖开发者可入选AIWIN人才菁英榜，优先获得AIWIN菁英实训营等官方人才培养项目的参与资格。
