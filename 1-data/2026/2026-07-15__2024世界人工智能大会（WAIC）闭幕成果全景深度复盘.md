### 🏆 大会基础概况

本届2024世界人工智能大会暨人工智能全球治理高级别会议主题为**“以共商促共享 以善治促善智”**，由上海市人民政府副市长陈杰宣布闭幕，上海市人民政府副秘书长庄木弟等出席闭幕式。大会首创“闭幕不闭馆”模式，展览将持续开放至7月7日，延长公众体验周期，同时官宣2025年大会再度相约。

### 📝 闭幕式核心成果汇总

闭幕式上集中发布、签约、揭牌了多类重磅产业与平台项目，核心内容如下：
1.  **产学研协同签约**：上海人工智能实验室携手9家产业头部机构完成现场签约，依托书生大模型及生态技术，发挥连接器、加速器和放大器的独特作用，打通产业链上下游协同创新链路，加速科研成果向现实生产力转化。
2.  **市级重点项目落地**：集中签约一批上海市人工智能重点项目，覆盖三大核心赛道：
    | 赛道领域 | 核心价值说明 |
    | :--- | :--- |
    | **大模型** | 在图像识别、自然语言处理、预测分析等多领域展现出极强的技术落地能力 |
    | **具身智能** | 兼具人机交互、自然语言理解能力，可通过感知、认知、决策与动态环境实时校准互动，辅助人类完成决策与行动任务 |
    | **智算生态** | 融合云计算弹性、大数据洞察力、物联网广泛连接、AI智能决策能力，打造全新计算范式 |
3.  **两大公共服务平台揭牌**：正式落地“上海人工智能安全治理实验室”和“上海市智能算力公共服务平台”，聚焦上海“五个中心”建设使命，深入落实人工智能“上海方案”，践行《全球人工智能治理倡议》，率先落地《人工智能全球治理上海宣言》。
4.  **国资与政企合作举措**：11家上海国资国企单位共同发布“上海国资国企‘人工智能+’行动倡议”，以AI技术推动国企转型升级；上海市政府与中国移动达成深化战略合作，启动“上海5GA²示范之城”，锚定未来三年5G-A与AI融合创新，巩固上海数智化引领地位。

### 📊 本届大会核心数据（均创历史新高）

本届WAIC 2024的参会规模、展览体量、产业转化成果均创下历届峰值，关键指标如下：
| 维度 | 具体数据 |
| :--- | :--- |
| **国际参与度** | 来自50多个国家和地区的1300位全球领军人物、展商、团组参会，包含9位图灵奖、菲尔兹奖、诺贝尔奖得主，88位国内外顶级院士 |
| **展览规模** | 展览面积超5.2万平方米，500余家知名企业参展，展出超1500项展品，50余款新品完成首发首秀 |
| **特色亮点** | 近百个大模型集中亮相，18台人形机器人矩阵展出，发布国内首款全尺寸通用人形机器人开源公版机；首创6000平方米全域链接馆，搭建一站式项目孵化、采购对接、场景落地、投融资全周期服务平台 |
| **传播与参观数据** | 截至6日下午2点，线下参观人数突破30万人次，全网流量突破19亿，较上届增长90% |
| **产业转化成果** | 对接132个采购团组，形成126个项目采购需求，预计意向采购金额150亿元；推动24个重大产业项目签约，预计总投资额超400亿元 |

### 🔍 补充细节
- 闭幕式上两位重磅嘉宾分享参会感悟：加州大学伯克利分校人工智能研究实验室人类兼容人工智能中心执行主任马克·尼兹伯格，以及元宇宙加速与可持续发展联合会（MASA）发起人、上海元宇宙与智能研究院（筹）院长袁昱，对本届大会传递的AI治理中国声音、前沿热点议题、重磅智能产品与多元创新生态作出高度评价。
- 大会设置的全域链接馆为行业首创功能区，打破了传统展会“只展示不落地”的局限，打通了技术方、需求方、资本方的对接链路，大幅提升了展会的产业转化效率。
