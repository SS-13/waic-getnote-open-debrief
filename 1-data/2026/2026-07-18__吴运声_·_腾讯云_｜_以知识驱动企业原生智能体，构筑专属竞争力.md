## 一句话概要
企业原生智能体需要"能力底座"与"知识底座"两者缺一不可：腾讯云 ADP 4.0 作为 AgentOps 平台提供可持续运转的能力底座，腾讯乐享作为"能连接、能治理、能进化"的 AI 原生知识库提供企业专属知识底座。

## 核心观点
- 企业智能体要真正落地，须同时具备两个底座：一是能支撑智能体"懂业务、懂企业、可持续运转"的能力底座，二是能让智能体不断获得企业专属价值的知识底座，二者缺一不可。
- 腾讯云智能体开发平台 ADP 升级到 4.0，本质是一个 AgentOps 平台，覆盖智能体的构建、分发、评测、观测全流程，并提供 RAG、工作流、Agent Loop 等多种构建模式与全链路管控、安全治理。
- ADP 4.0 新增 cloud 模式，支持 Agent 与 Workflow 双向调用：用 Agent 理解模糊意图，一旦需求明确（如报销、客户登记）即转入确定性强的工作流，把泛化的意图识别与确定性的流程结合起来。
- ADP 采用云端 Agent Harness 架构，把 Agent 放在云端统一运行管理，带来更稳定（算力云端统一管理）、全流程可治理可记忆（工具、沙箱、调度均在云端）的优势。
- 知识底座腾讯乐享是 AI 原生知识库，把散落在文档、会议、聊天记录中的内容转化为 AI 可理解的知识，并驱动业务执行、支持知识持续进化。

## 内容整理

### 两个底座：能力底座 + 知识底座
吴运声提出，企业原生智能体要真正在企业场景中用起来，需要同时具备两个底座。能力底座解决的是"智能体如何懂业务、懂企业并可持续运转"的问题；知识底座解决的是"智能体如何获取企业已有知识、沉淀企业专属价值"的问题。二者互为支撑、缺一不可：有了能力底座，智能体才能强大而可持续地运转；有了知识底座，智能体才能不断获得企业专属价值。演讲围绕这两个底座依次展开。

### 能力底座：腾讯云 ADP 4.0（AgentOps 平台）
能力底座是腾讯云智能体开发/构建平台 ADP，本次升级到 4.0 版本。ADP 4.0 可视为一个 AgentOps 平台，涵盖从智能体构建、分发到评测、观测的完整流程，并提供多种构建模式——包括传统 RAG 能力、工作流能力，以及较新的 Agent Loop 能力，同时具备全链路管控、安全治理、可观测、可维护等全方位能力。
构建方式上，4.0 新增了 cloud 模式，其一大能力是 Agent 与 Workflow 双向调用：面对需要理解用户模糊需求的情况用 Agent 的泛化能力，一旦需求明确（如用户说"要报销"或"要做客户登记"），就直接转入报销、客户登记等确定性强的工作流，从而把泛化性强的意图识别与确定性强的流程有机结合。另一大特征是云端 Agent Harness 架构：区别于跑在个人 PC/手机上的超级智能体，ADP 把 Agent 放在云端统一运行和管理，好处包括更稳定（整体算力由云端统一管理），以及全流程可治理、可记忆（工具、沙箱与调度都在云端控制）。此外，ADP 面向海外做了适配，在拉美、泰国及沃尔玛等主流海外渠道做全域触达、优化全球化交互体验，并深度连接海外办公生态，以贴合海外用户习惯。

### 落地案例与知识底座：腾讯乐享
ADP 已在媒体视频理解、零售、工业质检、金融交易自动化等行业得到丰富应用。以商品巡检为例：客户"好想来"在全国有超过 8000 家门店，非常关注各门店商品陈列情况；过去需大量人力线下巡检，如今在 ADP 上构建智能体，通过多步骤流程对图片做前置判断、剔除低质量图片，再进行陈列识别，大幅提升效率。
在知识底座方面，吴运声指出知识要经历三个环节：一是被 AI 理解（把散落在文档、会议内容、聊天记录中的信息转化为 AI 可理解的知识）；二是驱动业务执行（不能只等人来查，而要进入业务场景）；三是能够进化（知识本身也在不断迭代更新）。腾讯乐享正是这样一个"能连接、能治理、能进化"的 AI 原生知识库，可承载新人入职、客户售后等业务场景：用户只需一句话，乐享就能依托企业已有知识自动进行多步推理、完成复杂需求；它既可独立使用，也能对接 ADP 所创建的智能体，为其提供企业知识。为确保知识干净可信，乐享还提供"乐享智库"等能力，让企业知识成为可依赖的资产，从企业已有知识出发驱动智能体服务业务。

> 注：ADP、AgentOps、Agent Harness、乐享等名称按现场转写整理，个别为语音转写近似写法（如"同聚云""汉尼斯"）。

## 金句
> 能力底座与知识底座缺一不可：一个让智能体强大、可持续地运转，一个让智能体不断获得企业专属的价值。
> 知识不能只等人来查，而要进入到业务场景里去；而且知识也要能进化。
