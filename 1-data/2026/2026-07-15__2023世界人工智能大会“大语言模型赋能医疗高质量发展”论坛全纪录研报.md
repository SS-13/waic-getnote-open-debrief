### **🏛️ 论坛基础概况**

本次论坛是2023世界人工智能大会（WAIC，大会主题“智联世界 生成未来”，举办时间2023.07.06-07.08）的重要专题活动，核心信息如下：
| 项目 | 详情 |
| :--- | :--- |
| **举办时间** | 2023年7月7日 |
| **举办地点** | 上海张江科学会堂 |
| **主办单位** | 上海申康医院发展中心、上海市人工智能行业协会 |
| **指导单位** | 世界人工智能大会组委会办公室 |
| **承办单位** | 上海市医院协会医学人工智能管理专业委员会、上海市人工智能行业协会医疗AI专委会 |
| **协办单位** | 上海森亿医疗科技有限公司、联仁健康医疗大数据科技股份有限公司、上海皓桦科技股份有限公司 |
| **核心定位** | 汇聚政府、医疗机构、科研院校、产业界多方主体，探讨AI产业融合新趋势，以科技创新赋能医院高质量发展 |

### **🎤 开场致辞核心观点汇总**

论坛由上海申康医院发展中心副主任赵蓉主持开场，三位重磅嘉宾分别从国家战略、产业实践、地方布局三个维度发表致辞：
1.  **国家卫健委统计信息中心副主任胡建平（线上致辞）**
    明确AI三大核心驱动力为大数据、算法、超级计算，提出要推动技术在医疗健康领域实现场景化、专业化、垂直化落地，支撑**健康中国、数字中国**两大国家战略；特别指出AIGC领域需与脑科学、认知科学开展交叉创新，加速AI向生物工程、基因组学等深层场景渗透。
2.  **中国科学院院士陈义汉**
    介绍上海医工融合进展：本地各级医疗机构、院校正推动数字化与医疗卫生深度融合，AI技术已覆盖诊前、诊中、诊后全流程，推动医疗管理与服务模式创新；后续将重点布局AI、大数据、云计算、移动医疗、物联网等前沿技术的成果转化与产业落地，让AI创新成为医疗高质量发展的核心动能。
3.  **上海市经信委人工智能发展处副处长孙跃**
    强调AI是数字健康发展的核心保障，上海市已将医疗健康领域AI应用作为产业布局关键环节；申康医院发展中心在技术与医疗场景结合落地中发挥了关键作用，本次论坛集中展示大语言模型在医疗领域的标杆应用成果，助力共筑AI医疗创新生态。

### **🏆 医疗AI专项奖项颁发**

致辞环节后，陈义汉院士、上海市人工智能行业协会秘书长钟俊浩、赵蓉副主任共同为获奖主体颁发三类医疗AI专项奖项，覆盖服务、技术、实践三大维度：
| 奖项名称 | 评选方向 |
| :--- | :--- |
| 人工智能最佳智能服务奖 | 表彰在医疗智能服务场景落地中表现突出的医院与企业 |
| 人工智能优秀技术创新奖 | 鼓励医疗AI领域的前沿技术突破与自主创新成果 |
| 人工智能应用实践标杆奖 | 树立大语言模型等AI技术在医院场景落地的典型示范案例 |

### **📌 论坛总结与后续规划**

上海申康医院发展中心医联工程与信息化部主任何萍做最终总结：
- 本次论坛响应**健康中国2030**战略与上海人工智能高地建设目标，在市经信委、发改委、卫健委等多部门支持下，申康中心已依托AI、大数据、5G技术推进市级医院“便捷就医服务”数字化转型落地，率先探索大语言模型在公立医院的创新应用。
- 后续申康中心将联动全市市级医院、市人工智能行业协会与头部AI企业，持续推动高品质智慧医疗服务落地，打造面向未来的智慧型医院新形态。
