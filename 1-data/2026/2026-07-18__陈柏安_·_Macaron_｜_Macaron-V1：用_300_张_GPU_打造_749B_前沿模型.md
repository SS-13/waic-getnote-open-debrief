## 一句话概要
Macaron 团队以极少的算力（300 张 GPU）训练出 749B 的前沿模型 Macaron-V1，跳过预训练、以强化学习为主的后训练 + 自研 Mixture-of-LoRA 架构快速迭代，模型在多步工具调用、代码与实时交互界面（AGUI）生成上表现均衡，正式版将于次日发布。

## 核心观点
- Macaron-V1 上月在开闭源模型评测榜单上达到当时最好水准，且在多个 coding benchmark（如 Terminal-bench、SWE-verified 等）上取得均衡表现，与一线模型 competitive。
- 模型擅长复杂多步工具调用（搜索、浏览器浏览、代码/命令执行）与 GitHub 上的多步代码读写、提交 PR、修复代码。
- 在动效上专精 AGUI——实时交互界面生成，一句话生成富动态交互界面并准实时流式生成，为生活/学习类任务提供超越纯文本模型的体验。
- 训练流程"反向操作"：跳过整个预训练，在最前沿大模型上做以强化学习为主的后训练，并优化掉 SFT/合板步骤，用独创的 Mixture-of-LoRA 架构更快交付效果。
- 用"子集迭代"提效：RL 曲线只需 5–10 步即可观察任务设置是否带来有效提升，评测也先在 subset 上做、最后合板/开源时才用完整评测集。

## 内容整理

### 均衡的能力与真实任务表现
陈柏安展示 Macaron-V1 上月在评测榜单上达到当时开闭源模型的最好水准，并强调"均衡"——不仅在自己关心的场景，也在 Terminal-bench、SWE-verified 等 coding benchmark 上表现均衡，与当时一线模型处于 competitive 水准。模型能完成复杂的多步工具调用任务（搜索、浏览器浏览、代码执行、命令执行）从而得到正确答案；在代码任务上能于 GitHub 完成多步工具调用，做代码读写、执行并提交 PR，完成代码修复。动效方面，模型专精 AGUI（实时交互界面生成），能一句话生成多个极富动态动效的交互界面，并以准实时效果流式生成交互结果，让模型与用户的前端交互更自由自然；在复习单词、收拾行李这类日常/学习任务上，因能生成可实时交互的前端特效，给用户带来超越纯文本模型的表现。

### 反向训练流程与 Mixture-of-LoRA
在方法上，Macaron 对模型训练流程做了一次"反向"改造。传统流程是预训练→中训练→后训练→合板（SFT），而团队首先跳过整个预训练过程，直接在今天最前沿的大模型上进行以强化学习为主的后训练，持续提升效果；同时优化掉合板步骤，用一个独创的 Mixture-of-LoRA 架构，使模型能在强化学习基础上更快 deliver 更好的效果。在通用能力上，团队持续用强化学习推动代码、agent 等任务的基模能力提升。

### 用"子集"缩短迭代周期
团队发现在一条强化学习 curve 里，只需 5–10 步就能有效观察到所设计的 RL 任务、实验与 setting 能否带来模型能力的有效提升，因此绝大部分迭代不必在完整 train set 上训练，而是先在 subset 上观察效果。评测同理——在长上下文、多步工具调用的 agent 任务里，evaluation 会消耗大量时间，团队系统性分析了不同 evaluation set size 下的最大理论误差，选择先在 subset 上评测，只在最后合板与开源时才在完整评测集（往往上万道题）上做最终评测，从而缩短每轮迭代时间。最后，陈柏安预告 Macaron-V1 正式版将于次日上午 9:30 在 H4 领航舞台发布（此前 6 月已发布预览版），产品已上线移动端与 API，并同步推出 ChatGPT 插件。
