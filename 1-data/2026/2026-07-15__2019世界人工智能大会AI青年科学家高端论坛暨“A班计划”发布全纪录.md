### **🏆 论坛核心背景概况**

本次活动是2019年8月29日在上海举办的**世界人工智能大会（WAIC）** 的特色活动之一，以“创新动能，智汇传承”为主题，聚焦AI人才培养与顶尖青年科研人才发掘。
活动现场完成了多项重要议程：
1.  上海市政府副秘书长赵祝平、AI青年科学家联盟指导委员会主席、微软全球执行副总裁沈向洋，为联盟新一届成员颁发证书。
2.  全国政协委员、市知联会轮值会长、上海大学副校长汪小帆发布联盟副秘书处单位为将门创投。
3.  重磅年度项目——AI青年科学家联盟“A班计划”全球首次正式亮相并举办启动仪式。

### **🌟 “A班计划”核心细节全解析**

#### 项目基础信息

该计划由AI青年科学家联盟·梧桐汇发起，获得上海市政府及相关部门大力支持，定位为挖掘、培养AI学术研究人才和创业人才的精英项目，通过整合联盟自有资源及政产学研外部资源，打造未来AI学术和产业领军人物的成长“加速器”。

#### 遴选标准与首批成员画像

| 遴选维度 | 具体要求 |
| :--- | :--- |
| **覆盖人群** | 全球优秀AI方向博士生、融资不超过A轮的初创企业创始人 |
| **硬性门槛** | 年龄20-30岁、获得世界顶级学术会议认可、创业方向具备高科技含量 |
| **招募周期** | 为期半年的推荐与自荐 |
| **首批规模** | 11位来自全球顶尖高校的AI方向博士生 |
| **成员背景** | 覆盖加州大学伯克利分校、麻省理工学院、斯坦福大学、北京大学、清华大学等11所海内外顶尖院校 |
| **研究领域** | 计算机视觉、自然语言处理、机器学习、机器人、数据挖掘等AI热点方向 |
| **核心亮点** | 3人获得国际顶会Best Paper奖，成员平均年龄仅26岁 |

#### 三大核心支撑体系

计划从三个维度为青年人才提供全链条成长支持：
1.  **科研层面**：已与国家重点实验室鹏程实验室、国内外顶尖高校达成深度合作。
2.  **资本层面**：对接上海各区孵化器加速器、头部产业巨头加速器以及大量一线投资人资源网络。
3.  **人才培养层面**：建立联盟资深成员与A班人才的一对一Mentor导师机制，为成员成长全程护航。

#### 发起人的核心理念
- 上海交通大学教授、A班计划发起人卢策吾表示：项目定位不是为青年人才“锦上添花”，而是在他们科研创业的关键阶段“雪中送炭”，助力挖掘下一波类似深度学习级别的AI技术红利。
- 氪信科技创始人、A班计划发起人朱明杰表示：希望通过资源倾斜，让中国AI青年人才获得和硅谷同级别创业者对等的成长机会，减少他们早期摸索的时间成本。

### **💡 AI人才培养高端对话核心观点**

论坛设置多场跨界交流环节，围绕AI人才成长的核心议题展开深度探讨：
1.  **院士高端对话**：沈向洋院士与毛军发院士分别从企业全球AI战略布局、高校AI学科建设的双重视角，围绕AI人才核心特质、AI人才涌入是否稀释其他行业人才密度等开放性议题展开交流。
2.  **科创成长主题分享**：朱明杰在《从科学技术到生产力：新时代科创家的自我修养》演讲中提出，AI风口更垂青全才型创业者，企业必须先完成“产品-客户-研发再投入”的商业闭环，同时构建高校-企业-社会的正向反馈闭环，参考硅谷的成熟模式，才能培育出顶尖科技企业。
3.  **多场跨界圆桌讨论**：分别围绕“人工智能产学研人才对接与培养”“从科学家到科创家的人才跨界路径”等议题，汇聚商汤科技、爱立信、ABB机器人等产业界代表，以及高校学者、A班青年成员展开跨界碰撞。

### **📊 产业与政策背景补充**
1.  政策顶层设计：2017年国务院发布《新一代人工智能发展规划》，明确以2030年为节点的AI发展目标，要求在2020年前完成基础研究突破、建成全球顶尖人才集聚地、实现AI产业全球领先等里程碑。
2.  上海AI产业基础：截至2019年，上海AI相关产业规模超700亿元，集聚AI核心企业超1000家，全国1/3的AI人才汇聚上海，正全力打造国家人工智能发展高地，建设成为全国领先的AI创新策源地、应用示范地、产业集聚地和人才高地。
3.  AI青年科学家联盟溯源：该联盟于2018年首届世界人工智能大会期间，在上海市副市长吴清见证下正式成立，首批会员汇聚20余位头部AI企业创业领军人物与学界中坚力量，承载着推动上海成为中国AI创新热土、打通高校科研与产业落地通道的核心使命。
