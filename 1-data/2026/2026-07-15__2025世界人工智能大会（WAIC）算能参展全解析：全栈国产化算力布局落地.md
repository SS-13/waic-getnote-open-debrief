### 📅 参展基础信息
- **展会名称**：2025世界人工智能大会（WAIC）
- **开展时间**：2025年7月26日-29日
- **举办地点**：上海世博展览馆
- **算能展位号**：H1-A825
- **参展核心定位**：以算为擎赋能新质生产力，夯实大模型基础架构，推动各领域智能化进阶，本次将携云边端全系列智算产品、大模型一体机、RISC-V高性能服务器等前沿成果亮相。

### 🚀 普惠算力布局：构建云边协同新生态

算能依托“云端统筹+边缘响应”的协同体系，搭建覆盖数据中心、边缘节点的全链路算力解决方案，实现算力资源弹性分配与实时决策，为行业提供“云边一体”的算力支撑，大幅提升智能化转型效率；同时基于RISC-V开源生态打造高适配性、普惠性算力模块，推动AI技术在重点行业落地“普惠化”进阶。

本次重点展出的全新一代智算卡**SC11 FP300**，是专为云端智能应用设计的核心算力产品，核心参数如下：
| 产品特性 | 具体指标 |
| :--- | :--- |
| 精度支持 | 覆盖INT8/FP8/TF32/FP16/BF16/FP32全精度 |
| 互联能力 | 支持多芯多卡互联 |
| 显存规格 | 最大256GB显存容量，搭载多路编解码能力 |
| 功耗设计 | 采用低电压、低功耗内存技术 |
| 适配场景 | 生成式智能应用、互联网搜索推荐、视频编解码、智慧城市、智慧交通、智能制造，可高效兼容主流深度学习算法 |

### 🔧 RISC-V赛道突破：从芯片到产业全栈落地

算能长期秉持“软件开源、硬件开放”战略深耕RISC-V领域，是国内RISC-V高性能算力赛道的核心厂商：
1.  **初代产品落地**：2023年推出全球首款64核服务器级RISC-V处理器**SG2042**，主频2.0GHz，搭载32条PCIe通道，首次实现RISC-V从物联网、端侧场景向服务器高性能计算场景的跨越，仅用12年就完成了RISC-V在服务器领域的落地，速度远超X86、Arm架构的同期发展节奏。基于SG2042搭建的服务器集群已在山东大学部署，面向学术与商业云客户开放使用。
2.  **行业权威认可**：在2025北京RISC-V生态大会上，算能SG2042与第二代服务器级处理器**SG2044**产品矩阵，成功入选「RISC-V高性能产品创新成果」。
3.  **第二代芯片升级**：SG2044在初代产品基础上完成全面迭代，核心参数如下：
    - 64核@2.6GHz，搭载高带宽内存
    - 支持RVV1.0向量标准、SV48大地址空间
    - 40 lane PCIe 5.0高速互联
    - 集成AES/SM系列国密安全加密引擎
    - 支持大并发高清视频硬件编解码
    - 搭载多精度TPU异构单元，原生支持DeepSeek等数百亿级参数大模型推理
4.  **全系列服务器量产**：基于SG2044打造的4U RISC-V高性能服务器矩阵已实现量产，覆盖三大核心品类：
    | 产品型号 | 定位特性 |
    | :--- | :--- |
    | SRA3-40 计算服务器 | 众核并发，支持混合精度计算 |
    | SRB3-40 存储服务器 | 多盘位、大容量，实现高速数据传输 |
    | SRM3-40 融合服务器 | 面向大模型推理场景，超高算力密度、高能效比 |
    该系列服务器实现软硬件全栈国产化，可搭载自研SC11 FP300智算卡支持4U8卡配置，仅需4卡即可部署Deepseek-R1/V3满血非量化版本，具备优异的$/mtoken与J/token性价比表现，可覆盖通用计算、AIGC、智算中心、边缘计算等多场景。
5.  **开源生态认可**：2025年5月31日，SG2044正式合并进入Linux 6.16主线，继SG2042之后再次获得Linux官方的原生支持与维护，标志着算能RISC-V产品的生态成熟度得到全球开源社区的权威验证。

### ☁️ SophNet云算力平台：落地AI普惠

算能推出**SophNet云算力平台**（官网：sophnet.com），依托自研TPU处理器打造一站式大模型服务平台，实现“几行代码接入顶尖大模型、零代码创建开箱即用智能体”，核心架构从底层到上层分为算力底座层、Hub调度层、MaaS服务层、Agent应用层四大层级，核心优势如下：
1.  **自研TPU算力核心**：专为AI推理和训练任务优化，相比传统GPU在大规模并行计算场景下拥有更高能效比、更低延迟，SC11单卡256GB显存搭配原生FP8算力单元，在DeepSeek推理场景下具备极致性价比。
2.  **分布式智能调度**：支持多任务并行处理、算力动态弹性扩展，适配从小规模实验到大规模生产部署的全场景需求，同时提供兼容OpenAI SDK的标准化API层，开发者无需复杂适配即可快速接入现有业务。
3.  **丰富模型生态**：平台已接入DeepSeek R1满血版、DeepSeek V3 0324、Qwen3等主流开源大模型，还推出业内独有的极速版DeepSeek V3 Fast模型，同时支持用户私有模型托管，通过PD分离部署技术保障模型推理的高响应速度与稳定性。
4.  **全链路自动化运维**：覆盖模型部署、算力分配、性能监控全流程管理，大幅降低用户运维成本。
5.  **安全隐私保障**：内置多层数据加密、访问控制、隐私隔离机制，同时支持企业级私有化部署选项，全方位保障数据与模型安全。
