### 🏆 有道“子曰”教育大模型发展全历程

网易有道是国内教育垂类大模型的落地领跑者，自2023年起持续迭代技术，完整发展时间线如下：
| 时间节点 | 核心里程碑 | 关键价值 |
| :--- | :--- | :--- |
| **2023年7月26日** | 正式发布国内首个教育领域垂直大模型“子曰”及六大应用 | 以“场景为先”为定位，依托专业教育预训练语料精准匹配学习场景答疑需求 |
| **2023年11月4日** | “子曰”教育大模型通过相关备案 | 成为国内首个完成备案的教育垂类大模型 |
| **2024年1月3日** | 推出子曰教育大模型2.0 | 完成基础能力的首次系统性升级 |
| **2024年6月** | 通过中国信通院教育大模型评估，荣获4+级最高评级 | 成为国内首批获得该权威最高认证的教育大模型企业 |
| **2025年1月** | 子曰翻译大模型2.0上线 | 在翻译质量、运行效率、鲁棒性三大维度实现跨越式提升 |
| **2025年1月22日** | 发布并开源国内首个分步骤讲解推理模型“子曰-o1” | 14B参数，单模型推理能力可复现OpenAI o1水平，支持消费级显卡部署，专注中文逻辑推理 |
| **2025年6月23日** | 开源国内首个数学教育专用推理模型“子曰3数学模型（Confucius3-Math）” | 14B轻量级参数，可在单块消费级GPU高效运行，解决数学领域AI幻觉问题，在GAOKAO-Bench(Math)评测中取得98.5分，表现优于DeepSeek-R1等知名通用大模型 |

截至2024年“子曰”发布一周年，有道已基于该大模型开发出覆盖翻译、作文批改、语法精讲、口语练习、家庭辅导等十余项细分学习场景的应用，全部集成至全系软硬件产品体系中。

### 🎯 本届WAIC有道参展核心产品矩阵

本次有道共展出超15款产品，覆盖C端个人学习场景与B端企业知识管理场景，构建全生态AI教育解决方案：

#### 1. 旗舰新品：有道AI答疑笔SpaceOne

2025年2月推出的国内首款AI原生学习硬件，深度融合DeepSeek-R1推理模型与自研“子曰”大模型，核心特性为：
- 支持9科全学科随时随地答疑
- 可视化拆解解题思考全过程，还原教师级详尽“思考草稿纸”，完整呈现每一步逻辑细节
- 重新定义大模型时代智能学习硬件的全新交互形态

#### 2. 核心成熟产品

| 产品名称 | 核心亮点 |
| :--- | :--- |
| **有道翻译** | 拥有18年发展历程，国内教育学习领域用户规模最大的工具类应用，全功能升级为子曰翻译大模型，翻译质量行业第一；支持109种语言互译，覆盖10余种场景，支持文本、文档、图片、音频、视频、同传多形态翻译，内置AIBox、AI文档问答、AI写作等增值功能 |
| **有道趣动屏** | 集成屏幕、摄像头、音箱、雷达多智能模块，可实现身份识别、运动数据实时可视化，搭配趣味游戏、运动排行榜、勋章激励体系，无需教师在场即可引导学生自主运动 |
| **青少年潜能测评系统** | 由有道精品课联合清华长三角研究院研发，对标国际CogAT测试框架，覆盖语言、数学、逻辑、观察、空间五大核心维度，叠加共情力、目标管理等社会能力指标，是新课标体系下首个体能化未来竞争力评估模型 |
| **QAnything** | B端一站式本地知识库问答产品，命名含义为“万物皆可问”，打破数据格式壁垒，将任意私有信息转化为可对话查询的动态知识库，用户通过自然语言提问即可获得精准、可溯源的答案 |

#### 3. 其他参展产品

有道词典笔X7 Pro、全球首个虚拟人口语私教HiEcho、新一代AI全科学习助手有道小P、AI播客助手有道文档fm、中文慕课平台中国大学MOOC、有道小图灵、有道纵横棋院、有道多语言翻译大模型、有道同传智能体等。

### 💡 关键洞察

有道走出了一条差异化的教育大模型落地路径：不盲目追求超大参数规模，而是聚焦教育垂直场景需求，通过14B级轻量级开源模型实现消费级硬件可部署，在数学推理、中文教育等细分赛道的表现反超通用大模型，为AI教育产品的普惠化落地提供了可参考的样本。
