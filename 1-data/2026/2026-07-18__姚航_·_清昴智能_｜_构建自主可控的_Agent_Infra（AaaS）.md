## 一句话概要
清昴智能从大模型部署与国产芯片适配起家，面向 Agent 时代提出"Agent as a Service"，用云化底座 + Agent Hub 平台把 token 成本压到最低，并以安全沙箱、Agent 集团协作帮助企业把 Agent 从"可用"做到"可生产"。

## 核心观点
- Agent 爆发背后有两个拐点：大模型能力拐点（能端到端完成"从想法提出到任务执行"）与形式拐点（Agent / token 工厂，底层能源就是 token）。
- Agent 落地需消耗大量 token → 带来大量算力消耗 → 背后是供应链；同时 Agent 进企业需要清晰的目标与执行框架。
- 提出"AaaS（Agent as a Service）"，深耕高质量 Agent / token 原料，并推出面向企业级落地的 Agent Hub 平台，对标海外。
- 通过集群与单机优化 + 上下文缓存，把企业用 Agent 的 token 成本降到最低。
- 企业级 Agent 不是单个 Agent，而是"Agent 集团"多 Agent 协作；落地要解决安全（沙箱隔离、权限管理、可回溯）。

## 内容整理

### 从国产芯片适配到云化底座
2023 年公司聚焦解决大模型部署难题，在算力受限后把核心能力聚焦到国产芯片上，做了一系列国产芯片的适配优化，并于 2023 年拿到华为的战略投资；2025 年推出系列产品，尤其是面向国产芯片的优化框架与向上走的计算云平台。这一过程中与共济、清华有深度合作。今年，公司面向 Agent 发布了首个云化底座 S 平台（AaaS）。

### 两个拐点与"可用到可生产"
姚航分析 Agent 趋势爆发源于两个拐点：一是大模型能力拐点——越来越多基座模型能完成从一个想法提出到任务执行的端到端过程；二是形式拐点——出现了 Agent / token 工厂，底层能源就是 token。由此他推演出一条逻辑：Agent 要落地需要大量 token，token 带来大量算力消耗，算力背后是各种供应链；另一方面，Agent 要落到企业需要非常清晰的执行框架与执行系统。综合两方面，公司提出"AaaS（Agent as a Service）"概念，面向各行各业深耕高质量的 Agent 与 token 原料，并推出面向企业级落地的 Agent Hub 平台，对标海外首批 Cloud 版方案。在一定输入/输出与持续上下文缓存情况下，通过集群与单机各方面优化，帮助企业把用 Agent 的整体 token 成本降到最低。

### 安全、Agent 集团与场景落地
当 token 成本足够高性价比后，如何让企业把 Agent 引入自己的环境？公司基于 OpenCL 推出"玄武 CL"产品，帮助企业实现闭环的 Agent / AI 落地。这里考虑几个方面：一是安全——通过沙箱隔离、权限管理、可回溯等一系列方式（呼应清华团队反复强调的"用得安全"）；二是认为现有企业级 Agent 不是单个 Agent，而是一系列 Agent 协作，即"Agent 集团"。从适配国产芯片、把集群调度起来形成算力平台、形成高质量 token，到 Agent 平台帮助企业做私有化协作，再到具体场景（办公、物流、工业乃至政府场景，客户中包括全国最大的物流中心）。姚航总结"后 Agent 时代"要既有底层能力、也有平台交付与场景结果的综合解决方案，并感慨技术代差会越来越小——曾被视为高门槛的 Agent 工作正被 AI 逐步替代，但这更需要各家深度耕耘、持续迭代自己企业内部的 Agent。

## 金句
> "我们提出了一个叫 AaaS 的概念——面向各行各业的 Agent，去深耕高质量的 Agent 原料、高质量的 token 原料。"

> "现有的 Agent 不是一个 Agent，它是一系列 Agent 进行协作，叫做 Agent 集团。"
